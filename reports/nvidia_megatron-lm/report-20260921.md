# Pull Request Digest for nvidia/megatron-lm (20260914-20260921)

**PR 统计**：共 224 个（已合并 81 · 进行中 56 · 草稿 41 · 已关闭 46），另有 1 个机器人 PR 未计入

## 本周概览
本周重点围绕 MXFP8 推理与训练生态的完善、MFSDP v2 原型的关键组件落地，以及多模态能力的显著增强展开。同时，训练框架在配置初始化顺序、优化器链正确性、日志去重和 CI 基础设施方面进行了多项重要修复与重构，提升了大规模训练的稳定性与可维护性。

**最活跃领域**：1. MXFP8 推理与训练；2. MFSDP v2；3. 多模态支持；4. 训练与优化器修复；5. CI/测试改进

## 重点进展
- **MXFP8 选择性推理精度与批量不变性**：支持按层选择 BF16/MXFP8 推理参数存储，并实现 Torch/vLLM/FlashInfer 的批量不变推理及 TE 分组训练，大幅降低显存占用并保持精度 [#7300](https://github.com/nvidia/megatron-lm/pull/7300) [#7302](https://github.com/nvidia/megatron-lm/pull/7302)
- **多模态视觉上下文并行与检查点初始化**：新增视觉 token 的 CP 切分/聚合、padding 处理，并支持从纯语言检查点初始化多模态模型的语言部分，打通多模态训练关键路径 [#7315](https://github.com/nvidia/megatron-lm/pull/7315) [#7316](https://github.com/nvidia/megatron-lm/pull/7316)
- **训练配置构造重构**：将配置解析与运行时初始化解耦，使 `parse_and_validate_args` 不再触发 tokenizer、microbatch 计算等服务，解决了配置与运行时耦合导致的多个问题 [#7418](https://github.com/nvidia/megatron-lm/pull/7418)
- **推理请求序列化性能修复与视觉缓存扩展**：将 Tensor 序列化从 `tolist()` 改为字节级算法，消除推理请求创建瓶颈；同时统一视觉哈希，扩大缓存范围 [#7352](https://github.com/nvidia/megatron-lm/pull/7352)
- **优化器链嵌套支持与步骤同步修复**：修复 `ChainedOptimizer` 嵌套时崩溃及步骤同步错误，并支持 MIMO 中混合优化器的正确状态遍历 [#7354](https://github.com/nvidia/megatron-lm/pull/7354) [#7355](https://github.com/nvidia/megatron-lm/pull/7355)

## 值得关注
- **CI 回滚与重新应用**：因 CI 失败回退了三个近期合并的 PR（[#7326](https://github.com/nvidia/megatron-lm/pull/7326)），随后通过自动化 PR 重新应用了 DeepSeek-V3 NVFP4 训练支持（[#7328](https://github.com/nvidia/megatron-lm/pull/7328)）、多模态视觉 token 工具（[#7329](https://github.com/nvidia/megatron-lm/pull/7329)）和融合 GDN 注意力（[#7327](https://github.com/nvidia/megatron-lm/pull/7327)），需关注后续稳定性。
- **PyTorch 2.14 兼容性**：`CUDAGraph.register_generator_state()` 在 PyTorch 2.14 中已弃用，相关警告导致 CI 日志膨胀和 OOM，已通过 [#7348](https://github.com/nvidia/megatron-lm/pull/7348) 修复，但需注意未来版本移除该 API 的风险。
- **破坏性变更风险**：`warn_single_rank` 的引入（[#7361](https://github.com/nvidia/megatron-lm/pull/7361)）曾导致警告过滤器被频繁重置，使其他警告被抑制，已通过 [#7451](https://github.com/nvidia/megatron-lm/pull/7451) 修复，提醒框架工程师注意全局状态变更的副作用。
