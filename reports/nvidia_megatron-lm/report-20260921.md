# Pull Request Digest for nvidia/megatron-lm (20260914-20260921)

1. 关键要点  
   - 本周最显著趋势是围绕 DeepSeek-V4、GLM-5.3-Flash 等下一代混合架构的组件化集成（mHC/CSA/KDA），以及 MoE 训练路径与 MFSDP v2 的大规模重构与稳定性修复；共 225 个 PR，最活跃领域集中在：1) 模型架构与注意力变体；2) MFSDP v2/分布式优化器；3) MoE 优化；4) CI/测试基础设施；5) 推理优化。

2. 新模型与架构特性  
   - [PR#7500](https://github.com/NVIDIA/Megatron-LM/pull/7500) - [PR#7503](https://github.com/NVIDIA/Megatron-LM/pull/7503) — 分 4 个 PR 系列加入 DeepSeek-V4.1 CSA2、单遍 mHC、V4.1 Engram、V4.1 视觉及 DSpark 草案注意力。  
   - [PR#7521](https://github.com/NVIDIA/Megatron-LM/pull/7521)、[PR#7522](https://github.com/NVIDIA/Megatron-LM/pull/7522)、[PR#7523](https://github.com/NVIDIA/Megatron-LM/pull/7523) — 从 #7054 拆分，加入 GLM-5.3-Flash 所需的 mHC 数值控制、KPool DSA 索引器、NoPE MLA 及 FP8 精度控制。  
   - [PR#7427](https://github.com/NVIDIA/Megatron-LM/pull/7427) — 添加 Kimi Delta Attention（KDA）作为 `experimental_attention_variant="kda"`，及可配置的 mHC 输入归一化 epsilon。  
   - [PR#7393](https://github.com/NVIDIA/Megatron-LM/pull/7393) — 加入 Qwen4-Exp (Qwen3.8-Flash-Next) 的 Gated Residual hyper connections、共享输出门等架构块。  
   - [PR#7469](https://github.com/NVIDIA/Megatron-LM/pull/7469) — DSv4 支持 packed THD 上下文并行（CP>1），覆盖 window attention、CSA、HCA、MTP。  
   - [PR#7387](https://github.com/NVIDIA/Megatron-LM/pull/7387) — 通过 `TreePackedSeqParams` 支持共享前缀训练树与上下文并行。  

3. MFSDP v2 与分布式优化器  
   - [PR#7345](https://github.com/NVIDIA/Megatron-LM/pull/7345)、[PR#7306](https://github.com/NVIDIA/Megatron-LM/pull/7306)、[PR#7305](https://github.com/NVIDIA/Megatron-LM/pull/7305) — 将 #6197 的 MFSDP v2 MXFP8/VPP/1F1B/分布式 Muon 工作 rebase 并拆分为可合并的增量 PR。  
   - [PR#7396](https://github.com/NVIDIA/Megatron-LM/pull/7396) — 在 MFSDP v2 中加入 `TensorAtomic` 分片布局，为 owner-based 参数分片打基础。  
   - [PR#7322](https://github.com/NVIDIA/Megatron-LM/pull/7322) — 训练期间保持 MFSDP v2 参数/梯度/优化器状态为本地张量，仅在 checkpoint 边界构造 DTensor。  
   - [PR#7519](https://github.com/NVIDIA/Megatron-LM/pull/7519) — 初步支持 MFSDP v2 + Muon v1.1（预览 PR）。  
   - 多个优化器修复：嵌套 `ChainedOptimizer` 遍历 [PR#7355](https://github.com/NVIDIA/Megatron-LM/pull/7355)、步骤同步 [PR#7354](https://github.com/NVIDIA/Megatron-LM/pull/7354)、混合 CPU/GPU Adam 梯度路由与恢复 [PR#7449](https://github.com/NVIDIA/Megatron-LM/pull/7449)。  

4. MoE 优化  
   - [PR#7450](https://github.com/NVIDIA/Megatron-LM/pull/7450) — 采用 MoonEP 风格的专家复制，在 HybridEP 上实现虚拟专家负载均衡。  
   - [PR#7425](https://github.com/NVIDIA/Megatron-LM/pull/7425)、[PR#7416](https://github.com/NVIDIA/Megatron-LM/pull/7416)、[PR#7423](https://github.com/NVIDIA/Megatron-LM/pull/7423)、[PR#7424](https://github.com/NVIDIA/Megatron-LM/pull/7424) — 一组 opt-in 重计算与路由优化：缓存 DeepEP 分派元数据、跳过无用 fc2/combine、复用序列并行输入、融合 sigmoid 路由与辅助损失。  
   - [PR#7331](https://github.com/NVIDIA/Megatron-LM/pull/7331) — 新增 `--moe-ep-chunk-overlap`，以 token 分块双流调度重叠 MoE 专家并行 A2A 与 GEMM。  
   - [PR#7526](https://github.com/NVIDIA/Megatron-LM/pull/7526) — 添加 dense vs fused Triton 的 ScatterMoE 专家后端基准（测量工具）。  
   - [PR#7488](https://github.com/NVIDIA/Megatron-LM/pull/7488) — 可复现的 MoE token 不均衡基准，含 all-to-all baseline。  

5. 推理优化  
   - [PR#7520](https://github.com/NVIDIA/Megatron-LM/pull/7520)、[PR#7431](https://github.com/NVIDIA/Megatron-LM/pull/7431) — RL `get_logprobs` 直接基于 vocabulary-parallel logits 计算，避免全词表 gather。  
   - [PR#7310](https://github.com/NVIDIA/Megatron-LM/pull/7310) — 支持动态推理异步调度路径上的 MoE 路由回放。  
   - [PR#7404](https://github.com/NVIDIA/Megatron-LM/pull/7404) — 修复 MTP 层路由器在推理 router-replay 捕获时的崩溃与状态问题。  
   - [PR#7405](https://github.com/NVIDIA/Megatron-LM/pull/7405) — 恢复 `--stream-ckpt-dequant`，支持 `--fp8-param-gather`/`--fp4-param-gather` 的流式推理反量化加载。  
   - [PR#7491](https://github.com/NVIDIA/Megatron-LM/pull/7491) — 修复多模态占位符 token 生成的漏洞，防止注入不存在的 embedding。  
   - [PR#7352](https://github.com/NVIDIA/Megatron-LM/pull/7352) — 加速 Tensor 序列化并扩展视觉缓存作用域，减少推理请求创建瓶颈。
