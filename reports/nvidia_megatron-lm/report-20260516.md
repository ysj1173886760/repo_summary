# Pull Request Digest for nvidia/megatron-lm (20260509-20260516)

**关键要点**  
本周最显著的趋势是围绕 Qwen3.5-VL 等新模型的大规模支持落地，同时 MXFP8 低精度训练与混合专家并行（MoE）的优化持续深化；共 111 个 PR，最活跃领域为：1. 新模型与架构支持 2. 低精度训练与量化 3. MoE 与专家并行 4. 混合模型与 Mamba 5. 分布式训练与 FSDP 6. 推理优化 7. CI/基础设施与代码健康。

---

### 1. 新模型与架构支持
- **Qwen3.5-VL 系列**：通过 5 个主 PR 和对应的 dev 镜像，系统性添加 Qwen3.5-VL 训练支持，包括 MTP packed-seq CP+THD 修复 [PR#4495](https://github.com/NVIDIA/Megatron-LM/pull/4495)、FSDP DTensor 检查点兼容 [PR#4753](https://github.com/NVIDIA/Megatron-LM/pull/4753)、`SharedExpertMLP` meta init [PR#4754](https://github.com/NVIDIA/Megatron-LM/pull/4754)、Interleaved MRoPE 布局 [PR#4755](https://github.com/NVIDIA/Megatron-LM/pull/4755) 及完整训练示例 [PR#4756](https://github.com/NVIDIA/Megatron-LM/pull/4756)，并追加 MoE aux loss padding_mask 修复 [PR#4777](https://github.com/NVIDIA/Megatron-LM/pull/4777)。
- **DeepSeek-V4 MTP**：添加 MTP 支持 [PR#4763](https://github.com/NVIDIA/Megatron-LM/pull/4763)。
- **MTP 修复**：修复 MTP 层重计算与 TE FP8/MXFP8 检查点兼容性 [PR#4765](https://github.com/NVIDIA/Megatron-LM/pull/4765) [PR#4766](https://github.com/NVIDIA/Megatron-LM/pull/4766)，以及 EP 重叠下 PP=1 的断言释放 [PR#4796](https://github.com/NVIDIA/Megatron-LM/pull/4796)。
- **MIMO 训练**：添加 colocated MIMO 的 LLM PP>1 支持 [PR#4784](https://github.com/NVIDIA/Megatron-LM/pull/4784)，修复非 colocated 布局下的分布式检查点保存/加载 [PR#4801](https://github.com/NVIDIA/Megatron-LM/pull/4801) 及冻结模块优化器设置 [PR#4790](https://github.com/NVIDIA/Megatron-LM/pull/4790)。
- **Nemotron 推理优化**：优化预填充引擎步骤，提升 Mamba 预填充速度 30% [PR#4764](https://github.com/NVIDIA/Megatron-LM/pull/4764)。

### 2. 低精度训练与量化
- **MXFP8**：新增 opt-in MXFP8 LM-head 输出投影 [PR#4825](https://github.com/NVIDIA/Megatron-LM/pull/4825)；修复 DP 重叠关闭时参数收集的数值问题 [PR#4800](https://github.com/NVIDIA/Megatron-LM/pull/4800) [PR#4769](https://github.com/NVIDIA/Megatron-LM/pull/4769)；dev 分支镜像 MXFP8 参数收集修复 [PR#4818](https://github.com/NVIDIA/Megatron-LM/pull/4818)。
- **ModelOpt 量化**：示例中添加自动量化支持 [PR#4821](https://github.com/NVIDIA/Megatron-LM/pull/4821)；现代化后训练示例脚本 [PR#4807](https://github.com/NVIDIA/Megatron-LM/pull/4807)；依赖升级至 0.44.0 [PR#4803](https://github.com/NVIDIA/Megatron-LM/pull/4803) 及 0.43.0 [PR#4723](https://github.com/NVIDIA/Megatron-LM/pull/4723)。
- **TP 不变训练**：实现跨 TP 度和 GPU 架构的 bitwise 一致训练 [PR#4740](https://github.com/NVIDIA/Megatron-LM/pull/4740)。
- **MTP QAT**：支持冻结基础模型并仅训练 MTP 头，适配 ModelOpt 量化模型导出 [PR#4785](https://github.com/NVIDIA/Megatron-LM/pull/4785)。

### 3. MoE 与专家并行
- **DeepEP v2**：添加 flex dispatcher 后端 [PR#4793](https://github.com/NVIDIA/Megatron-LM/pull/4793)；为 THD 格式训练添加 deepep/hybridep dispatcher 支持 [PR#4816](https://github.com/NVIDIA/Megatron-LM/pull/4816)。
- **内存优化**：减少 unfused EP combine 路径的 MoE 峰值内存 [PR#4746](https://github.com/NVIDIA/Megatron-LM/pull/4746)。
- **进程组传递**：将自定义进程组贯穿 MoE 梯度最终化 [PR#4782](https://github.com/NVIDIA/Megatron-LM/pull/4782) 及混合日志 [PR#4781](https://github.com/NVIDIA/Megatron-LM/pull/4781)。
- **YAML 配置**：允许 YAML MoE 配置使用 model specs [PR#4822](https://github.com/NVIDIA/Megatron-LM/pull/4822)。
- **DeepEP IB 限制**：添加 Python 侧防护栏并重算内部处理 [PR#4719](https://github.com/NVIDIA/Megatron-LM/pull/4719)，随后回退过于保守的旧防护栏 [PR#4718](https://github.com/NVIDIA/Megatron-LM/pull/4718)。

### 4. 混合模型与 Mamba
- **HybridStack 分组**：添加分组语法与 EP 重叠调度，支持嵌套 HybridStack [PR#4798](https://github.com/NVIDIA/Megatron-LM/pull/4798)。
- **Mamba 修复**：修复 chunked prefill 下 Mamba prefix 匹配 [PR#4758](https://github.com/NVIDIA/Megatron-LM/pull/4758)。
- **Paged Stashing**：更新以支持混合模型、降低预存储成本并优化张量生命周期 [PR#4778](https://github.com/NVIDIA/Megatron-LM/pull/4778)。
- **依赖升级**：升级 `mamba-ssm` 至 2.3.2.post1，`causal-conv1d` 至 1.6.2.post1 [PR#4712](https://github.com/NVIDIA/Megatron-LM/pull/4712)。
- **GDN 选择性重计算**：为 GDN 层的 `norm_out` 启用选择性重计算 [PR#4715](https://github.com/NVIDIA/Megatron-LM/pull/4715)。

### 5. 分布式训练与 FSDP
- **FSDP 修复**：修复双缓冲下 bucket 不匹配导致的 CUDA IMA [PR#4810](https://github.com/NVIDIA/Megatron-LM/pull/4810)；修复 FSDP DTensor 检查点转换错误 [PR#4799](https://github.com/NVIDIA/Megatron-LM/pull/4799)；修复零计数与解耦梯度不兼容 [PR#4802](https://github.com/NVIDIA/Megatron-LM/pull/4802)；保留非 FSDP-unit bucket 跨 AllGatherPipeline 重置 [PR#4717](https://github.com/NVIDIA/Megatron-LM/pull/4717)。
- **分布式优化器**：将非 Muon 参数路由至 `DistributedOptimizer` 以消除 padding 开销 [PR#4771](https://github.com/NVIDIA/Megatron-LM/pull/4771)；修复 Muon QKV 分割对 gated attention 的支持 [PR#4728](https://github.com/NVIDIA/Megatron-LM/pull/4728)。
- **检查点**：修复 CP RNG tracker 语义 [PR#4828](https://github.com/NVIDIA/Megatron-LM/pull/4828)；避免 GPU0 CUDA 上下文增长 [PR#4827](https://github.com/NVIDIA/Megatron-LM/pull/4827)；修复 MIMO 优化器检查点元数据恢复 [PR#4791](https://github.com/NVIDIA/Megatron-LM/pull/4791)。
- **通信优化**：优化 MTP mHC 的 `e_proj` 和 `h_proj` TP 通信 [PR#4817](https://github.com/NVIDIA/Megatron-LM/pull/4817)。
