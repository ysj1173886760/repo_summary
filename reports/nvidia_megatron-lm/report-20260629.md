# Pull Request Digest for nvidia/megatron-lm (20260622-20260629)

本周核心驱动力围绕 Blackwell 硬件适配与 FSDP 通信隐藏优化，伴随多模型混合架构（DeepSeek/Mamba）代码集成与训练稳定性修复的集中冲刺。共 104 个 PR，最活跃领域为：
1. Megatron-FSDP 实验性通信重叠与内存优化
2. 混合模型架构支持与数值修复（DeepSeek‑V4、Mamba、GatedDeltaNet、Diffusion LM）
3. CI/CD 基础设施现代化（GB200/GB300、flash_mla、容器构建缓存）
4. 分支同步与版本发布（main↔dev nightly sync、core_r0.18.0 补丁）
5. 训练稳定性与数值精度修复（梯度裁剪、MoE FP8/FP4、TP 平滑）

---

### 1. 分布式训练与 FSDP 优化
- 前向和反向通信重叠：实现 `FsdpContext` 管理独立 CUDA 流，延迟参数释放以重叠 all‑gather 与计算 [PR#5513](https://github.com/NVIDIA/Megatron-LM/pull/5513)，并试验性全量 FSDP 通信重叠 [PR#5416](https://github.com/NVIDIA/Megatron-LM/pull/5416)。
- 可选 NCCL 对称内存 staging，减少显存碎片并降低延迟 [PR#5440](https://github.com/NVIDIA/Megatron-LM/pull/5440)。
- `MaxPoolAllocator` 为混合架构（如 Nemotron‑6 MoE）实现双缓冲 FSDP bucket 分配，消除显存碎片 [PR#5462](https://github.com/NVIDIA/Megatron-LM/pull/5462)。
- DBuffer 移除自定义 mesh axis 校验，简化去重缓冲区逻辑 [PR#5441](https://github.com/NVIDIA/Megatron-LM/pull/5441)。
- 优化部分 CUDA 图内存使用 [PR#5451](https://github.com/NVIDIA/Megatron-LM/pull/5451)。
- 支持 Muon 优化器的 FP8 参数 gather 和紧凑解耦 LayerWise DDP 布局，使 Muon 内存降至 Adam 水平且位等价 [PR#5479](https://github.com/NVIDIA/Megatron-LM/pull/5479)（main）/ [PR#5470](https://github.com/NVIDIA/Megatron-LM/pull/5470)（dev）。
- 支持 A2A 重叠与部分 CUDA 图兼容 [PR#5505](https://github.com/NVIDIA/Megatron-LM/pull/5505)。

### 2. 混合模型架构与数值修复
- **DeepSeek‑V4 混合模型**：在 dev 分支启用完整迭代 CUDA 图，封闭与 gpt_model 的性能差距 [PR#5485](https://github.com/NVIDIA/Megatron-LM/pull/5485)；添加 formal YaRN RoPE 配置字段使 `--position-embedding-type yarn` 在混合模型中可用 [PR#5465](https://github.com/NVIDIA/Megatron-LM/pull/5465) / [PR#5461](https://github.com/NVIDIA/Megatron-LM/pull/5461)。
- **Mamba 与 GatedDeltaNet**：修复 Mamba 前缀缓存应对多 chunk prefill 和空步骤 [PR#5502](https://github.com/NVIDIA/Megatron-LM/pull/5502)；将 `mamba` 加入选择性重计算模块 [PR#5463](https://github.com/NVIDIA/Megatron-LM/pull/5463)；为 GDN 层添加 `gdn_norm_out` 选择性重计算支持 [PR#5443](https://github.com/NVIDIA/Megatron-LM/pull/5443)；隔离 GDN `in_proj` 梯度，防止单一大梯度钳制全局梯度范数 [PR#5431](https://github.com/NVIDIA/Megatron-LM/pull/5431)。
- **MoE 数值修复**：修复 FP8/FP4 主权重下单分组权重的梯度尖峰和精度问题 [PR#5487](https://github.com/NVIDIA/Megatron-LM/pull/5487) / [PR#5464](https://github.com/NVIDIA/Megatron-LM/pull/5464)；排除填充 token 参与 HybridEP 路由 [PR#5515](https://github.com/NVIDIA/Megatron-LM/pull/5515)；修复多 chunk upcycling 参数顺序错误 [PR#5442](https://github.com/NVIDIA/Megatron-LM/pull/5442)。
- **MIMO 多模态**：添加异构 MIMO (Nemotron6‑MoE VLM) 训练入口点，基于 stock `pretrain()` 循环 [PR#5504](https://github.com/NVIDIA/Megatron-LM/pull/5504)；将显式 process group 穿入训练归约、调度及 checkpoint 路径 [PR#5486](https://github.com/NVIDIA/Megatron-LM/pull/5486)。
- **其他**：双塔扩散语言模型实验 [PR#5472](https://github.com/NVIDIA/Megatron-LM/pull/5472)；离线 KD 扩展支持序列长度、CP 及 batchsize 不变性 [PR#5482](https://github.com/NVIDIA/Megatron-LM/pull/5482)。

### 3. 推理增强
- 动态推理异步调度：允许下一 prepare/forward 与当前请求生命周期更新并行 [PR#5453](https://github.com/NVIDIA/Megatron-LM/pull/5453)。
- Blackwell 推理：prefill 使用 FA4，decode 回退至 FA2 以获得最优吞吐 [PR#5494](https://github.com/NVIDIA/Megatron-LM/pull/5494)。
- 新增 `logprobs_mode`（raw/processed）对齐 vllm 行为 [PR#5419](https://github.com/NVIDIA/Megatron-LM/pull/5419)。
- 强制 RL 推理 CP=1 以确保正确性 [PR#5423](https://github.com/NVIDIA/Megatron-LM/pull/5423)。
- 引入 Dynamo 前端聚合推理组件，为分离式推理铺路 [PR#5489](https://github.com/NVIDIA/Megatron-LM/pull/5489)。
- 清理 MTP 推理控制流冗余 [PR#5418](https://github.com/NVIDIA/Megatron-LM/pull/5418)。

### 4. 训练稳定性修复
- 梯度裁剪：修复当梯度列表为空时 `inf`/`p`‑norm 分支崩溃 [PR#5530](https://github.com/NVIDIA/Megatron-LM/pull/5530)。
- TP 标签平滑：使用全局词汇量计算标签平滑，并跨 TP 组归约 log‑prob，防止数值下溢 [PR#5522](https://github.com/NVIDIA/Megatron-LM/pull/5522)。
- Context Parallel：修复 `BlendedDataset` 的 `dataset_id` 标量在 per‑sequence CP 分区时越界 [PR#5531](https://github.com/NVIDIA/Megatron-LM/pull/5531)；修复序列打包 wrapper 在 eval 场景丢失代码 [PR#5483](https://github.com/NVIDIA/Megatron-LM/pull/5483)。
- RoPE 与 MLA：防止融合 MLA RoPE 内核 ros/sin 缓存尺寸不足时越界 [PR#5497](https://github.com/NVIDIA/Megatron-LM/pull/5497)；修复融合 DSA 反向 RoPE 的 in‑place 操作破坏保存的注意力输出 [PR#5526](https://github.com/NVIDIA/Megatron-LM/pull/5526)。
- Tokenizer：修复 `MegatronTokenizerTextAbstract` 特殊 ID 属性无限递归 [PR#5445](https://github.com/NVIDIA/Megatron-LM/pull/5445) 及 tokenizer 递归误差 [PR#5478](https://github.com/NVIDIA/Megatron-LM/pull/5478)。
- 其他：MoE metric 张量绑定到 CUDA 设备以避免 NCCL FastTrak 注册失败 [PR#5446](https://github.com/NVIDIA/Megatron-LM/pull/5446)；GPTDataset 防止零 token 导致无限循环 [PR#5519](https://github.com/NVIDIA/Megatron-LM/pull/5519)。
