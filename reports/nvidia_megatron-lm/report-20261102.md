# Pull Request Digest for nvidia/megatron-lm (20261026-20261102)

**PR 统计**：共 318 个（已合并 39 · 进行中 82 · 草稿 180 · 已关闭 17），另有 1 个机器人 PR 未计入

## 本周概览
本周合并的 PR 集中在训练数值稳定性、MoE/FSDP 性能与内存优化，以及推理正确性修复。动态推理侧有大量 draft 修复覆盖服务协议、MLA/Mamba/FlashInfer 等路径；同时一个大型进程组重构系列（draft）持续推进，旨在消除对全局 `parallel_state` 的隐式依赖。

**最活跃领域**：1. 推理；2. MoE/性能优化；3. FSDP/分布式训练；4. 数值精度/训练稳定性；5. CI/工具链

## 重点进展
- **step-wise LR multipliers**：支持在现有 LR schedule 上叠加分段常数乘子，便于 batch-size ramp 时按 √(B/B_final) 缩放学习率 [#8524](https://github.com/nvidia/megatron-lm/pull/8524)
- **batch-invariant MoE unpermute Triton 融合**：将训练侧 AllToAll combine 从 Python 循环改为单个 Triton kernel，输出与梯度 bitwise 一致 [#8559](https://github.com/nvidia/megatron-lm/pull/8559)
- **FlashInfer MXFP8 专家权重内存减半**：refit 直接写入 routed layout，消除双份专家权重驻留 [#8560](https://github.com/nvidia/megatron-lm/pull/8560)
- **Megatron-FSDP backward prefetch 修复**：预取 activation-recompute 所需 row-wise 权重，避免按需 gather 阻塞主 stream；并排除无需 all-gather 的 bucket [#8515](https://github.com/nvidia/megatron-lm/pull/8515) [#8575](https://github.com/nvidia/megatron-lm/pull/8575)
- **GDP 内存与数值修复系列**：保存 GTP shards in place 节省约 85GiB；保持 `A_log`/`dt_bias`/beta sigmoid 在 FP32；优化 gate storage [#8530](https://github.com/nvidia/megatron-lm/pull/8530) [#8517](https://github.com/nvidia/megatron-lm/pull/8517) [#8528](https://github.com/nvidia/megatron-lm/pull/8528) [#8529](https://github.com/nvidia/megatron-lm/pull/8529)
