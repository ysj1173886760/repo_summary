# Pull Request Digest for nvidia/megatron-lm (20260928-20261005)

**PR 统计**：共 175 个（已合并 18 · 进行中 85 · 草稿 62 · 已关闭 10）

## 本周概览
本周 MFSDP v2 迎来关键增强，正式支持 `TensorAtomic` 布局与不均匀集合通信，并修复了大量训练与反向传播边界问题。推理侧集中解决了多模态、工具调用和采样一致性问题，同时确定性训练得到系统性加固。Lite 分支的 DSA 索引器 top-k 流水线初具雏形，MoK 后端集成也正式启动。

**最活跃领域**：1. MFSDP v2；2. 推理；3. 确定性训练；4. 模型架构与 MoE；5. Lite 与 DSA 索引器

## 重点进展
- **MFSDP v2 支持 TensorAtomic 布局与不均匀集合通信**：通过三个合并 PR 为 `GlobalLayout` 添加显式 rank 段和 per-placement 构建器，使 `DBuffer` 能处理 `TensorAtomic` 布局的不均匀 allgather/reduce-scatter，并接入 `fully_shard`，为灵活参数分布奠定基础 [#7670](https://github.com/nvidia/megatron-lm/pull/7670) [#7671](https://github.com/nvidia/megatron-lm/pull/7671) [#7672](https://github.com/nvidia/megatron-lm/pull/7672)
- **推理引擎多项关键修复**：移除多模态媒体字节限制，修复推理时无最终答案返回 null 内容、Qwen3 工具函数名归一化、请求级停止词强制和 finish reason 保留，并支持请求局部采样种子，提升服务健壮性与 RL 兼容性 [#7702](https://github.com/nvidia/megatron-lm/pull/7702) [#7749](https://github.com/nvidia/megatron-lm/pull/7749) [#7753](https://github.com/nvidia/megatron-lm/pull/7753) [#7747](https://github.com/nvidia/megatron-lm/pull/7747) [#7828](https://github.com/nvidia/megatron-lm/pull/7828)
- **确定性训练全面加固**：支持确定性融合 MoE 辅助损失，修复 mHC 反向规约选择、编译后 packed 序列边界查找、CSA 反向样本局部索引等，并新增独立精度和灵敏度检查框架，系统性提升训练可复现性 [#7697](https://github.com/nvidia/megatron-lm/pull/7697) [#7704](https://github.com/nvidia/megatron-lm/pull/7704) [#7705](https://github.com/nvidia/megatron-lm/pull/7705) [#7706](https://github.com/nvidia/megatron-lm/pull/7706) [#7793](https://github.com/nvidia/megatron-lm/pull/7793)
- **Mixture-of-Kittens (MoK) 后端集成启动**：MoK 作为可选 MoE 后端被引入 ARM64 CI 镜像，为 GB200/GB300 平台的高效 MoE 训练铺路 [#7696](https://github.com/nvidia/megatron-lm/pull/7696)
- **Lite DSA 索引器 top-k 完整工具链（进行中）**：一系列 PR 为 Lite 分支引入了 FP8/MXFP4 量化、top-k 选择引擎、插件加载和 CP 绑定，显著提升 DSA 推理效率并降低显存占用 [#7863](https://github.com/nvidia/megatron-lm/pull/7863) [#7864](https://github.com/nvidia/megatron-lm/pull/7864) [#7865](https://github.com/nvidia/megatron-lm/pull/7865) [#7866](https://github.com/nvidia/megatron-lm/pull/7866) [#7869](https://github.com/nvidia/megatron-lm/pull/7869) [#7870](https://github.com/nvidia/megatron-lm/pull/7870)
