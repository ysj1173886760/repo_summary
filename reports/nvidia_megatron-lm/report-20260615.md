# Pull Request Digest for nvidia/megatron-lm (20260608-20260615)

本周趋势核心为**异构 MIMO 训练流程全面贯通与 DeepSeek 模型大规模适配**，伴随大量分布式稳定性修复与 Multi-Token Prediction（MTP）能力深化；共 118 个 PR，主要活跃领域为：1）异构 MIMO 训练框架 2）优化器与分布式训练稳定性 3）DeepSeek 架构集成 4）MTP 训练能力 5）推理服务与动态批处理 6）注意力变体与内核。

### 1. 异构 MIMO 训练 (Multi-Module Multi-Grid)
- [PR#5260]：引入 `HyperCommGrid` 与异构分布式初始化，支持视觉编码器与语言模型在不相交网格上训练。
- [PR#5285]：添加每模块随机数种子与角色感知的 DDP 包装，使 MIMO 能运行于标准 `train_step`。
- [PR#5287]：基于角色选择数据迭代器，配合 `HeteroTopology`。
- [PR#5286]：实现双梯度最终化及视觉梯度修正，解决非协同布局下的 DP 参与度问题。
- [PR#5234]：桥接通信器跨网格 P2P 路由到专用进程组，避免使用 world 组。

### 2. 优化器与分布式训练稳定性
- [PR#5339] [PR#5219] [PR#5257]：修复单 GPU / `dp_cp_size==1` 时 `LayerWiseDistributedOptimizer` 因 `dp_cp_params_list` 为 `None` 导数的 `TypeError`。
- [PR#5334]：修复 NVFP4 混合精度下 `torch_dist` 检查点保存的优化器状态分片越界。
- [PR#5255]：消除分布式优化器初始化及 `dp_zero` 路径中 O(DP-world-size) 的 CPU 开销。
- [PR#5331]：`MimoOptimizer.step()` 全球做 `MIN` 规约 `update_success` 标志，避免跨网格学习率调度不同步。
- [PR#5321] [PR#5320]：新兴优化器依赖升到 v0.3.0。
- [PR#5238]：将 `OptimizerConfigOverrideProvider` 从 mbridge 移植入 Megatron。

### 3. DeepSeek 架构与模型集成
- [PR#5254]：引入 DeepSeek 的 DualPipe / DualPipeV 双向流水线调度（源自 deepseek-ai/DualPipe），实现前后向计算-通信全覆盖。
- [PR#5261] [PR#5266]：新增 DeepSeek-V4 Flash MoE 训练配方与性能摘要。
- [PR#5308]：在 FP8 训练中保持 DeepSeek V4 的 CSA compressor 和 indexer 为高精度，避免误量化。
- [PR#5230]：开放用户可配置的 DeepEP `FusedA2A` 参数 (`chunk_size`, `num_sms`)。

### 4. Multi-Token Prediction（MTP）训练
- [PR#5340]：新增 MTP 隐藏状态混合、logit 级 KD 及可选骨干冻结，用于 Nemotron 3 Ultra。
- [PR#5329]：支持 `mtp_layer_split`，将 MTP 层分布到多个 PP rank 而非局限于最后一个 rank。
- [PR#5318]：拆分 MTP 输出投影和损失计算到多个流水线阶段，均衡负载减少气泡。
- [PR#5223]：将 `mtp_detach_heads` 配置统一到主线，消除 `mtp_isolated_loss` 分支。

### 5. 推理服务与动态批处理
- [PR#5326]：高级推理 API 默认启用 `use_coordinator=True`（协调器模式）。
- [PR#5303]：异步动态解码调度第一步：拆分请求生命周期处理为 `prepare`/`bookkeep`，新增 `--inference-dynamic-batching-async-scheduling` 标志。
- [PR#5249]：添加滑动窗口注意力、sink 注意力和动态 YaRN/RoPE 支持到动态推理。
- [PR#5274]：重构 Mamba 动态推理为通用 SSM 接口。
- [PR#5336]：实验性 MiniMax 稀疏注意力（MSA）后端，实现块稀疏注意力。

### 6. 注意力变体与内核优化
- [PR#5338]：修复 `_reduce` 中非连续张量导致 all-reduce 结果被丢弃的静默正确性问题。
- [PR#5294]：为 Qwen3.5-VL 实现融合 mRoPE 内核（`fused_mrope.py`）。
- [PR#5310]：支持融合 MLA QKV 检查点重载。
- [PR#5243]-[PR#5247]（拆分自 #3674）：DSA（Direct Self-Attention）系列改进，包括修复 THD RoPE 在 CP 下的行为、重构 absorbed MLA、启用 DSA CP/THD 钩子等。
- [PR#5270]：修复 `flash_decode=True` 时静态推理引擎的数值问题。

### 7. CI/基础设施与稳定性
- [PR#5316]：统一遗留测试作用域命名为 L-tier 词汇。
- [PR#5280] [PR#5240] [PR#5241] [PR#5253]：修复 T5 数据加载器卡死、BERT 交织 PP P2P 死锁、GRPO CUDA 图内存回归等 CI 间歇性挂起问题。
- [PR#5275] [PR#5305] [PR#5278]：限制测试启动重试、允许合并队列 DCO 检查、添加贡献指南 DCO 要求。
- [PR#5235]：Slack 轮值失败通知机制。

### 8. 框架基础与 Megatron Lite
- [PR#5290] [PR#5292]：Megatron Lite 实验性轻量骨架和并行原语（TP/EP/PP/CP/SP），提供本地注册和模型注册 API。
- [PR#5259] [PR#5250] [PR#5328] [PR#5251]：将 `pg_collection` 注入训练循环各处（reductions、DDP bucket sizing、DDP wrap），使非 `parallel_state` 调用方能复用标准路径。
- [PR#5333]：将 `p2p_communicator` 和 `schedule_pg_collection` 传递到 `train_step` 及调度器，支持跨网格 MIMO 调度。

### 9. 强化学习与环境
- [PR#5341] [PR#5306]：修复多环境 RL 的 `num_groups` 处理，添加 rollout 提交与消费粒度控制。
- [PR#5312]：支持非 Gym 多轮环境。

### 10. 数据与训练辅助
- [PR#5298]：添加文档间注意力掩码（`inter_document_masking`），用 `cu_seqlens` 限制注意力范围。
- [PR#5311]：更新 SFT 数据集与损失计算。
- [PR#5220]：MoE 路由追踪 `RouterTracer`，输出 JSONL 分析路由负载与专家激活频率。

整体上，Megatron-LM 正快速向异构多模态、多网格训练框架演进，同时深度整合 DeepSeek 方案并大规模修补单 GPU、动态批处理等路径的稳定性。
