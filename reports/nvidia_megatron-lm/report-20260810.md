# Pull Request Digest for nvidia/megatron-lm (20260803-20260810)

本周这161个PR聚焦于**分布式训练框架MFSDP V2的生产级完善、Muon优化器在GTP场景下的复杂适配、以及HybridModel架构的显式声明与迁移**。最活跃的领域为：  
1. MFSDP V2功能增强与稳定性修复  
2. Muon优化器分布式扩展与低精度加速  
3. HybridModel显式架构定义与迁移  
4. MoE推理/训练性能调优  
5. 分布式并行策略细化（GTP, CP, SP）  
6. CI/DevOps与依赖稳定性  

---

### 1. 分布式训练与MFSDP
- [PR #6336](https://github.com/NVIDIA/Megatron-LM/pull/6336) 修复MFSDP V2 BF16计算权重在优化器步后未能刷新的问题，并将测试步数扩展到10步以捕获此类回归。
- [PR #6359](https://github.com/NVIDIA/Megatron-LM/pull/6359) 通过显式`phase`属性严格校验FSDP模块的状态转换（RESTING/FORWARD/BACKWARD），并分离激活重计算的检测逻辑。
- [PR #6323](https://github.com/NVIDIA/Megatron-LM/pull/6323) 支持在MFSDP中检测重入式激活重计算（reentrant recomputation），抑制预取和重新分片，适配`CheckpointFunction`。
- [PR #6230](https://github.com/NVIDIA/Megatron-LM/pull/6230) 消除MFSDP对模块图的强反向引用，避免删除分片模型后CUDA持久存储泄漏。
- [PR #6224](https://github.com/NVIDIA/Megatron-LM/pull/6224) 在reduce-scatter流上延迟物理化主梯度缓冲区，改善内存分配时机。
- [PR #6228](https://github.com/NVIDIA/Megatron-LM/pull/6228) 修复MFSDP V2与TE单组MoE权重（`GroupedTensor`）的兼容问题，使专家权重可正常训练。
- [PR #6316](https://github.com/NVIDIA/Megatron-LM/pull/6316) 将FSDP持久通信池从硬编码双缓冲泛化为可配置`fsdp_buffer_count`，支持1F1B重叠。
- [PR #6317](https://github.com/NVIDIA/Megatron-LM/pull/6317)/[PR #6318](https://github.com/NVIDIA/Megatron-LM/pull/6318) 使手动NCCL用户缓冲区注册确定性化，并支持将注册范围限定为密集内部AllGather，隔离专家与密集内存分配。
- [PR #6214](https://github.com/NVIDIA/Megatron-LM/pull/6214)/[PR #6215](https://github.com/NVIDIA/Megatron-LM/pull/6215) 从参数布局分析派生MFSDP V2 checkpoint chunk元数据，并实现`FullyShardedOptimizer`的DCP存盘/加载。
- [PR #6353](https://github.com/NVIDIA/Megatron-LM/pull/6353)、[PR #6369](https://github.com/NVIDIA/Megatron-LM/pull/6369) 修复checkpoint测试setup并解耦`FsdpContext`与`FsdpModule`的混合。
- [PR #6271](https://github.com/NVIDIA/Megatron-LM/pull/6271) 修复Megatron-FSDP下fused MLA和MTP的checkpoint保存/加载问题。
- [PR #6303](https://github.com/NVIDIA/Megatron-LM/pull/6303) 强制`LanguageModule`族要求显式传入`PGCollection`，消除对全局并行状态的依赖。
- [PR #6293](https://github.com/NVIDIA/Megatron-LM/pull/6293) 继续削减`megatron/core`中对全局进程组的读访问（207→155处），迈向独立并行网格。

### 2. 优化器（Muon与分布式）
- [PR #6379](https://github.com/NVIDIA/Megatron-LM/pull/6379) 修复`LayerWiseDistributedOptimizer`对Muon参数的负载均衡策略：不再以元素数`numel`为代理，改为基于Newton-Schulz计算成本，解决GTP下严重的不平衡。
- [PR #6380](https://github.com/NVIDIA/Megatron-LM/pull/6380) 使`TensorParallelMuon`的GTP-remat路径遵循现有`tp_mode`（blockwise/distributed），取代之前的单一全矩阵冗余计算策略。
- [PR #6381](https://github.com/NVIDIA/Megatron-LM/pull/6381) 添加`--muon-use-syrk`标志，在Newton-Schulz内部使用Triton SYRK kernel计算Gram矩阵，减少近一半FLOPs。
- [PR #6326](https://github.com/NVIDIA/Megatron-LM/pull/6326) 支持`--muon-split-qkv-per-head`模式，对每个物理Q/K/V head独立进行Newton-Schulz正交化，重构per-head布局。
- [PR #6342](https://github.com/NVIDIA/Megatron-LM/pull/6342) 修复全部分可重分片优化器状态在桶填充（bucket padding）下的切片错误，避免loss爆炸。
- [PR #6244](https://github.com/NVIDIA/Megatron-LM/pull/6244) 实现分块优化器状态与主权重卸载到CPU，GPU端仅逐块更新，降低峰值显存。
- [PR #6248](https://github.com/NVIDIA/Megatron-LM/pull/6248) 释放量化参数在分布式优化器初始化期间持有的高精度副本，及时调用`torch.cpu.empty_cache()`。
- [PR #6355](https://github.com/NVIDIA/Megatron-LM/pull/6355) 修复CUDA图捕获时梯度阈值检查中的GPU到CPU同步问题。

### 3. 模型架构（HybridModel、MTP、MLA/DSA）
- [PR #6313](https://github.com/NVIDIA/Megatron-LM/pull/6313) 重构Hybrid层以使用per-layer config，使每层可携带专属参数，为未来异构层铺路。
- [PR #6310](https://github.com/NVIDIA/Megatron-LM/pull/6310) 添加HybridModel的Python recipe API、声明式配置和启动器支持。
- [PR #6295](https://github.com/NVIDIA/Megatron-LM/pull/6295)、[PR #6297](https://github.com/NVIDIA/Megatron-LM/pull/6297)、[PR #6299](https://github.com/NVIDIA/Megatron-LM/pull/6299) 系列引入直接混合架构描述符（`HybridLayerSpec`等），并集成到训练、PP/VPP拆分和checkpoint中。
- [PR #6315](https://github.com/NVIDIA/Megatron-LM/pull/6315) 将Qwen3.5-VL语言解码器从`GPTModel`迁移到`HybridModel`，显式表达GatedDeltaNet/全注意力混合栈。
- [PR #6241](https://github.com/NVIDIA/Megatron-LM/pull/6241) 添加`mla_native_v_head_dim`配置，使MLA在thd路径上使用原生V维度而非填充，节省计算。
- [PR #6343](https://github.com/NVIDIA/Megatron-LM/pull/6343) 融合MLA RoPE打包、DSA索引器投影，用单一Triton kernel实现前向/反向，针对B200提升。
- [PR #6213](https://github.com/NVIDIA/Megatron-LM/pull/6213) 融合Q上投影GEMM、RoPE与MXFP8量化，提升训练性能。
- [PR #6206](https://github.com/NVIDIA/Megatron-LM/pull/6206) 使融合cuDNN DSA索引器可达CP1，并增加NVTX测量点。
- [PR #6340](https://github.com/NVIDIA/Megatron-LM/pull/6340) 修复`fused_mla_rope_kv_split`在`v_dim==0`时的形状推断和梯度全零Padding错误。
- [PR #6246](https://github.com/NVIDIA/Megatron-LM/pull/6246) 引入MTP序列滚动上下文，在连续打包CP下预取后续行，避免per-depth P2P。
- [PR #6205](https://github.com/NVIDIA/Megatron-LM/pull/6205) 修复MTP在上下文并行下因使用未填充序列边界而导致损失计算错误的bug。

### 4. MoE与推理优化
- [PR #6328](https://github.com/NVIDIA/Megatron-LM/pull/6328) 动态设定MoE激活kernel网格大小为token行数，将`_silu_mul_bounded_kernel`从22%的SM占用提升至全占用，解码吞吐提升3.79%。
- [PR #6334](https://github.com/NVIDIA/Megatron-LM/pull/6334) 改小MoE token计数kernel的`BLOCK_SIZE`，大幅降低解码形状下的串行化开销（从381.8µs降至更低）。
- [PR #6274](https://github.com/NVIDIA/Megatron-LM/pull/6274) 引入MoonEP分发器，通过GPU在线调度热专家复制与权重预取，消除EP负载不均衡。
- [PR #6229](https://github.com/NVIDIA/Megatron-LM/pull/6229) 为NCCL EP灵活分发器添加eager模式和溢出处理，支持CUDA图。
- [PR #6311](https://github.com/NVIDIA/Megatron-LM/pull/6311) 将EP A2A重叠的重计算粒度从模型块改为层粒度，减少前向向后间隙的激活驻留。
- [PR #6208](https://github.com/NVIDIA/Megatron-LM/pull/6208) 添加SeqTopK序列级路由模式，将专家预算分配到sequence级别。
- [PR #6329](https://github.com/NVIDIA/Megatron-LM/pull/6329) [Draft] 使前缀缓存块只读，防止请求重写。
- [PR #6222](https://github.com/NVIDIA/Megatron-LM/pull/6222) 添加基于NIXL/NCCL的prefill-to-decode KV-cache分离式移交（disaggregated handoff）。
- [PR #6223](https://github.com/NVIDIA/Megatron-LM/pull/6223) 将推理tokenizer分离到独立线程并随DP规模扩展前端副本。
- [PR #6260](https://github.com/NVIDIA/Megatron-LM/pull/6260) 为动态批推理服务器添加VLM端到端支持（视觉编码器、embedding注入、掩码）。
- [PR #6218](https://github.com/NVIDIA/Megatron-LM/pull/6218) 修复前缀缓存在重复哈希情况下的陈旧映射和Mamba槽位失效问题。
- [PR #6356](https://github.com/NVIDIA/Megatron-LM/pull/6356)/[PR #6351](https://github.com/NVIDIA/Megatron-LM/pull/6351) 使prefill分块不依赖inference context，并cherry-pick分布式checkpoint相关修改。
