# Pull Request Digest for nvidia/megatron-lm (20260516-20260523)

**本周关键趋势**：DeepSeek-V4 全栈支持（含混合注意力、Hash MoE、MTP+mHC）与 MLA 动态推理重构成为两大并行主线，共 111 个 PR，活跃领域集中在 ① 模型架构（DeepSeek-V4/Hybrid/mHC）、② 推理引擎（MLA/CUDA Graph）、③ 分布式训练（FSDP/EP-overlap/1F1B）、④ CI/测试基础设施。

### 1. 新模型架构与组件
- **DeepSeek-V4 系列**：密集提交了针对 DeepSeek-V4 的全栈支持。
    - [PR#4867](https://github.com/NVIDIA/Megatron-LM/pull/4867) 添加了混合注意力机制（CSA + HCA），复用部分 DSA 参数。
    - [PR#4866](https://github.com/NVIDIA/Megatron-LM/pull/4866) 实现了 Hash MoE 与 SwiGLU clamp 支持。
    - [PR#4869](https://github.com/NVIDIA/Megatron-LM/pull/4869) 将 MTP 与 mHC 及新的 mHC 契约集成。
    - [PR#4894](https://github.com/NVIDIA/Megatron-LM/pull/4894) 与 [PR#4897](https://github.com/NVIDIA/Megatron-LM/pull/4897) 分别集成了针对 DSv4 混合注意力和 DSA 的 cuDNN 融合内核。
- **mHC（多头超连接）**：通过拆分 PR 逐步落地。
    - [PR#4945](https://github.com/NVIDIA/Megatron-LM/pull/4945) 完成 GPT 模型接线。
    - [PR#4946](https://github.com/NVIDIA/Megatron-LM/pull/4946) 添加流水线并行支持。
    - [PR#4947](https://github.com/NVIDIA/Megatron-LM/pull/4947) 引入融合 cuTile 内核。
    - [PR#4949](https://github.com/NVIDIA/Megatron-LM/pull/4949) 为 HybridModel 增加 mHC 支持。
- **Hybrid 架构增强**：
    - [PR#4942](https://github.com/NVIDIA/Megatron-LM/pull/4942) 为 HybridStack 引入分组语法、检查点兼容及 EP-overlap 支持。
    - [PR#4848](https://github.com/NVIDIA/Megatron-LM/pull/4848) 添加 `use_head_wise_attn_gate` 特性，支持 per-head 标量门控。
- **其他模型修复**：
    - [PR#4899](https://github.com/NVIDIA/Megatron-LM/pull/4899) 将 Mamba 卷积参数重构为直接 mixer 参数，修复 FSDP 兼容性。
    - [PR#4938](https://github.com/NVIDIA/Megatron-LM/pull/4938) 修复 MimoModel 中多模态 RoPE 的 `position_ids` 传递问题。

### 2. 推理引擎优化
- **MLA 动态推理重构**：3 部分系列 PR 替换了 MLA 推理后端。
    - [PR#4918](https://github.com/NVIDIA/Megatron-LM/pull/4918) 放宽了 FlashMLA 的 block-size 限制。
    - [PR#4919](https://github.com/NVIDIA/Megatron-LM/pull/4919) 将 MLA 调度切换至 FlashInfer 的 `BatchMLAPagedAttentionWrapper`。
    - [PR#4920](https://github.com/NVIDIA/Megatron-LM/pull/4920) 添加了 MLA 动态推理的 logits 匹配测试。
- **CUDA Graph 与调度**：
    - [PR#4950](https://github.com/NVIDIA/Megatron-LM/pull/4950) 为 MTP 推理添加全模型 CUDA Graph 支持。
    - [PR#4870](https://github.com/NVIDIA/Megatron-LM/pull/4870) 在 prefill 调度器中引入 CUDA Graph 感知的准入门控。
    - [PR#4922](https://github.com/NVIDIA/Megatron-LM/pull/4922) 防止填充 token 被路由到专家，减少不必要的 CUDA Graph 录制。
- **静态推理清理**：[PR#4880](https://github.com/NVIDIA/Megatron-LM/pull/4880) 移除了用户侧静态推理入口，统一至 `DynamicInferenceEngine`。

### 3. 分布式训练与性能
- **FSDP 与 EP-overlap**：
    - [PR#4941](https://github.com/NVIDIA/Megatron-LM/pull/4941) 重构通用 combined-1F1B 调度计划基类。
    - [PR#4943](https://github.com/NVIDIA/Megatron-LM/pull/4943) 为 HybridStack 添加 FSDP 支持及 EP-overlap 调度。
    - [PR#4887](https://github.com/NVIDIA/Megatron-LM/pull/4887) 修复使用 OP Fuser 时 FSDP EP-overlap 遗漏预反向参数收集的问题。
    - [PR#4891](https://github.com/NVIDIA/Megatron-LM/pull/4891) 修复混合 M-FSDP 的数值问题，正确保留 `DTensor` 梯度元数据。
    - [PR#4849](https://github.com/NVIDIA/Megatron-LM/pull/4849) 引入 Megatron-FSDP2，提供 `fully_shard()` API。
- **内存与计算优化**：
    - [PR#4940](https://github.com/NVIDIA/Megatron-LM/pull/4940) 在 dispatch 时排空前序 reduce-scatter，降低峰值内存。
    - [PR#4909](https://github.com/NVIDIA/Megatron-LM/pull/4909) 在 combined backward 后立即释放 loss 节点输入，减少显存占用。
    - [PR#4913](https://github.com/NVIDIA/Megatron-LM/pull/4913) 将 GDN 前向中的逐序列 AlltoAll 融合为统一操作。
    - [PR#4921](https://github.com/NVIDIA/Megatron-LM/pull/4921) 添加选项跳过最终完整重计算单元，保留前向激活。
- **优化器修复**：
    - [PR#4889](https://github.com/NVIDIA/Megatron-LM/pull/4889) 修复层级分布式优化器在 MXFP8 wgrad 下的对齐失败问题。
    - [PR#4895](https://github.com/NVIDIA/Megatron-LM/pull/4895) 修复多优化器（如 Muon+Adam）下权重冗余安装问题。
