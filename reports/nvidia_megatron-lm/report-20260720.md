# Pull Request Digest for nvidia/megatron-lm (20260713-20260720)

**本周关键要点**：MFSDP v2 与 MCore 的集成进入加速阶段，同时推理管线针对 DeepSeek-V3 MLA CUDA Graph 捕获进行多项关键补强，共 96 个 PR，顶级活跃领域为 1) MFSDP v2 / Megatron-FSDP 集成与稳定性，2) 推理性能优化（MLA、CUDA Graph、Mamba），3) 训练正确性与数值修复，4) CI/测试健壮性，5) 新模型架构支持。

---

### 1. MFSDP v2 与 Megatron-FSDP 框架集成
- **核心集成与优化器适配**：引入实验性 `FullyShardedDataParallelV2` 适配器，通过 `USE_MFSDP_V2` 切换 [PR#5774](https://github.com/NVIDIA/Megatron-LM/pull/5774)；新增基于 `FullyShardedOptimizer` 的优化器集成路线，与 `DistributedOptimizer` 方案并行评估 [PR#5865](https://github.com/NVIDIA/Megatron-LM/pull/5865)；初始 MCore 集成使 FSDP 单元包装、参数与梯度分片通过 MCore `DistributedOptimizer` 路由 [PR#5813](https://github.com/NVIDIA/Megatron-LM/pull/5813)。
- **通信重叠与性能**：支持双通信组重叠——前向 all-gather 与反向 reduce-scatter 使用独立 NCCL 通信器 [PR#5772](https://github.com/NVIDIA/Megatron-LM/pull/5772)；引入 planned bucket allocation 以在 Megatron-FSDP 下启用部分 CUDA Graph [PR#5800](https://github.com/NVIDIA/Megatron-LM/pull/5800)。
- **数值与生命周期修复**：修复 `DTensor` 参数范数在 FP32 计算时的精度问题 [PR#5878](https://github.com/NVIDIA/Megatron-LM/pull/5878)；过滤重复梯度以修复 FSDP zero-count 路径 [PR#5879](https://github.com/NVIDIA/Megatron-LM/pull/5879)；添加参数/梯度 L2 范数日志用于收敛诊断 [PR#5880](https://github.com/NVIDIA/Megatron-LM/pull/5880)；通过参数生命周期注册表防止模块重建后状态丢失 [PR#5836](https://github.com/NVIDIA/Megatron-LM/pull/5836)；修复根模块前向 Hook 派发错误 [PR#5808](https://github.com/NVIDIA/Megatron-LM/pull/5808)；避免额外的权重同步 memcpy [PR#5834](https://github.com/NVIDIA/Megatron-LM/pull/5834)。
- **测试与对称内存**：补充对称内存路径的覆盖测试，验证 zero-CTA copy-engine 与重叠加 [PR#5859](https://github.com/NVIDIA/Megatron-LM/pull/5859)、[PR#5858](https://github.com/NVIDIA/Megatron-LM/pull/5858)；通过扩大模型尺寸（dim=16384）稳定 overlap 测试 [PR#5846](https://github.com/NVIDIA/Megatron-LM/pull/5846)；清理 MFSDP v2 术语 [PR#5793](https://github.com/NVIDIA/Megatron-LM/pull/5793)；NCCL 环境变量迁移至 `conftest` [PR#5794](https://github.com/NVIDIA/Megatron-LM/pull/5794)、[PR#5826](https://github.com/NVIDIA/Megatron-LM/pull/5826)。

### 2. 推理优化
- **MLA / CUDA Graph**：为 DeepSeek-V3 MLA 添加 Triton KV-cache 追加内核，并在 CUDA Graph 捕获期间智能调度 [PR#5856](https://github.com/NVIDIA/Megatron-LM/pull/5856)；A100 上采用捕获感知的 Triton 调度，避免急切执行时的回退 [PR#5825](https://github.com/NVIDIA/Megatron-LM/pull/5825)。
- **CUDA Graph 与采样**：FA4 推理设置 `num_splits=0` 启用自动调谐 [PR#5804](https://github.com/NVIDIA/Megatron-LM/pull/5804)；默认 CUDA Graph 覆盖提升至 512 token [PR#5797](https://github.com/NVIDIA/Megatron-LM/pull/5797)；禁止 FlashInfer 采样与 CUDA Graph 混用以避免 RNG 状态漂移 [PR#5791](https://github.com/NVIDIA/Megatron-LM/pull/5791)。
- **Mamba 与推测解码**：Mamba 前缀缓存状态提取的 Triton 内核优化，以及临时空间缩小一个数量级 [PR#5866](https://github.com/NVIDIA/Megatron-LM/pull/5866)、[PR#5863](https://github.com/NVIDIA/Megatron-LM/pull/5863)；实现精确且内存高效的 Mamba 推测解码（利用 rank-1 状态更新）[PR#5803](https://github.com/NVIDIA/Megatron-LM/pull/5803)。
- **前缀缓存与分离 KV**：添加前缀缓存生命周期钩子 [PR#5860](https://github.com/NVIDIA/Megatron-LM/pull/5860)；实现 NCCL 和 NIXL 的分离式 KV 传输后端 [PR#5861](https://github.com/NVIDIA/Megatron-LM/pull/5861)；LRU 驱逐策略改为只驱逐叶子块 [PR#5822](https://github.com/NVIDIA/Megatron-LM/pull/5822)。

### 3. 训练正确性与数值修复

- **状态与检查点**：修复混合 dtype 参数组的分布式优化器状态保存/加载 [PR#5835](https://github.com/NVIDIA/Megatron-LM/pull/5835)；修复 tools/checkpoint MoE 转换中专家权重静默丢弃 [PR#5845](https://github.com/NVIDIA/Megatron-LM/pull/5845)；恢复后跳过冗余最终检查点 [PR#5870](https://github.com/NVIDIA/Megatron-LM/pull/5870)；GPT 到 Hybrid 模型的运行时检查点翻译 [PR#5792](https://github.com/NVIDIA/Megatron-LM/pull/5792)；DeepSeek-V4 保留 DSA 反向残差以收紧融合反向容差 [PR#5773](https://github.com/NVIDIA/Megatron-LM/pull/5773)；修复 DSv4 零 loss 索引器梯度问题 [PR#5809](https://github.com/NVIDIA/Megatron-LM/pull/5809)。
- **CUDA Graph 健壮性**：固定 micro-batch 下支持 THD 全迭代 CUDA Graph [PR#5807](https://github.com/NVIDIA/Megatron-LM/pull/5807)、[PR#5783](https://github.com/NVIDIA/Megatron-LM/pull/5783)；解决全迭代 CUDA Graph 数据迭代器损坏 [PR#5819](https://github.com/NVIDIA/Megatron-LM/pull/5819)；支持 mHC 选择性重计算下的 TE 部分 CUDA Graph [PR#5841](https://github.com/NVIDIA/Megatron-LM/pull/5841)。
