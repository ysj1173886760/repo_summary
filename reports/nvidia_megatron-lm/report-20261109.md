# Pull Request Digest for nvidia/megatron-lm (20261102-20261109)

**PR 统计**：共 286 个（已合并 36 · 进行中 58 · 草稿 165 · 已关闭 27）

## 本周概览
本周最显著的变化是 `parallel_state` 弃用重构全面展开，数十个 PR 将模型、优化器、检查点等核心组件从全局并行状态迁移到显式 `ProcessGroupCollection`，为多模型网格和 RL 场景奠定基础。推理路径集中修复了大量 P1/P2 正确性与稳定性问题，涵盖动态批处理、MLA、MoE 和 SSM。Batch-invariant 训练模式修复了梯度丢失等关键缺陷，并移除了 DeepGEMM 依赖以简化使用。

**最活跃领域**：1. 并行状态弃用与进程组重构；2. 推理修复与优化；3. Batch-invariant 训练；4. MFSDP 与数据并行；5. MoE 与混合模型

## 值得关注
- **并行状态弃用（BC-breaking）**：`parallel_state` 全局访问器被标记为弃用，将在 0.23 版本移除。所有外部代码需迁移到显式进程组传递。 [#8907](https://github.com/nvidia/megatron-lm/pull/8907) [#8909](https://github.com/nvidia/megatron-lm/pull/8909)
- **过早合并回退**：[#9101](https://github.com/nvidia/megatron-lm/pull/9101) 回退了四个因批处理选择器错误而提前合并的 PR（#8520, #8787, #8548, #8261），这些 PR 已重新开放为 [#9104](https://github.com/nvidia/megatron-lm/pull/9104)、[#9105](https://github.com/nvidia/megatron-lm/pull/9105)、[#9106](https://github.com/nvidia/megatron-lm/pull/9106)、[#9107](https://github.com/nvidia/megatron-lm/pull/9107)，需重新审查。
- **DeepGEMM 移除**：[#8923](https://github.com/nvidia/megatron-lm/pull/8923) 从 batch-invariant 模式中移除了 DeepGEMM 后端，现有配置将收到弃用警告并自动映射到 `te_native`，简化了依赖。
- **配置容器重构（进行中）**：[#9031](https://github.com/nvidia/megatron-lm/pull/9031) 正在分离配置容器，可能影响检查点格式，需关注后续进展。
