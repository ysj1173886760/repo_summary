# Pull Request Digest for nvidia/megatron-lm (20260810-20260817)

本周核心趋势是推理引擎在 decode 路径上进行了密集的 kernel 融合与内存优化，同时 MFSDP v2 的训练内存管理持续深化，DeepSeek-V4 混合模型架构的集成工作大规模展开。共 178 个 PR，最活跃的领域为：① 推理性能优化（decode 路径、MoE 调度、注意力融合） ② MFSDP v2 训练内存与通信优化 ③ GTP 梯度并行修复与增强 ④ 混合模型架构支持（DeepSeek-V4、Ling-V3 等） ⑤ MoE 专家并行与路由优化 ⑥ 训练指标与可观测性 ⑦ CI/CD 与基础设施改进。
