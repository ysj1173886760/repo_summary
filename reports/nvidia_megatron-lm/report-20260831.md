# Pull Request Digest for nvidia/megatron-lm (20260824-20260831)

**PR 统计**：共 178 个（已合并 76 · 进行中 36 · 草稿 34 · 已关闭 32）

## 本周概览
本周合并了多项关键架构特性与稳定性修复：ShortcutMoE 实现注意力与 MoE 重叠、推理正式支持视频模态、DeepSeek-V3 引入 NVFP4 训练支持，同时确定性训练、上下文并行和 FSDP 内存管理方面有重要修正。社区贡献活跃，多个 PR 改进了动态 CP、MoE 性能和分布式优化器行为。

**最活跃领域**：1. MoE 与专家并行优化；2. 上下文并行与动态调度；3. 推理与多模态支持；4. FSDP 与内存管理；5. 确定性训练与 Bug 修复

## 重点进展
- **ShortcutMoE 实现注意力与 MoE 重叠**：新增 ShortcutMoE 架构，将注意力计算置于侧流并与 All-to-All 专家通信重叠，实现 82%–95% 重叠效率，同时添加额外归一化防止精度下降 [#6959](https://github.com/nvidia/megatron-lm/pull/6959)
- **推理支持视频模态**：扩展 Megatron-Inference 以支持视频输入，可通过原始字节或预处理张量传入，并支持多模态嵌入缓存的引擎暂停重计算 [#6809](https://github.com/nvidia/megatron-lm/pull/6809)
- **DeepSeek-V3 NVFP4 训练支持**：添加 NVFP4 低精度训练，包括 1F1B EP 重叠调度、FP4 上下文选择及 MTP 层跳过 FP4 等，集成到训练流程 [#6841](https://github.com/nvidia/megatron-lm/pull/6841)
- **确定性训练关键修复**：在 `--deterministic-mode` 下固定 Triton autotune 缓存目录，避免不同 rank 选择不同 kernel 配置；分离 MoE aux-loss 融合标志，仅对破坏确定性的操作进行守卫 [#6966](https://github.com/nvidia/megatron-lm/pull/6966) [#6967](https://github.com/nvidia/megatron-lm/pull/6967)
- **MFSDP v2 暴露 HSDP 和 HFSDP**：通过 MFSDP v2 适配器支持混合分片，密集参数可使用外层 DP 分片，专家参数保持 ZeRO-3，提升大规模训练效率 [#6873](https://github.com/nvidia/megatron-lm/pull/6873)
