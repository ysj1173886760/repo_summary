# Pull Request Digest for nvidia/megatron-lm (20260907-20260914)

本周最具影响力的趋势是 **MFSDP v2 与多模态 SFT 训练能力密集集成，同时 DSA/混合模型训练基础设施显著扩展**；本周共计 **162** 个 PR，最活跃领域依次为：  
1. MFSDP v2 分布式训练与优化器  
2. 多模态/视觉‑语言 SFT 集成  
3. DSA 动态稀疏注意力训练  
4. 混合模型与 DeepSeek‑V4.1 支持  
5. 推理与服务增强  
6. 确定性训练与测试体系  

---

### 核心特性增强  
- **多模态 SFT 完整流水线**：引入 `Energon` 多模态数据管道、`Super` 混合模型 packed 输入支持、视觉‑文本元数据与视觉 CP 处理、会话格式与 tokenizer 工具、LLaVA 式多模态 checkpoint 初始化 [PR#7248] [PR#7249] [PR#7250] [PR#7251] [PR#7253] [PR#7254] [PR#7255]  
- **DSA 训练支持**：添加简化版 DSA（带 GQA）的训练循环、Triton 内核及 autograd [PR#7152] [PR#7156] [PR#7181]；支持 128K 长上下文的 DeepSeek‑V4.1‑Flash 训练 [PR#7285]；wire DSA 索引器进主训练循环，并支持 EP 1F1B overlap 下的 partial CUDA graph [PR#7206]  
- **QSA 参考实现**：引入 QSA 索引器、稀疏 KL loss 和 Sparse‑GQA 参考 [PR#7234]  
- **Engram 可训练 n‑gram 记忆**：在 GPT/HybridModel 中集成 hash‑ngram 嵌入表，含 EP 分片与独立 LR 调度 [PR#7231] [PR#7178]  
- **HybridModel 增强**：支持 GPT 权重加载到 grouped HybridModel [PR#7192]；添加 first‑class 配置列表 [PR#7153]；共享 RoPE 模块以节省内存 [PR#7111]

- **分布式优化器**：
