# Pull Request Digest for nvidia/megatron-lm (20260921-20260928)

**PR 统计**：共 112 个（已合并 20 · 进行中 42 · 草稿 40 · 已关闭 10）

## 本周概览
本周 Megatron-LM 主要围绕 MFSDP v2 的生产化增强、GTP 重计算下的 MTP 通信优化、推理栈稳定性与多模态适配，以及 CI 基础设施提速展开。一批关键修复和基础模块的引入为复杂模型训练和规模化推理铺平了道路。

**最活跃领域**：1. MFSDP v2 训练与通信；2. GTP/MTP 性能与修复；3. Inference 多模态与稳定性；4. CI/测试与构建优化；5. 模型组件与架构演进。

## 重点进展
- **MFSDP v2 支持 MXFP8 计算与参数传输**：适配器接受 MXFP8 权重与量化数据缓冲，自动检测 `MXFP8Tensor` 并启用 FP8 训练，在保持高精度聚合的同时缩小与 TE 的集成差距。 [#7588](https://github.com/nvidia/megatron-lm/pull/7588)
- **GTP 下 MTP output_layer 的 wgrad reduce-scatter 合并**：将每个迭代中因 MTP 重复层和多个 microbatch 导致的多次 reduce-scatter 合并为一次，无额外内存开销，显著降低通信压力。 [#7573](https://github.com/nvidia/megatron-lm/pull/7573)
- **MFSDP 命名与子类复用**：易混淆的 `Flat` 放置策略重命名为 `RowAtomic`，明确行原子分片语义；同时用 `functools.cache` 复用 `Fsdp` 子类，消除重复流创建。 [#7539](https://github.com/nvidia/megatron-lm/pull/7539) [#7612](https://github.com/nvidia/megatron-lm/pull/7612)
- **Inference 关键稳定性与多模态支持**：修复前端副本不安全 `fork` 导致的 scale 级 hang；并添加 Nemotron VL 视觉预处理，对齐 NeMo-RL 训练输入。 [#7556](https://github.com/nvidia/megatron-lm/pull/7556)
- **Streamwise Wide-Residual 连接原语引入**：将宽残差连接（含流式 sigmoid 门控）和结构化算子作为基础模块加入 Core，为复杂架构提供可组合的残差协议。 [#7579](https://github.com/nvidia/megatron-lm/pull/7579) [#7599](https://github.com/nvidia/megatron-lm/pull/7599)

## 值得关注
- **训练配置体系重构**：`ProfilingConfig`、`LoggerConfig`、`RNGConfig` 等通过 [#7568](https://github.com/nvidia/megatron-lm/pull/7568) [#7587](https://github.com/nvidia/megatron-lm/pull/7587) [#7591](https://github.com/nvidia/megatron-lm/pull/7591) 被确立为权威配置，未来可能废弃部分旧 CLI 参数，需关注迁移影响。
- **共享权重梯度同步机制变更**：新的多重性声明和 1F1B 调度器将替换基于 fire-count 的旧同步逻辑，可能影响 tied embeddings 等共享参数的 backward 行为，正在 [#7581](https://github.com/nvidia/megatron-lm/pull/7581) [#7582](https://github.com/nvidia/megatron-lm/pull/7582) 开发。
- **分布式检查点兼容性修复**：因 PyTorch 新引入 `strides` 字段，`TorchDistLoadShardedStrategy` 仅用 `dtype` 创建 placeholder tensor，需确保下游适配 [#7620](https://github.com/nvidia/megatron-lm/pull/7620)。
- **循环数据加载器恢复安全强化**：新增 DP 尺寸与分片模式校验（[#7648](https://github.com/nvidia/megatron-lm/pull/7648)），并探索 DP 无关的排列 epoch 以避免恢复时数据重复/跳过（[#7649](https://github.com/nvidia/megatron-lm/pull/7649)），防范静默数据错误。
- **MoE checkpoint 布局转换修复**：强制专家 FC1 权重连续化，并拒绝不兼容的恢复，防止训练出现 NaN 或收敛问题 [#7606](https://github.com/nvidia/megatron-lm/pull/7606)。
- **MFSDP 清理与类型化异常**：实验性参数组注解清理，并引入 `OptionalDependencyUnavailable` 以规范化可选导入失败检测 [#7636](https://github.com/nvidia/megatron-lm/pull/7636) [#7637](https://github.com/nvidia/megatron-lm/pull/7637)，影响自定义后端。
