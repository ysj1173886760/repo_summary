# Pull Request Digest for nvidia/megatron-lm (20260523-20260530)

# Megatron-LM 技术周报

## 核心要点

本周共提交 **100** 个 PR，最显著的趋势是 **MoE 架构的深度优化与混合并行策略的成熟化**，涵盖从 DeepSeek-v4 支持、HybridEP 调度器切换到 MoE 辅助损失梯度修复等多个层面。活跃领域集中在：① MoE 训练与调度器优化 ② 功能测试与 CI 基础设施 ③ 混合模型架构（Hybrid/MIMO） ④ 优化器与参数管理 ⑤ 社区缺陷修复。

---

## 1. MoE 架构与调度器优化

- **HybridEP 调度器切换**：[PR#5039] 将 H100 DeepSeek-v3 周测从 DeepEP 切换至 HybridEP，解决 PyTorch 26.04 下 DeepEP 的 CPU 超时问题。
- **MoE 辅助损失梯度修复**：[PR#5047] 修复 `aux_loss`/`z_loss` 在 TP>1 时的梯度缩放问题，通过乘以 `tp_cp_group.size()` 保证 TP/CP 无关性；[PR#5007] 将相同修复移植至 `main` 分支，并对齐 DP 平均语义。
- **序列级辅助损失兼容性**：[PR#5052] 适配 TE >= 2.16 的 `fused_moe_aux_loss` 内核契约，修复 `probs.shape[-1] == num_experts` 断言。
- **路由映射构建优化**：[PR#4964] 在非融合路由器路径中直接构建布尔张量路由映射，修复 #4965。
- **DeepSeek-v4 支持**：[PR#5042] 启用 DeepSeek-v4 `hybrid_model`；[PR#5011] 添加 Packed Sequence (THD) 支持；[PR#5018] 修复 dense loss 和 RoPE 类型；[PR#4977] 修复 CP 注意力下的全局 RoPE 长度。
- **MoE 调度器 THD 支持**：[PR#5008] 为 `main` 分支添加 DeepEP/HybridEP 的 THD 序列打包调度器支持，对应 dev 分支 [PR#4816]。
- **共享专家激活值解耦**：[PR#4968] 引入 `activation_func_clamp_value_shared_expert` 配置，独立控制共享专家的 SwiGLU 激活值裁剪。
- **MoE 路由损失语义对齐**：[PR#5007] 对齐 `global_aux_loss` 与 `aux_loss` 的反向缩放，补偿 DP 平均。

## 2. 功能测试与 CI 基础设施

- **Golden 值更新与测试修复**：[PR#5069] 重新录制 `nemotron3_super_release_gb200_sm` 的 golden 值；[PR#4995] 更新 T5 功能测试的 golden 值；[PR#5068] 修复推理 API 测试失败。
- **迭代时间窗口优化**：[PR#5010] 将迭代时间比较限制在稳态窗口 `range(30, 46)`，避免预热步骤污染中位数；[PR#5023] 使窗口自适应，兼容短测试。
- **测试重新启用**：[PR#4984] 重新启用 GB200 1-node MoE 测试；[PR#4985] 重新启用 `test_pp2_create_cudagraphs_first_stage`；[PR#4978] 重新启用 paged-stashing MoE 测试，添加 SM100 硬件门控。
- **CI 配置修复**：[PR#5072] 添加 `PYTHONUNBUFFERED=1` 解决 JET workload 输出缓冲；[PR#5038] 修复 `install_python_deps` 覆盖容器 torch/transformers 的问题；[PR#4973] 移除功能测试的 MASTER_PORT 偏移。
- **测试组织**：[PR#5063] 将 MIMO 单元测试移至 `tests/unit_tests/models/mimo/`；[PR#4981] 为 `BlendedDataset` 添加测试覆盖。
- **发布测试修复**：[PR#5040] 跳过中间恢复窗口的 golden 值比较；[PR#5022] 固定 15B GB200 配置的 `eval-global-batch-size`。

## 3. 混合模型架构（Hybrid/MIMO）

- **HybridModel 配置食谱**：[PR#5031] 支持 `HybridModelConfig` 食谱加载；[PR#5030] 添加食谱加载、验证和 lowering 路径。
- **MIMO 桥接扇出**：[PR#5062] 支持可变模态 token 的非共位桥接扇出，通过 `_mimo_bridge_split_sizes` 注释编码器输出。
- **GatedDeltaNet2 模块**：[PR#4956] 添加 `GatedDeltaNet2` 核心模块及混合堆栈布线。
- **MTP 修复**：[PR#5034] 标记 MTP 阶段的 `word_embeddings` 为 `is_embedding_or_output_parameter`；[PR#4983] 修复 MTP 重计算路径中 `padding_mask` 转发；[PR#4966] 修复 `_checkpointed_forward` 缺失 `padding_mask` 参数。
- **DeepSeek-v4 混合注意力**：[PR#5011] 添加 Packed Sequence 支持；[PR#4977] 修复 CP 注意力 RoPE 生成。

## 4. 优化器与参数管理

- **CPU 卸载修复**：[PR#5071] 修复 `HybridDeviceOptimizer` 在加载不含优化器状态的检查点时，内部参数副本保留随机初始化值的问题。
- **参数组标识**：[PR#5060] 使用 `param_group_name` 作为规范标识符，解决 µP 下多组共享 `wd_mult`/`lr_mult` 但 LR 调度不同的问题。
- **Muon 优化器扩展**：[PR#5015] 添加 MLA 支持；[PR#4987] 支持 Muon + MXFP8 的 `--fp8-param-gather`；[PR#5000] 实现 Muon 与其他预条件优化器的超参数迁移。
- **FSDP 优化**：[PR#4979] 修复分组专家权重的填充问题；[PR#5013] 将修复移植至 dev 分支；[PR#4976] 添加基于 DBuffer 的最小 FSDP 路径。
- **MXFP8 参数收集修复**：[PR#4994] 修复 `--fp8-param-gather` 与 `--reuse-grad-buf-for-mxfp8-param-ag` 的交互问题；[PR#4982] 修复 `ChainedOptimizer` 中 MXFP8 延迟同步的门控逻辑。
- **DDP 配置同步**：[PR#4988] 强制同步 `OptimizerConfig.overlap_param_gather` 与 DDP 配置。

- **FSDP 兼容性**：[PR#4953] 为 `finish_grad_sync` 添加 `force_all_reduce` 参数，修复 Torch FSDP2 崩溃；[PR#4959] 修复 `safe_get_rank()` 缺失 `os` 导入。
- **Moonlight MTP 修复**：[PR#4975] 修复 `num_nextn_predict_layers=0` 时的 `labels.clone()` 错误。

- **离线知识蒸馏**：[PR#5019] 添加端到端离线知识蒸馏基础设施，支持教师-学生两阶段训练。
