# Pull Request Digest for nvidia/megatron-lm (20260706-20260713)

**关键要点**：本周最显著的动向是围绕 DeepSeek-V4/Hybrid 模型架构的深度集成与 FSDP 实验性功能的全面增强，共 86 个 PR，最活跃的领域依次为：1) DeepSeek-V4/Hybrid 模型支持，2) FSDP 实验性功能增强，3) 推理优化，4) 分布式检查点与优化器修复，5) 文档与 CI 改进。

### 1. 新功能与架构支持
- **DeepSeek-V4/Hybrid 模型**：
    - [PR#5762] 修复 HybridModel 的 THD 数据入口、MoE 辅助损失及 `csa_ratios` 参数对齐。
    - [PR#5722] 为 `DSv4HybridAttention` 引入 `BatchedGEMM`，支持 MXFP8/BF16 并消除 `.contiguous()` 调用。
    - [PR#5729] 添加 DeepSeek-V4 (DSA) 模型级 bit-exact 确定性代理测试。
    - [PR#5691] 重叠 DSv4 indexer 和压缩 KV 的 CP 通信，提升 packed-THD 执行性能。
    - [PR#5668] 修复 HybridEP 在 `torch.compile` 无 CUDA Graph 时的 token 均衡问题。
    - [PR#5664] 重构 CP 布局以优化长上下文训练性能。
- **注意力机制**：
    - [PR#5769] 新增 Kimi Delta Attention (KDA) 线性注意力变体，作为 `experimental_attention_variant`。
    - [PR#5765] 升级 FLA 至 0.5.1 并集成 GDN2 chunk kernel 到 `GatedDeltaNet`。
- **训练与数据**：
    - [PR#5681] 添加可变长度 THD 数据集，支持 HuggingFace/Parquet/JSON 等源。
    - [PR#5679] 添加 THD 序列打包调度器，支持 DP 均衡及多种并行模式。
    - [PR#5662] 新增逐层资源 profiling，提供 GPU 耗时与内存报告。
    - [PR#5688] 添加可配置的优化器参数组覆盖 (`OptimizerConfig.overrides_config`)。
- **推理**：
    - [PR#5745] 添加基于 DeepEP v2 (ElasticBuffer) 的推理 MoE token 分发支持。
    - [PR#5727] 为动态引擎添加流式回复支持。
    - [PR#5700] 启用 Qwen MoE 的推理优化路径。

### 2. FSDP 实验性功能增强
- **通信与计算重叠**：
    - [PR#5719] 实现实验性 FSDP (`mfsdp_v2`) 的显式预取，重叠参数 all-gather 与计算。
    - [PR#5743] 支持 HSDP 延迟 DP-outer 梯度 reduction，基于 #5652 的 microbatch 上下文。
- **模块与钩子修复**：
    - [PR#5711] 允许无参数 FSDP 根模块，便于定义重叠协调作用域。
    - [PR#5710] 为冻结参数 FSDP 单元配对 backward 钩子，修复 NVTX 不平衡。
    - [PR#5704] 添加 FSDP NVTX 注解，标记前向/后向钩子范围。
- **其他**：
    - [PR#5730] 修复 FSDP 高优先级流的 Blackwell 架构门控条件，确保 `--use-torch-fsdp2` 也受架构检查。
    - [PR#5714] 修复 FSDP2 SwiGLU 检查点保存/加载的 TP-DP 分片逻辑。

### 3. 分布式检查点与优化器
- **检查点转换与加载**：
    - [PR#5753] 实现 GPT 到 Hybrid 模型的检查点自动转换，无需离线步骤。
    - [PR#5737] 修复 tied-embeddings 模型在 PP>1 时检查点转换的断言失败。
    - [PR#5671] 添加异步分布式检查点加载，重叠磁盘 I/O 与其他计算。
- **优化器状态修复**：
    - [PR#5742] 支持 `DistributedOptimizer` 检查点非 Adam 优化器（如 Lion），动态发现状态键。
    - [PR#5707] 修复 layer-wise (Muon) 分布式优化器在 DP=1、CP 分区等配置下的崩溃。
    - [PR#5684] 修复 `ChainedOptimizer` 的 torch 检查点保存，确保 LayerWise 和 DistributedOptimizer 状态均被保留。
- **其他修复**：
    - [PR#5759] 修复 `remove_sharded_tensors` 公共 API 的三处独立错误并重新启用单元测试。
    - [PR#5751] 移除 `save_dist_checkpoint_full` 中冗余的 `contiguous()` 调用。

### 4. 并行策略与核心组件修复
- **并行配置验证**：
    - [PR#5757]/[PR#5756] 在 `TransformerConfig` 中验证 `num_attention_heads` 能被 `num_query_groups` 整除，提前捕获无效 GQA 配置。
    - [PR#5764] 保护 `validate_args` 中的 CUDA 设备探测，避免无 GPU 进程崩溃。
- **通信与并行**：
    - [PR#5754] 修复自定义并行顺序下 AG 组的创建，缓存并复用 `RankGenerator`。
    - [PR#5748] 修复 SP + MTP 的 all-gather 问题。
    - [PR#5720] 支持非 colocated bridge 通信器中目标 CP>1。
    - [PR#5735] 为 NCCL EP 添加零拷贝支持，跳过 D2D 拷贝。
- **其他核心修复**：
    - [PR#5761] 修复 `combined_1f1b.py` 中 `and` 逻辑错误，正确进入 autocast 和 fp8 上下文。
    - [PR#5750] 修复 `MambaLayer` 未传递 `layernorm_epsilon` 的问题。
    - [PR#5696] 修复 inter-document masking 与 MBS>1 时 MoE 序列负载均衡损失的计算错误。
    - [PR#5724] 对齐 eager 与 graph 模式下的 THD padding 逻辑。
