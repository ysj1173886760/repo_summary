# Pull Request Digest for nvidia/megatron-lm (20260831-20260907)

**PR 统计**：共 103 个（已合并 53 · 进行中 18 · 草稿 16 · 已关闭 16）

## 本周概览
本周重点推进了 MFSDP v2 的 CUDA 图支持与独立 HSDP 实例，为分布式训练带来显著性能提升；DeepSeek-V4 架构持续优化，包括反向传播重计算与 CSA 融合；动态上下文并行 V2 系列定义了运行时 CP 契约并集成到标准路径；推理侧 MTP 头添加 KV 缓存并支持仅 MTP 训练模式；确定性训练通过停止填充未初始化内存获得约 15% TFLOP/s 提升。

**最活跃领域**：1. 分布式训练与 MFSDP v2；2. CUDA 图与训练性能优化；3. DeepSeek-V4 与混合架构；4. 动态上下文并行 (DCP)；5. 推理优化

## 重点进展
- **MFSDP v2 全迭代 CUDA 图与独立 HSDP 实例**：支持全迭代 CUDA 图捕获与重放，并允许专家参数使用独立的 HSDP 实例，大幅提升分布式训练灵活性和性能 [#7075](https://github.com/nvidia/megatron-lm/pull/7075) [#7012](https://github.com/nvidia/megatron-lm/pull/7012)
- **DCP V2 运行时动态 CP 契约（部分进行中）**：定义运行时动态上下文并行组契约，并集成到标准训练/评估路径，为动态 CP 奠定基础 [#7045](https://github.com/nvidia/megatron-lm/pull/7045) [#7047](https://github.com/nvidia/megatron-lm/pull/7047)
- **DeepSeek-V4 训练优化**：反向传播中重计算 RoPE 以节省激活内存，并融合 CSA 的 THD 相关操作减少内核启动开销 [#7036](https://github.com/nvidia/megatron-lm/pull/7036) [#7064](https://github.com/nvidia/megatron-lm/pull/7064)
- **MTP 推理增强**：MTP 头注意力层添加 KV 缓存提升接受率，并支持冻结骨干的仅 MTP 训练模式 [#7033](https://github.com/nvidia/megatron-lm/pull/7033) [#7021](https://github.com/nvidia/megatron-lm/pull/7021)
- **确定性训练性能提升**：在确定性模式下停止填充未初始化内存，带来约 15% TFLOP/s 提升，且保持位精确可复现 [#7093](https://github.com/nvidia/megatron-lm/pull/7093)
