# Pull Request Digest for nvidia/megatron-lm (20260831-20260907)

过去一周 Megatron-LM 社区的 **103 个 PR** 集中体现了将训练与推理推向极端规模的工程浪潮，最明确的信号是**动态上下文并行全面落地、MFSDP v2 趋于完整，以及与 DeepSeek 系列模型深度适配的架构扩展**。最活跃的方向依次为：
1. 训练性能与 CUDA Graph / 低精度优化
2. 上下文并行与分布式策略（DCP, MFSDP v2, HSDP）
3. 推理与 KV 缓存、前缀缓存
4. 新模型架构与组件（音频编码器、DeepSeek-V4、MTP）
5. 基础设施、CI 与文档

---

### 1. 训练性能与 CUDA Graph / 低精度
- **主机同步剪除**：[PR#7076] 每迭代移除 104 次不必要的 device→host 同步，无损于数值正确性。
- **CUDA 图全迭代支持**：[PR#7075] 为 MFSDP v2 提供完整迭代 CUDA Graph 覆盖；[PR#6994] 在 HybridStack 中合并部分 CUDA 图捕获；[PR#6992] 确保 eval 模式正确回退到 eager 执行，避免 MoE 路由计数回放问题。
- **低精度与存储优化**：[PR#7095] 在 FP8 主权重回写时保持 row-only MXFP8 存储；[PR#7054] 修复 DSA indexer 的 FP8 精度拆分；[PR#7007] 避免参数 offload 时的重复 host 分配。
- **Muon 优化**：[PR#7085] 支持 per-head Muon QKV 正交化并修复 TP>num_query_groups 问题；[PR#7078] 修复门控 MLP 的 Muon 梯度分离。
- **其它**：[PR#7083] 对 GTP wgrad reduce-scatter 排队避免 backward 阻塞；[PR#7096] 移除 MoE unpermute 中冗余的确定性分配。

### 2. 动态上下文并行（DCP V2 系列）
- [PR#7097] 允许任意 CP 大小（非 2 的幂），引入轻量逻辑 CP 描述符，并可选通过 TE 原生传输执行 P2P / MoE aux-loss 通信。
- DCP V2 四部曲 [PR#7045 – #7048]：定义运行时动态 CP 组契约；使 MoE aux-loss 感知运行时 CP 拓扑；将动态 CP 集成进标准 train/eval 调度（PP>1、VPP）；传播动态 CP 组到 GDN／Mamba／MLA／MTP 等所有消费者层。

### 3. 分布式策略与优化器
- **MFSDP v2 增强**：[PR#7082] 支持在 MFSDP v2 中启用 CP；[PR#7012] 让 dense 与 expert 参数独立选择 HSDP 实例数。
- **优化器 / 检查点**：[PR#7080] 将分布式优化器 state dict 中的 tuple 键替换为安全字符串；[PR#7028] 防止源检查点元数据覆盖目标分片参数；[PR#7027] 中心化检查点转换器的假进程组初始化；[PR#7013] 修复 FP32 模型参数的非叶张量问题。
- **梯度裁剪**：[PR#7074] 修复 MFSDP v2 的精度感知梯度裁剪，使其不误用 decoupled_grad。

### 4. 推理与 KV / 前缀缓存
- **前缀缓存 logprobs**：[PR#7063] 在 canonical KV 块上缓存 prompt 对数概率，跨 chunk 重组时保持正确性。
- **MTP 推理与 KV 缓存**：[PR#7033] 为 MTP 头注意力层添加 KV 缓存；[PR#7056] 将 MTP 推理代码抽成独立的 mixin 类；[PR#7021] 添加 MTP-only 训练模式（冻结 backbone）。
- **推理正确性**：[PR#7061] 修复 NVLS EP=1 时的 CUDA graph padding 处理、prefix-cache 在 RAED 场景下的 KV 丢失、greedy 采样退化等三个边缘问题。
- **推理性能**：[PR#7015] 将元数据移出 RESTful 传输；[PR#6996] 将 prompt 哈希从协调器前移到前端。

### 5. 新架构与模型组件
- **双模 RoPE 音频编码器**：[PR#7066] 引入支持离线／因果／混合模式的音频 Transformer 编码器。
- **DeepSeek-V4 视觉支持**：[PR#7022] 为 `DeepSeek-V4-Flash-Vision-Exp` 添加训练阶段架构支持。
- **DeepSeek-V4 CSA 优化**：[PR#7064] 融合 THD 相关算子以减少 kernel launch。
- **HybridModel 扩展**：[PR#7035] 添加原生 list 架构；[PR#7008] 为 HybridModel 加入输出处理器回调。
- **其他激活函数**：[PR#7003] 添加 TanH Sq-relu 和 SiTU GLU。

### 6. MoE 相关修复与改进
- **专家偏置整数计数**：[PR#7081] 保持 token 计数为精确整数，避免 BF16 舍入导致偏差更新错误。
- **Hash MoE 辅助损失**：[PR#7079] 跳过 hash 路由层的 aux-loss（实际路由与 logits 路由不一致）。
- **缓存／路由**：[PR#7059] 对 `pad_routing_map` 无法达到对齐时添加警告；[PR#6999] 保持 HybridEP 容量跨 CUDA graph 重放。
- **CPU 初始化**：[PR#7011] 添加 MoE 层 CPU 初始化支持。

### 7. 基础设施与 CI
- **sync 工作**：[PR#7094], [PR#7055], [PR#7058] 等多次 `main→dev` 同步，修复合并冲突。
- **CI 增强**：[PR#7072] 支持 functional test label 与并发控制；[PR#7068] 将 `torch-memory-saver` 移入 inference 额外依赖。
- **基础镜像**：[PR#6991] 更新到 26.08 基础镜像。
- **文档**：[PR#7034] 添加确定性训练文档。

### 8. 修复合集
- **日志**：[PR#7092] 修正首次迭代打印的损失为均值而非实时值。
- **MLA 与 offload**：[PR#7090] 使 activation offload 作用于融合 MLA 投影；[PR#7044] 避免对已 offload 的 activation 重复释放。
- **S3 数据集检查**：[PR#6990] 修复大小写敏感的 S3 对象存在性检查。
- **推理序列化**：[PR#7057] 修复 `TensorStateDeallocatedError` 反序列化及内存单位格式。
- **模型导出**：[PR#7024] 添加 flag 禁用 KV cache scale clamp。
