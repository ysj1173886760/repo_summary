# Pull Request Digest for nvidia/megatron-lm (20260727-20260803)

**关键要点**：本周 125 个 PR 中，最显著的趋势是 MFSDP v2 框架的深度集成与成熟化，涵盖重构、新分片策略、激活重计算支持及优化器设计文档，同时 MLA 和 GTP 持续获得精度与性能增强。最活跃的领域依次为：1. MFSDP v2 2. MLA/DSA/DSv4 3. GTP 4. 推理优化 5. CI/基础设施。

---

### 1. MFSDP v2 框架演进
- **重构与生命周期管理**：
  - [PR#6190](https://github.com/NVIDIA/Megatron-LM/pull/6190) 将惰性上下文初始化替换为显式 `fully_shard` 作用域，消除前向钩子中的流创建与模块命名耦合。
  - [PR#6127](https://github.com/NVIDIA/Megatron-LM/pull/6127) 新增构造期 `fully_shard_options()` 上下文管理器，将对称内存等配置从单次调用提升为组级不可变选项。
  - [PR#6067](https://github.com/NVIDIA/Megatron-LM/pull/6067) 在 `fully_shard` 时规范化数据并行轴，简化内部 `dp_axes` 契约。
- **分片策略扩展**：
  - [PR#6137](https://github.com/NVIDIA/Megatron-LM/pull/6137) 为实验性 MFSDP v2 添加 `no_shard`、`optim`、`optim_grads` 分片策略，支持微批次梯度累积与确定性后优化器权重同步。
- **激活重计算与调度集成**：
  - [PR#6197](https://github.com/NVIDIA/Megatron-LM/pull/6197) 为 MFSDP v2 添加激活重计算和专家并行 1F1B 重叠调度支持，填补了直接调用子模块时缺失的生命周期集成。
  - [PR#6153](https://github.com/NVIDIA/Megatron-LM/pull/6153) 修复 FSDP 激活重计算预取，在反向传播期间禁用前向 all-gather 预取，并保持重计算参数物化直到后向重分片。
  - [PR#6174](https://github.com/NVIDIA/Megatron-LM/pull/6174) 修复组合 1F1B 中 FSDP 前向预取状态错乱，确保前向/反向层状态隔离。
- **梯度与优化器处理**：
  - [PR#6187](https://github.com/NVIDIA/Megatron-LM/pull/6187) 在 reduce-scatter 流上分配 `main_grad`，避免缓冲区提前释放导致的数据竞争。
  - [PR#6169](https://github.com/NVIDIA/Megatron-LM/pull/6169) 将对称内存 AVG 语义封装进 `DBuffer`，使 FSDP 部分梯度缓冲区在语义上保持 `Partial(AVG)`。
  - [PR#6164](https://github.com/NVIDIA/Megatron-LM/pull/6164) 修复 MFSDP v2 中绑定参数的注册与梯度钩子，确保每个物理可训练参数仅一个梯度钩子。
- **文档与示例**：
  - [PR#6186](https://github.com/NVIDIA/Megatron-LM/pull/6186) 提供 MFSDP 优化器设计文档，对比钩子、子类化与组合方式。
  - [PR#6085](https://github.com/NVIDIA/Megatron-LM/pull/6085) 添加实验性 FSDP QwenImage 训练示例。

### 2. MLA/DSA/DSv4 注意力机制增强
- **MLA 配置与精度**：
  - [PR#6122](https://github.com/NVIDIA/Megatron-LM/pull/6122) / [PR#6204](https://github.com/NVIDIA/Megatron-LM/pull/6204) 添加可配置的 `attention_latent_norm_epsilon`，应用于标准/吸收式 MLA 及 DSv4 主潜变量归一化，默认继承 `layernorm_epsilon`。
  - [PR#6178](https://github.com/NVIDIA/Megatron-LM/pull/6178) 允许 FP8/FP4 与 `AbsorbedMLA` 上投影重计算共存，移除过时的量化不支持断言。
- **稀疏注意力与 RoPE 融合**：
  - [PR#6185](https://github.com/NVIDIA/Megatron-LM/pull/6185) 将 DSv4 输出逆 RoPE 融合进 CSA 稀疏注意力 autograd Function，避免保留额外旋转激活。
  - [PR#6166](https://github.com/NVIDIA/Megatron-LM/pull/6166) 修复稀疏索引器反向传播中因填充槽位导致的原子竞争，通过标记无效索引跳过 K/dK 计算。
- **FLOPs 统计修正**：
  - [PR#6148](https://github.com/NVIDIA/Megatron-LM/pull/6148) 为 DSA 变体补充 top-k 稀疏性和索引器成本计入 FLOPs 计算。
- **MLA 重计算预取**：
  - [PR#6176](https://github.com/NVIDIA/Megatron-LM/pull/6176) 扩展 FSDP 权重预取至选择性 `mla_up_proj` 重计算，在重放前异步收集上行投影权重。
- **其他修复**：
  - [PR#6145](https://github.com/NVIDIA/Megatron-LM/pull/6145) 修复吸收式 MLA 中延迟权重梯度处理，确保 `linear_kv_up_proj.weight` 的 TE 延迟闭包被正确触发。

### 3. GTP（广义张量并行）优化
- **通信与内存**：
  - [PR#6101](https://github.com/NVIDIA/Megatron-LM/pull/6101) 避免输出层在反向传播中重复 all-gather，复用前向保留的权重。
  - [PR#6155](https://github.com/NVIDIA/Megatron-LM/pull/6155) 添加 NCCL 对称内存/用户缓冲区注册支持，加速 GTP 的 all-gather 和 reduce-scatter。
  - [PR#6202](https://github.com/NVIDIA/Megatron-LM/pull/6202) 修复嵌入预取缓冲区重用排序，防止别名缓冲区导致的数据覆盖。
- **精度与计算**：
  - [PR#6200](https://github.com/NVIDIA/Megatron-LM/pull/6200) 添加 `reduce-scatter-with-fp32-accumulation` 支持，在 FP32 累加后再缩放，避免 BF16 预缩放精度损失。
- **CUDA 图与重拟合**：
  - [PR#6077](https://github.com/NVIDIA/Megatron-LM/pull/6077) 修复 GTP 全迭代 CUDA 图捕获回归，处理叶子节点流和异步 RS 事件。
  - [PR#6133](https://github.com/NVIDIA/Megatron-LM/pull/6133) 原生支持 GTP 重拟合（refit），并大幅简化规划器。
