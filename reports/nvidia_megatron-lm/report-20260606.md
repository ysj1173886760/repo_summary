# Pull Request Digest for nvidia/megatron-lm (20260530-20260606)

**本周关键趋势：** 推理优化与异构并行基础设施成为焦点，同时 MoE 路由修复与 CI 稳定性持续改进。共 113 个 PR，最活跃的领域为：1) 推理优化  2) MoE 与专家并行  3) CI/测试与基础设施  4) 异构并行与通信  5) 模型支持与配置  6) FSDP 与优化器  7) 训练状态管理。

---

### 1. 推理优化 (Inference)
- 动态批处理路径补齐滑动窗口注意力支持，统一 `flash_decode_and_prefill` 与静态路径的 `window_size` 行为 [PR#5138](https://github.com/NVIDIA/Megatron-LM/pull/5138)。
- 实现事务性异步调度架构，用于动态解码的 `forward` 与 `sampling` 交替执行，消除 CPU 记账间隙 [PR#5196](https://github.com/NVIDIA/Megatron-LM/pull/5196)。
- 前缀缓存逻辑重构为独立类 `PrefixCacheRegistry` 与 `PrefixCacheBlockState`，便于后续修改 [PR#5119](https://github.com/NVIDIA/Megatron-LM/pull/5119)，并补充单元测试 [PR#5122](https://github.com/NVIDIA/Megatron-LM/pull/5122)。
- 路由重放缓存移入独立类，降低推理上下文耦合度 [PR#5127](https://github.com/NVIDIA/Megatron-LM/pull/5127)。
- 修复 0 生成 token 时的 logprob 切片问题 [PR#5167](https://github.com/NVIDIA/Megatron-LM/pull/5167)，并钳制 `max_new_tokens` 以对齐 vllm 行为 [PR#5181](https://github.com/NVIDIA/Megatron-LM/pull/5181)。
- 添加 sink attention 支持（动态推理）[PR#5140](https://github.com/NVIDIA/Megatron-LM/pull/5140)。
- 动态 CP 调度加入打包支持，Nemotron Ultra SFT 场景获得 2.4x 加速 [PR#5191](https://github.com/NVIDIA/Megatron-LM/pull/5191)，并改进默认打包调度器 [PR#5154](https://github.com/NVIDIA/Megatron-LM/pull/5154)。

### 2. MoE 与专家并行 (MoE & Expert Parallelism)

- 添加 DeepEP v2 作为 flex 调度器的后端 [PR#5153](https://github.com/NVIDIA/Megatron-LM/pull/5153)。
