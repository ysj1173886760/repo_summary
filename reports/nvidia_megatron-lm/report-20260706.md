# Pull Request Digest for nvidia/megatron-lm (20260629-20260706)

本周共 104 个 PR，推理服务能力大幅扩展（动态批处理、前缀缓存、VLM 支持），同时 FSDP 实验性功能、MoE 性能优化、序列打包与检查点系统迎来多项架构增强。最活跃领域依次为：1) 推理服务，2) FSDP/分布式训练，3) MoE，4) 序列打包/THD，5) 检查点优化。

1. 推理服务
   - 新增 `super_v3` 和 `ultra_v3` 推理解析器 [PR#5634](https://github.com/NVIDIA/Megatron-LM/pull/5634)
   - 添加性能分析端点 `start_profile` / `stop_profile`，支持客户端控制 nsys 追踪范围 [PR#5611](https://github.com/NVIDIA/Megatron-LM/pull/5611)
   - 聊天补全 API 返回前缀缓存命中数据 [PR#5609](https://github.com/NVIDIA/Megatron-LM/pull/5609)
   - 前缀缓存引入负载感知路由策略 `load_balanced` [PR#5607](https://github.com/NVIDIA/Megatron-LM/pull/5607)
   - `DynamicInferenceEngine` 支持 VLM，可接收图像输入并运行视觉编码器 [PR#5606](https://github.com/NVIDIA/Megatron-LM/pull/5606)
   - 动态批处理增加重叠异步调度模式，统一串行/重叠调度实现 [PR#5549](https://github.com/NVIDIA/Megatron-LM/pull/5549)
   - 异步调度样本保持 GPU 驻留，跳过非 primer 解码的 CPU token H2D [PR#5547](https://github.com/NVIDIA/Megatron-LM/pull/5547)
   - 预分配 all-gather 缓冲区至最大容量，避免 CUDA graph 场景下的动态 resize 导致内存损坏 [PR#5546](https://github.com/NVIDIA/Megatron-LM/pull/5546)
   - Triton 内核通过环境变量避免生产环境重编译和自动调优 [PR#5608](https://github.com/NVIDIA/Megatron-LM/pull/5608)
