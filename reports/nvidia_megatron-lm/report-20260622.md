# Pull Request Digest for nvidia/megatron-lm (20260615-20260622)

**关键要点**：本周 70 个 PR 中，实验性 FSDPv2 的通信重叠与优化器适配、MoE 内核融合与稳定性修复，以及 MIMO 异构训练框架的端到端集成构成三大主线。最活跃领域：1) 分布式训练与 FSDPv2 优化，2) MoE 性能与正确性，3) MIMO 异构多模态训练，4) 混合架构（SSM/GDN）支持，5) 优化器（Muon/LayerWise）改进。

---

### 1. 分布式训练与 FSDPv2 优化
- **实验性 FSDP 通信重叠** [PR#5416](https://github.com/NVIDIA/Megatron-LM/pull/5416)：引入惰性 `FsdpContext`，延迟全参数释放，异步打包 reduce-scatter，统一通信流管理临时缓冲区。
- **混合精度 FSDP 优化器适配** [PR#5411](https://github.com/NVIDIA/Megatron-LM/pull/5411)：通过 pre/post hooks 在优化器消费梯度时临时转换精度，拒绝闭包式 step，增加 Adam 覆盖。
- **实验性 `fully_shard` 实现** [PR#5387](https://github.com/NVIDIA/Megatron-LM/pull/5387)：基于 DBuffer 原语的 per-module FSDP 路径，支持参数分片、全量物化与梯度归约。
- **FSDP meta-parameter 支持** [PR#5369](https://github.com/NVIDIA/Megatron-LM/pull/5369)：在 minimal FSDP 之上恢复 meta-parameter 路径，可独立合并或丢弃。
- **LayerWise 优化器 bucket 填充优化** [PR#5415](https://github.com/NVIDIA/Megatron-LM/pull/5415)：将 `bucket_size` 视为软下限，用真实参数替代分片填充，减少 MoE 等场景的内存膨胀。
- **紧凑 LayerWise DDP 布局 for Muon** [PR#5391](https://github.com/NVIDIA/Megatron-LM/pull/5391) / [PR#5388](https://github.com/NVIDIA/Megatron-LM/pull/5388)：移除持久化的 `dp_size * max(shard_load)` 填充，复用现有 flag，无新配置项。
- **torchcomms 路由** [PR#5385](https://github.com/NVIDIA/Megatron-LM/pull/5385)：使所有 `torch.distributed` 集合通信可通过 PyTorch TorchComms 路由，无需修改调用点。

### 2. MoE 性能与正确性
- **量化均衡** [PR#5349](https://github.com/NVIDIA/Megatron-LM/pull/5349)：在 MoE 中实现 Quantile Balancing 负载均衡策略。
- **z-loss CUDA Graph 兼容修复** [PR#5401](https://github.com/NVIDIA/Megatron-LM/pull/5401)：避免在 CUDA Graph 捕获期间创建 CPU tensor，改用设备端标量。
- **零 token permute 内核修复** [PR#5393](https://github.com/NVIDIA/Megatron-LM/pull/5393)：当 `valid_tokens=0` 时跳过内核启动，防止空 all-reduce 导致 NCCL FastTrak 注册失败。
- **GDN A2A 辅助流重构** [PR#5392](https://github.com/NVIDIA/Megatron-LM/pull/5392) / [PR#5389](https://github.com/NVIDIA/Megatron-LM/pull/5389)：重构 GatedDeltaNet 的 all-to-all 辅助流，恢复融合 THD 路径。
- **chunkwise 上下文并行** [PR#5363](https://github.com/NVIDIA/Megatron-LM/pull/5363)：为 GDN 支持分块上下文并行。
- **Pre-GDR 内核融合** [PR#5361](https://github.com/NVIDIA/Megatron-LM/pull/5361) / [PR#5362](https://github.com/NVIDIA/Megatron-LM/pull/5362)：将 GDN 预处理（因果卷积、布局变换、QK 归一化等）融合为单一内核，减少显存占用。
- **MoE 过程组扩展** [PR#5375](https://github.com/NVIDIA/Megatron-LM/pull/5375)：为 MIMO 异构训练创建 `tp+dp`、`tp+dp+cp` 等密集过程组，供 MoE 层和梯度同步使用。

### 3. MIMO 异构多模态训练
- **端到端入口与引导** [PR#5377](https://github.com/NVIDIA/Megatron-LM/pull/5377)：`pretrain_mimo.py` 入口，`build_mimo_runtime` 编排器，mock VLM 数据。
- **前向步骤与 per-token loss** [PR#5376](https://github.com/NVIDIA/Megatron-LM/pull/5376)：角色无关的 `forward_step_func`，适配 stock pipeline schedule。
- **异构网格参数与过程组** [PR#5375](https://github.com/NVIDIA/Megatron-LM/pull/5375)：CLI 参数模块，拓扑辅助创建额外过程组。
- **Nemotron6-MoE VLM 模型提供者** [PR#5374](https://github.com/NVIDIA/Megatron-LM/pull/5374)：语言 Mamba 模型 spec、仿射投影器、RADIO 编码器集成。
- **训练循环跨网格路径** [PR#5373](https://github.com/NVIDIA/Megatron-LM/pull/5373)：`get_forward_backward_func` 选择、loss 访问守卫、`finalize_model_grads` 跳过等，对非 MIMO 无影响。
- **MimoModel.zero_grad_buffer** [PR#5372](https://github.com/NVIDIA/Megatron-LM/pull/5372)：委托给活跃 DDP 子模块，使 stock `train_step` 正常工作。
- **RADIO 编码器 TP 组线程** [PR#5371](https://github.com/NVIDIA/Megatron-LM/pull/5371)：将编码器 TP 组传入 `ColumnParallelLinear`，避免回退到全局组。
- **桥接过程组急切初始化** [PR#5370](https://github.com/NVIDIA/Megatron-LM/pull/5370)：避免 1F1B 死锁，对称化 leader 广播。
- **RADIO 视觉编码器包装** [PR#5397](https://github.com/NVIDIA/Megatron-LM/pull/5397)：class-token drop + pixel-shuffle 适配器，动态分辨率支持。

### 4. 混合架构（SSM/GDN/DSA）支持
- **GatedDeltaNet 优化器路由** [PR#5400](https://github.com/NVIDIA/Megatron-LM/pull/5400)：将 `in_proj` 权重路由至 Adam，避免被 Muon 正交化。
- **GDN L2-norm 内核融合** [PR#5396](https://github.com/NVIDIA/Megatron-LM/pull/5396)：将 q/k 的 L2 归一化折叠进 `gated_delta_rule` 内核，消除中间激活显存。
- **Muon 梯度裁剪跳过** [PR#5395](https://github.com/NVIDIA/Megatron-LM/pull/5395)：当全局 `grad_norm` 极大时跳过裁剪，防止数值下溢导致参数变为 NaN。
- **ModelOpt HybridModel 支持** [PR#5354](https://github.com/NVIDIA/Megatron-LM/pull/5354)：为 GDN、DSA、MTP 添加 ModelOpt spec，支持 duplicated 并行模式。
- **Hybrid CP 更新与 RoPE 修复** [PR#5356](https://github.com/NVIDIA/Megatron-LM/pull/5356) / [PR#5355](https://github.com/NVIDIA/Megatron-LM/pull/5355)：适配序列打包后的 Hybrid CP，修复 `local_cp_size=1` 时 RoPE 回退。
- **Mamba 前缀缓存安全检查** [PR#5348](https://github.com/NVIDIA/Megatron-LM/pull/5348)：扩展至 scratch space 缓冲区，防止 OOM。
- **SSM 推理通用接口** [PR#5382](https://github.com/NVIDIA/Megatron-LM/pull/5382)：为 SSM 添加通用推理接口。
- **DSA/DSv4 Indexer Replay** [PR#5386](https://github.com/NVIDIA/Megatron-LM/pull/5386)：RL 训练中重放 indexer top-k 决策，提升稳定性。
