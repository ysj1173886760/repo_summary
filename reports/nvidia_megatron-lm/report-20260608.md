# Pull Request Digest for nvidia/megatron-lm (20260601-20260608)

1. **关键要点**
   - 本周共 **117 个 PR**，最显著的技术趋势是**推理子系统向异步事务化调度与分离式内存管理深度重构，同时 MoE 路径的正确性及 TE/DeepEP 融合算子兼容性修复密集落地**。
   - 最活跃的领域：
      1. 动态推理异步调度与分离式推理
      2. MoE 路由、Expert Parallelism 及 TE 融合兼容性修复
      3. 训练基础设施重构 (GlobalState, FSDP 预取)
      4. CI 健壮性与平台测试覆盖增强
      5. 代码清理与文档规范化

2. **推理子系统**
   - **异步解码调度**：通过事务化 CPU/GPU 合约实现“forward → sampling → forward”连续流水，消除 CPU 簿记间隙，目标 GPU 100% 利用率 [PR#5202](https://github.com/NVIDIA/Megatron-LM/pull/5202) [PR#5200](https://github.com/NVIDIA/Megatron-LM/pull/5200) [PR#5198](https://github.com/NVIDIA/Megatron-LM/pull/5198) [PR#5196](https://github.com/NVIDIA/Megatron-LM/pull/5196)。
   - **分离式推理 (Disaggregated)**：引入推理分片规格、PG 集合构建、异构 KV/Mamba 重分片规划器及多目标池 Refit [MR1 #5186](https://github.com/NVIDIA/Megatron-LM/pull/5186) [MR2 #5187](https://github.com/NVIDIA/Megatron-LM/pull/5187) [MR3 #5188](https://github.com/NVIDIA/Megatron-LM/pull/5188)。
   - **动态批处理增强**：增加 packing 支持与调度器优化 [PR#5191](https://github.com/NVIDIA/Megatron-LM/pull/5191) [PR#5154](https://github.com/NVIDIA/Megatron-LM/pull/5154)，`HyperCommGrid` 多布局命名及 MIMO SP/CP 显式分组 [PR#5148](https://github.com/NVIDIA/Megatron-LM/pull/5148) [PR#5150](https://github.com/NVIDIA/Megatron-LM/pull/5150)，滑动窗口注意力动态批处理支持 [PR#5138](https://github.com/NVIDIA/Megatron-LM/pull/5138)。
   - **代码重构**：路由回放缓存与 Prefix Cache 拆分为独立类 [PR#5127](https://github.com/NVIDIA/Megatron-LM/pull/5127) [PR#5119](https://github.com/NVIDIA/Megatron-LM/pull/5119)，新增相关单元测试 [PR#5122](https://github.com/NVIDIA/Megatron-LM/pull/5122)。
