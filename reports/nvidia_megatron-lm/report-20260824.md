# Pull Request Digest for nvidia/megatron-lm (20260817-20260824)

**关键要点：** 本周 197 个 PR 的核心趋势是多模态（MIMO）与混合专家（MoE）训练/推理的深度集成优化，以及内核后端选择机制从分散的 `HAVE_*` 标志全面转向统一的 `BackendSpecProvider` 架构。最活跃的领域依次为：
1. MIMO 多模态与 MTP 训练
2. FSDP/MFSDP v2 分片及 1F1B 重叠
3. 内核后端重构（`BackendSpecProvider`）
4. 推理服务化（GDP 动态推理、CUDA Graph、前缀缓存）
5. 序列打包与变长数据管道
6. RL 训练优化
7. CI/CD 基础设施

---

### 1. 多模态与模型架构
- **MIMO 模态集成与 MTP 掩码**：多个 PR 完善了 MIMO 多模态模型对 MTP（多 token 预测）的支持，包括跨模态 token 掩码 [PR#6770](https://github.com/NVIDIA/Megatron-LM/pull/6770)、MTP 条件元数据集成 [PR#6790](https://github.com/NVIDIA/Megatron-LM/pull/6790)，以及显式进程组在 MTP 路径中的传递 [PR#6760](https://github.com/NVIDIA/Megatron-LM/pull/6760)。
- **GDP 与 MIMO 混合模型**：Gated Delta Product 的 CUDA Graph 支持 [PR#6595](https://github.com/NVIDIA/Megatron-LM/pull/6595)、分块预填充 [PR#6711](https://github.com/NVIDIA/Megatron-LM/pull/6711) 和前缀缓存 [PR#6780](https://github.com/NVIDIA/Megatron-LM/pull/6780) 已合入；进程组传递给 GDP 投影 [PR#6687](https://github.com/NVIDIA/Megatron-LM/pull/6687) 解决了显式分组问题。
- **新激活与注意力**：Kimi K3 的 SiTU-GLU 激活通过 TE 和本地回退加入 [PR#6674](https://github.com/NVIDIA/Megatron-LM/pull/6674) [PR#6636](https://github.com/NVIDIA/Megatron-LM/pull/6636)；注意力 logit 软封顶配置 [PR#6590](https://github.com/NVIDIA/Megatron-LM/pull/6590)；融合 GDN 注意力支持 [PR#6645](https://github.com/NVIDIA/Megatron-LM/pull/6645)。
- **混合状态管理**：混合 SSM 状态在分散推理中的传递 [PR#6584](https://github.com/NVIDIA/Megatron-LM/pull/6584)，Mamba 解码缓存刷新修复 [PR#6723](https://github.com/NVIDIA/Megatron-LM/pull/6723) 和 refit 缓存修复 [PR#6672](https://github.com/NVIDIA/Megatron-LM/pull/6672)。
- **流式宽残差**：Transformer 层引入 streamwise wide-residual 核心 [PR#6716](https://github.com/NVIDIA/Megatron-LM/pull/6716)，为后续优化打下基础。

### 2. 分布式训练优化
- **FSDP 与 MFSDP v2**：大量 PR 围绕 MFSDP v2 的细粒度 hooks [PR#6692](https://github.com/NVIDIA/Megatron-LM/pull/6692) 和 1F1B 重叠集成 [PR#6694](https://github.com/NVIDIA/Megatron-LM/pull/6694) 展开，设计文档 [PR#6693](https://github.com/NVIDIA/Megatron-LM/pull/6693) 独立提交。同时支持了 EP 分片的 DTensor 专家权重 [PR#6785](https://github.com/NVIDIA/Megatron-LM/pull/6785)、混合 FSDP 策略 [PR#6773](https://github.com/NVIDIA/Megatron-LM/pull/6773) [PR#6594](https://github.com/NVIDIA/Megatron-LM/pull/6594)，以及 meta 设备初始化 [PR#6659](https://github.com/NVIDIA/Megatron-LM/pull/6659)。DTensor 放置机制重构 [PR#6744](https://github.com/NVIDIA/Megatron-LM/pull/6744) [PR#6751](https://github.com/NVIDIA/Megatron-LM/pull/6751) 简化了公开 API。
- **GTP 与 Muon 优化器**：GTP 对齐填充处理在 Muon 正交化前剥离 [PR#6740](https://github.com/NVIDIA/Megatron-LM/pull/6740)，并在 `num_zeros` 统计中排除 [PR#6778](https://github.com/NVIDIA/Megatron-LM/pull/6778)。LayerShardedMuon 引入 [PR#6683](https://github.com/NVIDIA/Megatron-LM/pull/6683)，支持混合 TP 模式 [PR#6761](https://github.com/NVIDIA/Megatron-LM/pull/6761)，以及 auto TP 模式选择 [PR#6664](https://github.com/NVIDIA/Megatron-LM/pull/6664)。GTP 梯度在 FP32 下 reduce-scatter 修复 [PR#6624](https://github.com/NVIDIA/Megatron-LM/pull/6624)。
- **CUDA Graph 与通信优化**：局部 CUDA Graph 流别名修复 [PR#6643](https://github.com/NVIDIA/Megatron-LM/pull/6643)，GTP 持久缓冲区通用化 [PR#6713](https://github.com/NVIDIA/Megatron-LM/pull/6713)，前向预取依赖修复 [PR#6696](https://github.com/NVIDIA/Megatron-LM/pull/6696)。MIMO 流水线通信批量化 [PR#6606](https://github.com/NVIDIA/Megatron-LM/pull/6606) 和优化器同步减少 [PR#6727](https://github.com/NVIDIA/Megatron-LM/pull/6727)。
- **混合并行布局**：CP 布局转换支持混合模型 [PR#6764](https://github.com/NVIDIA/Megatron-LM/pull/6764) 及其集成 [PR#6776](https://github.com/NVIDIA/Megatron-LM/pull/6776)，允许 zigzag 与连续布局按注意力类型切换。

### 3. 内核后端架构
- **`BackendSpecProvider` 与 `ops` 包**：核心重构通过 `megatron/core/ops` 包 [PR#6689](https://github.com/NVIDIA/Megatron-LM/pull/6689) 和 `BackendSpecProvider` 取代所有 `HAVE_*` 标志和分散导入 [PR#6690](https://github.com/NVIDIA/Megatron-LM/pull/6690)，并提供了 CLI 按操作选择后端的能力。后续清理移除了旧的 `models/backends` 依赖 [PR#6766](https://github.com/NVIDIA/Megatron-LM/pull/6766)（替换 [PR#6763](https://github.com/NVIDIA/Megatron-LM/pull/6763)）。`megatron/core/ops` 实现层 [PR#6762](https://github.com/NVIDIA/Megatron-LM/pull/6762) 也已提交。
- **其他内核**：CuTeDSL Gated Delta Product 训练内核 [PR#6574](https://github.com/NVIDIA/Megatron-LM/pull/6574)、MOK megakernel 集成 [PR#6572](https://github.com/NVIDIA/Megatron-LM/pull/6572)、sonic-moe 融合内核 [PR#6601](https://github.com/NVIDIA/Megatron-LM/pull/6601) 和 channel-last conv1d 确定性 [PR#6655](https://github.com/NVIDIA/Megatron-LM/pull/6655)。

### 4. 推理系统
- **动态推理与 GDP**：除了 GDP 的 CUDA Graph 和分块预填充，还增加了 CUDA Graph 大小分布的 HYBRID 模式 [PR#6667](https://github.com/NVIDIA/Megatron-LM/pull/6667)、前缀亲和路由 [PR#6668](https://github.com/NVIDIA/Megatron-LM/pull/6668)。KV 缓存饱和测试 [PR#6722](https://github.com/NVIDIA/Megatron-LM/pull/6722) 覆盖了之前缺失的极端场景。
- **分散推理**：端到端预填充/解码分离实现 [PR#6675](https://github.com/NVIDIA/Megatron-LM/pull/6675)，含 KV/SSM 直接传输和协调器设计。
- **推理稳定性**：ZMQ 通信死锁修复 [PR#6779](https://github.com/NVIDIA/Megatron-LM/pull/6779) 和订阅者同步 [PR#6715](https://github.com/NVIDIA/Megatron-LM/pull/6715)；vLLM 专家 GEMM 缓冲区持久化用于 CUDA Graph [PR#6618](https://github.com/NVIDIA/Megatron-LM/pull/6618)；MXFP8 推理修复 [PR#6588](https://github.com/NVIDIA/Megatron-LM/pull/6588)。
- **Mamba 推测解码**：ReplaySSM 状态管理 [PR#6617](https://github.com/NVIDIA/Megatron-LM/pull/6617) 实现了高效的 Mamba 推测解码。

### 5. 数据管道与序列打包
- **序列打包**：基于 DP 平衡的打包调度器 [PR#6684](https://github.com/NVIDIA/Megatron-LM/pull/6684) 并集成到训练循环 [PR#6742](https://github.com/NVIDIA/Megatron-LM/pull/6742)，同时引入了变长数据集家族 [PR#6734](https://github.com/NVIDIA/Megatron-LM/pull/6734) 和 mock SFT 数据集。这些 PR 是原 #3386 的拆分落地。
- **RL 数据集**：`ResponsesEnvAgent` 提供 gym 风格集成 [PR#6703](https://github.com/NVIDIA/Megatron-LM/pull/6703)。

### 6. RL 训练优化
- **Rollout 管理**：部分 rollout 组持久化 [PR#6768](https://github.com/NVIDIA/Megatron-LM/pull/6768) 和按步 rollout bank 指标 [PR#6769](https://github.com/NVIDIA/Megatron-LM/pull/6769) 完善了之前的基础设施。
- **性能优化**：避免对选定 token 的全词汇表 gather [PR#6706](https://github.com/NVIDIA/Megatron-LM/pull/6706)，RL CUDA Graph 非 TE 路径修复 [PR#6709](https://github.com/NVIDIA/Megatron-LM/pull/6709)。
- **批量不变模式**：原生 NVLS multimem 选项和训练侧镜像 [PR#6634](https://github.com/NVIDIA/Megatron-LM/pull/6634) 支持真正的 on-policy RL。
