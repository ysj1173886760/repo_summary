# Pull Request Digest for nvidia/megatron-lm (20260720-20260727)

**关键趋势**：本周 Megatron-FSDP v2 实验路径密集迭代并开始与 TP/EP/优化器组合，DeepSeek-V4 稀疏注意力（CSA/DSA）及压缩索引器持续深化，CI 稳定性与自动化修复大量涌现。  
**总 PR 数**：162  
**最活跃领域**：  
1. Megatron-FSDP v2 开发与集成  
2. DeepSeek-V4 / 稀疏注意力（CSA/DSA）  
3. CI / 测试基础设施与稳定性修复  
4. 推理与 RL 训练增强  
5. MoE 与专家并行优化  
6. 序列打包与 THD 数据加载

8. 其他修复与优化

### 1. Megatron-FSDP v2 开发与集成（约 18 个 PR）
- **TP 组合与 DP+TP 支持**：[PR#6052](https://github.com/NVIDIA/Megatron-LM/pull/6052) 实现 DP+TP 组合性，`DBuffer` 持有全网格 `DTensor`，FSDP 不跨 TP 轴 gather。  
- **优化器与检查点**：[PR#6024](https://github.com/NVIDIA/Megatron-LM/pull/6024) 添加 PyTorch DCP 保存/加载；[PR#5976](https://github.com/NVIDIA/Megatron-LM/pull/5976) 修复优化器预初始化导致的欠更新；[PR#5949](https://github.com/NVIDIA/Megatron-LM/pull/5949) 将模型权重同步移至优化器后步。  
- **CUDA 图与通信**：[PR#5987](https://github.com/NVIDIA/Megatron-LM/pull/5987) 覆盖对称内存 FSDP 集合通信的 CUDA 图测试；[PR#6021](https://github.com/NVIDIA/Megatron-LM/pull/6021) 修复 DDP 初始化流与捕获流对齐。  
- **HFSDP / HSDP 扩展**：[PR#5972](https://github.com/NVIDIA/Megatron-LM/pull/5972) 支持 HFSDP（优化器跨 DP-outer 分片）；[PR#5985](https://github.com/NVIDIA/Megatron-LM/pull/5985) 预取 DP-Outer all-gather。  
- **Muon 优化器**：[PR#5986](https://github.com/NVIDIA/Megatron-LM/pull/5986) 添加 Muon 支持。  
- **EP 组合性**：[PR#5954](https://github.com/NVIDIA/Megatron-LM/pull/5954) 允许 MFSDP v2 与专家并行组合；[PR#5956](https://github.com/NVIDIA/Megatron-LM/pull/5956) 添加 EP 组合性单元测试。  
- **设计文档**：[PR#6031](https://github.com/NVIDIA/Megatron-LM/pull/6031) 运行时调度设计；[PR#5886](https://github.com/NVIDIA/Megatron-LM/pull/5886) 优化器设计讨论。  
- **重构与 API**：[PR#5971](https://github.com/NVIDIA/Megatron-LM/pull/5971) 将放置策略移至 `fully_shard` API 边界；[PR#6041](https://github.com/NVIDIA/Megatron-LM/pull/6041) 简化梯度重绑定。  
- **离线转换器**：[PR#5895](https://github.com/NVIDIA/Megatron-LM/pull/5895) 添加 `fsdp_dtensor` → `torch_dist` 检查点离线转换器。

### 2. DeepSeek-V4 / 稀疏注意力（CSA/DSA）（约 12 个 PR）
- **压缩索引器**：[PR#5992](https://github.com/NVIDIA/Megatron-LM/pull/5992) 添加 SM100 紧凑 cuDNN 索引器（BF16/MXFP8）；[PR#5883](https://github.com/NVIDIA/Megatron-LM/pull/5883) 消除压缩索引路径的每步 host-to-device 拷贝。  
- **CSA 内核**：[PR#5984](https://github.com/NVIDIA/Megatron-LM/pull/5984) 添加 CuTe-DSL 融合前向/反向门控池化内核；[PR#5960](https://github.com/NVIDIA/Megatron-LM/pull/5960) 使用完整 CSA 分母计算索引器损失。  
- **DSA 负载均衡**：[PR#6058](https://github.com/NVIDIA/Megatron-LM/pull/6058) 上下文并行下负载均衡的 DSA 索引器。  
- **混合注意力**：[PR#5948](https://github.com/NVIDIA/Megatron-LM/pull/5948) 启用 SBHD DSv4 混合注意力（滑动窗口 + 压缩稀疏）；[PR#5947](https://github.com/NVIDIA/Megatron-LM/pull/5947) 添加未融合压缩稀疏注意力核心。  
- **DSA 迁移**：[PR#6020](https://github.com/NVIDIA/Megatron-LM/pull/6020) 将 main 分支 DSA 实现迁移到 dev。  
- **GLM5.2 IndexShare**：[PR#5899](https://github.com/NVIDIA/Megatron-LM/pull/5899) 添加 IndexShare DSA 支持。  
- **性能优化**：[PR#5884](https://github.com/NVIDIA/Megatron-LM/pull/5884) 避免未融合 DSA THD 助手中的逐段 GPU→CPU 同步。
