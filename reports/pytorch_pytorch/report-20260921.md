# Pull Request Digest for pytorch/pytorch (20260914-20260921)

## 关键要点

本周最显著的趋势是：`Dynamo`/`Inductor` 面向 caller-driven 的 `precompile` 多图捕获 API 持续大规模落地，同时分布式测试通过复用 worker 系统性压缩 CI 时间。共 752 个 PR，最活跃领域排名为：1. `Dynamo`/`Inductor` 编译栈，2. 分布式（`FSDP2`/`DTensor`/`c10d`），3. 硬件后端适配（`ROCm`/`XPU`/`MPS`/`CPU`），4. 测试与 CI 重构，5. 其他组件（量化/JIT/优化器/导出）。

---

### 1. `Dynamo`/`Inductor` 编译栈

- **`precompile` 多图捕获 API**：bobrenjc93 的 ghstack 系列将 `torch.compiler.precompile` 从 callable 改为模块，并新增 caller-driven 的 `capture()`/`load()` 磁盘产物对，这是本周最庞大的一支栈。关键 PR：
  - [PR #197341](https://github.com/pytorch/pytorch/pull/197341)：新增基于磁盘产物对的 `capture()`/`load()`。
  - [PR #197343](https://github.com/pytorch/pytorch/pull/197343)：将 `torch.compiler.precompile` 改为模块。
  - [PR #197844](https://github.com/pytorch/pytorch/pull/197844)/[PR #197352](https://github.com/pytorch/pytorch/pull/197352)：`PrecompileSession` 多图捕获与独立 artifact 渲染。
  - [PR #197763](https://github.com/pytorch/pytorch/pull/197763)：公开 `DynamoTracer`、`PrecompiledCallable` 与捕获报告。
  - [PR #197455](https://github.com/pytorch/pytorch/pull/197455)：中和 serving 时 ambient autocast。
  - [PR #197349](https://github.com/pytorch/pytorch/pull/197349)/[PR #197348](https://github.com/pytorch/pytorch/pull/197348)：以源码形式携带 Dynamo eager graph，并拼接多个 Inductor 模块到同一 namespace。
- **Guard 状态序列化强化**：
  - [PR #197843](https://github.com/pytorch/pytorch/pull/197843)/[PR #197835](https://github.com/pytorch/pytorch/pull/197835)：将守卫状态裁剪从 `nn.Module` 扩展到任意用户对象。
  - [PR #197754](https://github.com/pytorch/pytorch/pull/197754)：从真实张量推导被守卫的 `FakeTensor`。
  - [PR #197833](https://github.com/pytorch/pytorch/pull/197833)/[PR #197817](https://github.com/pytorch/pytorch/pull/197817)：通过 `persistent_id` 裁剪精确内建容器，并用自定义 unpickler 读取。
- **Dynamo 语义与错误处理**：
  - [PR #197845](https://github.com/pytorch/pytorch/pull/197845)：为捕获的 method/wrapper descriptor 安装 `BUILTIN_MATCH` 守卫。
  - [PR #197781](https://github.com/pytorch/pytorch/pull/197781)/[PR #197230](https://github.com/pytorch/pytorch/pull/197230)/[PR #197056](https://github.com/pytorch/pytorch/pull/197056)：新增 `classmethod`/`staticmethod`、`bytearray`、`DELETE_GLOBAL` 处理器。
  - [PR #197443](https://github.com/pytorch/pytorch/pull/197443)：匹配 CPython 单参数 `KeyError` 字符串格式。
  - [PR #197315](https://github.com/pytorch/pytorch/pull/197315)：对 `ZeroTensor` 输入 graph break，避免 CPU kernel 空指针段错误。
- **编译性能优化**：anijain2305 的系列 PR（[PR #197728](https://github.com/pytorch/pytorch/pull/197728), [PR #197729](https://github.com/pytorch/pytorch/pull/197729), [PR #197730](https://github.com/pytorch/pytorch/pull/197730), [PR #197724](https://github.com/pytorch/pytorch/pull/197724) 等）针对配置读取、符号查询、fake 元数据复用、activation checkpointing 最小割做专项加速；`GenerationTracker` 与 `GuardedCode` 移入 C++ 也在推进（[PR #197733](https://github.com/pytorch/pytorch/pull/197733), [PR #197732](https://github.com/pytorch/pytorch/pull/197732)）。

### 2. 分布式（`FSDP2`/`DTensor`/`c10d`）

- **`c10d` 与 checkpoint_**
  - [PR #197568](https://github.com/pytorch/pytorch/pull/197568)：只从兼容父 backend split，修复 MCCL/NOCOLOR split 问题。
  - [PR #197467](https://github.com/pytorch/pytorch/pull/197467)：等待异步 `ncclCommRevoke` 完成。
  - [PR #197602](https://github.com/pytorch/pytorch/pull/197602)：新增 NCCL collective-config dispatcher 支持。
  - [PR #197616](https://github.com/pytorch/pytorch/pull/197616)：通用 c10d TorchComms backend 注册 hook。
  - 分布式测试大量使用持续 worker，例如 [PR #197647](https://github.com/pytorch/pytorch/pull/197647) 及同栈多个 checkpoint/ DTensor test PR，将测试时间从数百秒降至个位数。

### 4. 测试与 CI 重构

- **`HardwareClassification` 推广**：多组 PR 给量化、linalg、custom ops 等测试文件打 `GENERIC`/`ACCELERATOR` 标签，例如 [PR #197804](https://github.com/pytorch/pytorch/pull/197804), [PR #197791](https://github.com/pytorch/pytorch/pull/197791), [PR #197375](https://github.com/pytorch/pytorch/pull/197375)。
- **大规模测试文件拆分**：`test_linalg.py`、`test_scaled_matmul_cuda.py`、`test_cuda_multigpu.py` 等被拆为设备通用与专用类，如 [PR #197243](https://github.com/pytorch/pytorch/pull/197243), [PR #197536](https://github.com/pytorch/pytorch/pull/197536), [PR #197250](https://github.com/pytorch/pytorch/pull/197250)。
- **分布式测试加速**：d4l3k 系列将 FSDP/DTensor/checkpoint 等测试全部迁移到持续 worker，显著降低用例启动开销。
- **CI 配置**：CUDA 13.0 移至 periodic（[PR #197031](https://github.com/pytorch/pytorch/pull/197031)），新增 ARM64 CUDA CI（[PR #197575](https://github.com/pytorch/pytorch/pull/197575)），ROCm CI 架构限制与 Kubernetes 化（[PR #197330](https://github.com/pytorch/pytorch/pull/197330), [PR #197004](https://github.com/pytorch/pytorch/pull/197004)）。
