## 本周概览
本周核心变化是 `torch.compiler.precompile` 模块全面上线，提供多图预编译捕获与加载能力，大幅简化部署流程；同时 Dynamo guard 状态序列化与剪枝显著降低编译工件体积，分布式测试套件通过进程重用实现数量级耗时缩减，ROCm 和 MPS 后端持续收敛到生产级品质。

**最活跃领域**：1. `precompile` 与编译器基础设施；2. `dynamo` 与 `aot_compile`；3. `distributed` 测试与 FSDP2；4. `ROCm` 支持；5. `inductor` 优化

## 重点进展
- **引入 `torch.compiler.precompile` 模块**：新增 `capture()`/`load()` API 和多图驱动，将 Dynamo 捕获的编译结果序列化为磁盘工件，支持跨环境恢复执行，涵盖 guard 不变性报告与风险脱落检测。 [#197341](https://github.com/pytorch/pytorch/pull/197341) [#197342](https://github.com/pytorch/pytorch/pull/197342) [#197343](https://github.com/pytorch/pytorch/pull/197343) [#197353](https://github.com/pytorch/pytorch/pull/197353) [#197352](https://github.com/pytorch/pytorch/pull/197352) [#197601](https://github.com/pytorch/pytorch/pull/197601)
- **Dynamo guard 状态剪枝与精确序列化**：通过属性剪枝、精确容器表示和 `persistent_id` 剪枝，大幅压缩 guard 状态体积，加速编译图加载，并改进多图 no-match 报告质量。 [#197792](https://github.com/pytorch/pytorch/pull/197792) [#197752](https://github.com/pytorch/pytorch/pull/197752) [#197754](https://github.com/pytorch/pytorch/pull/197754) [#197818](https://github.com/pytorch/pytorch/pull/197818) [#197833](https://github.com/pytorch/pytorch/pull/197833)
- **分布式测试效率革命**：将大量 FSDP、DTensor、checkpoint 等测试迁移为复用工作者，避免每次新建进程组，分布式测试总耗时缩减超 50%。 [#197643](https://github.com/pytorch/pytorch/pull/197643) [#197644](https://github.com/pytorch/pytorch/pull/197644) [#197646](https://github.com/pytorch/pytorch/pull/197646) [#197654](https://github.com/pytorch/pytorch/pull/197654)
