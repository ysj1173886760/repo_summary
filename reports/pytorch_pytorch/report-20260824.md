# Pull Request Digest for pytorch/pytorch (20260817-20260824)

**关键要点**：本周最显著的趋势是 **Dynamo 预编译（`torch.compiler.precompile`）与 AOTAutograd 训练支持的深度集成**，以及 **Inductor 在性能优化、动态形状和硬件后端（ROCm/MPS/XPU）上的大量修复**；共 **682** 个 PR，顶级活跃领域为：① Inductor 编译器优化与修复 ② Dynamo 追踪与预编译 ③ 分布式训练（FSDP2/DTensor/流水线/c10d） ④ 硬件后端支持（ROCm, MPS, XPU） ⑤ 测试重构与硬件分类 ⑥ 自动微分与 AOTAutograd ⑦ 量化与 NN 模块修复 ⑧ 文档与代码清理。

---

### 1. 新功能与重大改进
- **Dynamo 预编译体系**：`torch.compiler.precompile` 新增 `training=True` 支持，可自动捕获反向图 [PR#193995]；引入 `guard_policy="varying"` 仅序列化区分性守卫 [PR#193987]；移除手动捕获块，简化 API [PR#193997]。同时支持 Dynamo 图打断（graph break）[PR#194148] 和重编译捕获 [PR#194113]，并完善了守卫重建、序列化与诊断 [PR#194293, PR#194294, PR#194295, PR#194252]。
- **可编辑的编译内核导出**：新增 `torch.compiler.export_python` 装饰器，将编译后的可读 Python 源码写入磁盘，支持手工调优 [PR#193899, PR#193898, PR#193973, PR#193974]。
- **AOTAutograd 训练图组合**：支持将训练图的前向与反向组合为独立源码，用于预编译 [PR#194158]；为未定义输出切线特化反向图 [PR#194523]；重放输入突变时保持正确语义 [PR#194534, PR#194543]。
- **Inductor 辅助写入**：引入 `AuxiliaryWriteRegion` 抽象，允许融合内核在运行时初始化或更新辅助输出区域 [PR#194406]。
- **每模块激活内存预算**：支持按 `nn.Module` ID 设置激活检查点预算，可跨图打断生效 [PR#194402, PR#194291]。
- **流水线发送缓冲区释放**：通过轮询完成、命名释放点、计数预算等方式，显著降低流水线并行中的激活内存占用 [PR#194119~194122]。
- **Muon 优化器加速**：Inductor 识别并批量执行对称矩阵乘法和 Newton-Schulz 更新，集成 QuACK 对称 GEMM 内核 [PR#194177~194181]。
- **组合 Inductor 选择**：支持注册多个 `InductorChoices` 工厂，实现可组合的编译策略 [PR#194097]。
- **`torch.nn.RMSNorm` C++ 前端**：补齐 Python/C++ 功能差距 [PR#193936]。
- **`torch.autograd.graph.queue_callback`**：公开私有 API，允许在反向传播结束后执行回调 [PR#193958]。
- **`isDifferentiableType` 暴露到 Python**：`torch._C._is_differentiable_type` [PR#194142]。
- **自动检测反向梯度输入突变**：防止自定义 `Function.backward` 中的隐式错误 [PR#194143]。
- **`torch.remainder` 零结果符号修复**：遵循文档，零结果取除数符号 [PR#193776]。
