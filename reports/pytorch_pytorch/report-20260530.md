# Pull Request Digest for pytorch/pytorch (20260523-20260530)

**关键摘要**：本周最显著的趋势是围绕 `torch.compile`、动态形状和导出的正确性与稳定性进行了大规模修复，共计 606 个 PR，其中活跃度最高的领域依次为：1. Dynamo 与编译器前端，2. Inductor 后端与代码生成，3. 导出与序列化，4. 分布式与 DTensor，5. 硬件后端支持。

### 1. 核心编译器与前端 (Dynamo, AOTAutograd, FX)
- **动态形状与符号推理**：
    - [PR#185692](https://github.com/pytorch/pytorch/pull/185692)：修复了 `SymFloat` 的延迟运行时断言丢失问题，防止 Inductor 因符号桶错误而丢弃检查。
    - [PR#185604](https://github.com/pytorch/pytorch/pull/185604)：改进了 `infer_size` 在非约束符号广播时的报错信息，避免将数据依赖错误隐藏为简单的等式失败。
    - [PR#185569](https://github.com/pytorch/pytorch/pull/185569)：修复了包含非约束项的符号布尔值短路求值问题，防止在可守卫的 `Or` 表达式上引发数据依赖错误。
    - [PR#185103](https://github.com/pytorch/pytorch/pull/185103)：修复了通过 `div/mod` 进行的非约束标量相等推理，允许静态评估利用已断言的事实。
    - [PR#185084](https://github.com/pytorch/pytorch/pull/185084)：避免在可能为单维度的符号维度上产生连续性守卫，减少动态切片的不必要重编译。
    - [PR#185031](https://github.com/pytorch/pytorch/pull/185031)：通过为 `aten.scalar_tensor` 记录 `item_memo`，消除了从大小派生的 `SymInt` 与其标量张量之间的冗余相等守卫。
- **图捕获与追踪**：
    - [PR#185034](https://github.com/pytorch/pytorch/pull/185034) 和 [PR#185033](https://github.com/pytorch/pytorch/pull/185033)：默认启用了 Dynamo 对 `torch.autograd.grad` 和 `Tensor.backward` 的捕获，移除了旧的 `trace_autograd_ops` 开关。
    - [PR#185619](https://github.com/pytorch/pytorch/pull/185619)：使 Dynamo 能够追踪 `einops` 0.8.2+ 的内部实现，将其视为常规 PyTorch 操作而非外部叶子节点。
    - [PR#185628](https://github.com/pytorch/pytorch/pull/185628)：内联了分解后的量化辅助函数，防止 Dynamo 因 `torch.ao` 包被跳过而出现图断裂。
    - [PR#185675](https://github.com/pytorch/pytorch/pull/185675)：实现了对 Python 3.15 虚拟迭代器的支持，确保 Dynamo 能够处理新的迭代器表示。
    - [PR#185471](https://github.com/pytorch/pytorch/pull/185471)：修复了 Dynamo 对 `torch._C._infer_size` 的追踪，使其能够正确处理 `torch.Size` 参数。
    - [PR#185456](https://github.com/pytorch/pytorch/pull/185456)：修复了 `Tensor.random_` 的追踪问题，解决了 FX 代码生成中 ATen 重载名称包含 Python 关键字的问题。
- **错误处理与用户体验**：
    - [PR#185412](https://github.com/pytorch/pytorch/pull/185412)：为 `torch.compile` 引入了特定的 `FakeTensorDeviceMismatchError`，取代了设备不匹配时的通用运行时错误。
    - [PR#185451](https://github.com/pytorch/pytorch/pull/185451)：将内部 Dynamo 断言错误包装为 `InternalTorchDynamoError`，防止编译器错误被误认为是用户错误。
    - [PR#185466](https://github.com/pytorch/pytorch/pull/185466)：在图断裂的用户堆栈中添加了插入符号，以精确指示导致问题的代码位置。
    - [PR#185155](https://github.com/pytorch/pytorch/pull/185155)：避免了因后端回退图断裂而产生的警告垃圾信息，将允许的异常降级为 `info` 日志。

### 2. 后端与代码生成 (Inductor, Triton, AOTInductor)
- **内核生成与优化**：
    - [PR#185690](https://github.com/pytorch/pytorch/pull/185690)：优化了 AOT 输入视图突变，使 Inductor 能够重新利用简单的切片赋值模式，避免功能化带来的冗余无操作视图散列。
    - [PR#185404](https://github.com/pytorch/pytorch/pull/185404)：在 post-grad 阶段将小行扩展的 `bmm` 折叠为 `mm`，显著提升了动态线性层在 CUDA 上的性能。
    - [PR#185052](https://github.com/pytorch/pytorch/pull/185052)：修复了 Inductor 对不相交跨步切片的复用分析，防止将每个元素仅使用一次的模式误判为高复用。
    - [PR#185627](https://github.com/pytorch/pytorch/pull/185627)：修复了 `wait_stream` 在代码生成中的重排序问题，将其添加到 `_SYNC_OPS` 以保持正确的调度顺序。
    - [PR#185325](https://github.com/pytorch/pytorch/pull/185325)：修复了 CPU 向量化 `atomic_add` 在标量索引上的问题，防止合法的 `scatter` 反向传播崩溃。
    - [PR#185157](https://github.com/pytorch/pytorch/pull/185157)：修复了 CPU 上布尔型 `argmin/argmax` 返回错误索引的问题，原因是向量化布尔值被错误地当作浮点数处理。
- **AOTInductor 与编译缓存**：
    - [PR#185634](https://github.com/pytorch/pytorch/pull/185634)：修复了 AOTI 的 CUDA 设备拷贝分配问题，确保目标缓冲区在正确的设备上创建。
    - [PR#185328](https://github.com/pytorch/pytorch/pull/185328)：修复了 AOTI CUDA 多架构目标打包问题，确保为部署目标生成正确的 PTX/cubin。
    - [PR#185312](https://github.com/pytorch/pytorch/pull/185312) 和 [PR#185049](https://github.com/pytorch/pytorch/pull/185049)：将隐式 CPU 线程数解析结果纳入 FX 图缓存键，防止因环境线程数变化而加载过时的编译产物。
    - [PR#185323](https://github.com/pytorch/pytorch/pull/185323)：将自定义算子的 fake 元数据纳入 FX 缓存键，确保算子实现变更后缓存会失效。
    - [PR#185511](https://github.com/pytorch/pytorch/pull/185511)：将 SDPA 后端状态添加到 FX 图缓存键，防止在不同 SDPA 后端（如 Flash 和 cuDNN）之间发生缓存碰撞。
- **Triton 与模板**：
    - [PR#185597](https://github.com/pytorch/pytorch/pull/185597)：修复了 `wrap_triton` 在 Triton 解释器模式下的处理，使其能正确接受 `InterpretedFunction`。
    - [PR#185514](https://github.com/pytorch/pytorch/pull/185514)：修复了 TMA 组合内核中的 `NameError`，使其能正确处理 `DelayReplaceLine` 对象。
    - [PR#185223](https://github.com/pytorch/pytorch/pull/185223)：修复了 TMA 代码生成中不支持的数据类型（如 `bool`）问题，使其能优雅地回退到常规块指针。

### 3. 导出与序列化 (Export, ONNX)
- **动态形状与约束**：
    - [PR#185166](https://github.com/pytorch/pytorch/pull/185166)：修复了跨动态维度的导出切片边界问题，使用 `sym_min/sym_max` 来暴露灵活的大小，避免安装值依赖的连续性守卫。
    - [PR#185371](https://github.com/pytorch/pytorch/pull/185371)：修复了符号抗锯齿 `resize` 的导出形状问题，防止动态缩放因子被特化。
    - [PR#184993](https://github.com/pytorch/pytorch/pull/184993)：修复了稀疏 COO 输入的导出动态形状问题，确保符号大小能正确传播。
    - [PR#185082](https://github.com/pytorch/pytorch/pull/185082)：在严格导出捕获期间保留提升的 `SymInt`，防止 Dynamo 和导出图之间出现分歧。
- **图完整性与健壮性**：
    - [PR#185090](https://github.com/pytorch/pytorch/pull/185090)：修复了导出分解过程中添加的常量丢失问题，确保新提升的张量常量能被包含在重建的 `ExportedProgram` 中。
    - [PR#185106](https://github.com/pytorch/pytorch/pull/185106)：修复了非严格导出中的状态别名问题，防止将已注册参数的别名错误地提升为独立的常量输入。
    - [PR#185108](https://github.com/pytorch/pytorch/pull/185108)：防止非严格导出泄露 fake 缓冲区，确保在 `forward` 中分配的缓冲区不会污染原始模块。
    - [PR#185140](https://github.com/pytorch/pytorch/pull/185140)：在非严格导出中保留了可重入的 `checkpoint`，防止 AOTAutograd 因 `no_grad` 区域而发出错误的 `detach`。
    - [PR#185073](https://github.com/pytorch/pytorch/pull/185073)：将新的追踪器状态视为常量，修复了严格导出中自由张量无法正确映射的问题。
- **ONNX**：
    - [PR#185005](https://github.com/pytorch/pytorch/pull/185005)：修复了 ONNX 类型提升重载选择问题，使其能正确解析 `aten.where` 的标量重载，而非依赖运行时的实现细节。

### 4. 分布式与 DTensor
- **DTensor 正确性**：
    - [PR#185177](https://github.com/pytorch/pytorch/pull/185177)：修复了 `nll_loss` 在批量分片且带有 `weight` 和 `reduction='mean'` 时的加权平均计算错误。
    - [PR#185356](https://github.com/pytorch/pytorch/pull/185356)：修复了 `DTensor` 的 `embedding` 掩码状态在 `compile` 下的问题，将掩码从 `placement` 元数据移至 `local_tensor`，以便 AOTAutograd 功能化。
    - [PR#185613](https://github.com/pytorch/pytorch/pull/185613)：禁用了 `run_dtensor_rng_op` 的 `FxGraphCache`，以防止多进程编译中因共享缓存目录而导致的 RNG 状态错误。
- **流水线并行与检查点**：
    - [PR#185355](https://github.com/pytorch/pytorch/pull/185355)：修复了流水线并行中接收缓冲区激活的后向钩子累积问题，防止钩子调用次数跨步骤增长。
    - [PR#185178](https://github.com/pytorch/pytorch/pull/185178)：在选择性激活检查点重计算期间，绕过了 FSDP 的 `all-gather` 内部操作的 SAC 追踪，修复了重放不匹配的问题。
- **新功能与基础设施**：
    - [PR#185565](https://github.com/pytorch/pytorch/pull/185565)：将 `torchcomms` 库上游化为 `torch.comms`，为 `gloo` 和 `nccl` 后端提供了新的通信库。
    - [PR#185475](https://github.com/pytorch/pytorch/pull/185475)：添加了实验性的嵌套自定义 Python 进程组，允许拦截 `dist.*` 集合调用。
    - [PR#185418](https://github.com/pytorch/pytorch/pull/185418)：将 `get_rank` 表示为 `SymInt`，使 `compile_on_one_rank` 能够生成跨 rank 有效的图。

### 5. 硬件后端 (ROCm, XPU, MPS, CPU)
- **ROCm**：
    - [PR#185678](https://github.com/pytorch/pytorch/pull/185678)：修复了 ROCm 上 `scatter_add` 的 CuTeDSL 内核错误调度问题，防止在 AMD GPU 上调用仅限 NVIDIA 的 CUTLASS DSL。
    - [PR#185644](https://github.com/pytorch/pytorch/pull/185644)：修复了 Quack RMSNorm 覆盖在 ROCm 和非 CUDA 张量上的错误应用。
    - [PR#185415](https://github.com/pytorch/pytorch/pull/185415)：修复了 AMD Strix Halo GPU 上 `LayerNorm` 反向内核因硬编码的 warp size 而导致的错误结果。
    - [PR#185303](https://github.com/pytorch/pytorch/pull/185303)：在 ROCm/HIP 构建中跳过了 CuTeDSL 算子的注册，防止导入时出现 `CudaDriverDependencyError`。
- **XPU**：
    - [PR#185531](https://github.com/pytorch/pytorch/pull/185531)：为 XPU 推理添加了 oneDNN LSTM 原语支持，取代了逐时间步的融合单元方法。
    - [PR#185507](https://github.com/pytorch/pytorch/pull/185507)：为 XPU LSTM 预计算 `igates`，将 O(T) 的 GEMM 启动减少为一次大型 GEMM。
    - [PR#185192](https://github.com/pytorch/pytorch/pull/185192)：添加了 `torch.xpu.list_gpu_processes` API，用于查询每个进程的 GPU 内存使用情况。
- **MPS**：
    - [PR#185622](https://github.com/pytorch/pytorch/pull/185622)：修复了 MPS `bucketization` 的速度回归问题，性能提升高达 577 倍。
    - [PR#185609](https://github.com/pytorch/pytorch/pull/185609)：为 MPS 添加了 Metal `cumsum` 和 `cumprod` 内核。
    - [PR#185351](https://github.com/pytorch/pytorch/pull/185351)：修复了 MPS LSTM 的 dropout 未被正确应用的问题。
- **CPU**：
    - [PR#185697](https://github.com/pytorch/pytorch/pull/185697)：移除了 mkldnn RNN 和注意力机制中始终为常量的模板标志。
    - [PR#185151](https://github.com/pytorch/pytorch/pull/185151)：修复了 `var_mean` 的 reduction 在适当的 `acc_type` 中执行，而非总是使用 `double`。
