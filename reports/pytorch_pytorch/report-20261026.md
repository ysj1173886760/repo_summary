# Pull Request Digest for pytorch/pytorch (20261019-20261026)

**PR 统计**：共 435 个（已合并 86 · 进行中 204 · 草稿 130 · 已关闭 15），另有 20 个机器人 PR 未计入

## 本周概览
本周 Dynamo 和 Inductor 持续深化编译正确性与性能优化，MPS 后端加速向 Metal 内核迁移并修复多项数值精度问题，分布式模块在 DTensor、FSDP2 和 NCCL 方面进行了重要修复与扩展。同时，AOTI 重构、动态形状符号化以及多后端（ROCm/XPU）兼容性改进也在稳步推进。

**最活跃领域**：1. Dynamo & Inductor；2. MPS；3. 分布式（c10d/DTensor/FSDP）；4. ROCm/XPU 后端；5. 量化与测试重构

## 重点进展
- **MPS 全面迁移至 Metal 内核**：max_pool2d、pixel shuffle/unshuffle、batch norm backward 及 SDPA 注意力等核心算子从 MPSGraph 迁移至 Metal，显著提升性能并修复 NaN 传播等问题 [#201411](https://github.com/pytorch/pytorch/pull/201411) [#201724](https://github.com/pytorch/pytorch/pull/201724) [#201745](https://github.com/pytorch/pytorch/pull/201745) [#201756](https://github.com/pytorch/pytorch/pull/201756)
- **Dynamo 图断开销大幅降低**：通过跳过冗余 RESUME 检查点、避免不可能恢复的检查点以及减少嵌套图断追踪开销，显著优化了 `torch.compile` 的编译时性能 [#201465](https://github.com/pytorch/pytorch/pull/201465) [#201466](https://github.com/pytorch/pytorch/pull/201466) [#201467](https://github.com/pytorch/pytorch/pull/201467)
- **Inductor 数值精度严格模式**：一系列 PR 针对 pointwise 算子（clamp、min/max、激活函数、除法等）在严格模式下匹配 eager 的 NaN 行为和舍入语义，提升编译结果的可信度 [#201888](https://github.com/pytorch/pytorch/pull/201888) [#201889](https://github.com/pytorch/pytorch/pull/201889) [#201890](https://github.com/pytorch/pytorch/pull/201890) [#201893](https://github.com/pytorch/pytorch/pull/201893)
- **AOTI 模型池重构与 RAII 管理**：将 AOTInductor 的模型管理提取为 `ModelPool` 类，并引入 RAII 租约机制简化异常处理和资源生命周期 [#201507](https://github.com/pytorch/pytorch/pull/201507) [#201508](https://github.com/pytorch/pytorch/pull/201508) [#201509](https://github.com/pytorch/pytorch/pull/201509)
- **分布式编译缓存与 DTensor 修复**：修复 DTensor 移位运算符返回不变输入的问题，并为 `FakeProcessGroup` 添加版本计数器匹配，确保与 NCCL 行为一致 [#201418](https://github.com/pytorch/pytorch/pull/201418) [#201606](https://github.com/pytorch/pytorch/pull/201606)
