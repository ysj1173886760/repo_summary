# Pull Request Digest for pytorch/pytorch (20260629-20260706)

**本周关键趋势**：大量 PR 聚焦于编译器与分布式训练的正确性修复及新硬件（RISC‑V、Blackwell、MI350、gfx1250）的使能，共 450 个 PR。  
**最活跃领域**：① Inductor 编译器 ② Dynamo 追踪 ③ MPS 后端 ④ ROCm 后端 ⑤ XPU 后端 ⑥ 分布式（DTensor/FSDP/c10d）

---

### 1. 编译器与代码生成（Inductor / Dynamo / AOTI）
- **精度修复**：修复 Hopper 上 bf16 矩阵乘累加精度丢失（`tl.dot` 缺少 `out_dtype`）[PR#188998](https://github.com/pytorch/pytorch/pull/188998)；修复 FP8 块缩放形状校验逻辑反转 [PR#188996](https://github.com/pytorch/pytorch/pull/188996)；修复 `log_sigmoid_forward` 在 CUDA 上因 FTZ 冲刷次正规数 [PR#188546](https://github.com/pytorch/pytorch/pull/188546)。
- **动态形状与符号整数**：允许 strict 模式下原始 unbacked SymInts 以支持 FlexAttention BlockMask [PR#188995](https://github.com/pytorch/pytorch/pull/188995)；修复 foreign unbacked SymInt 传递中代数关系丢失 [PR#188994](https://github.com/pytorch/pytorch/pull/188994)；处理 reciprocal SymPy 幂次的范围求值 [PR#188636](https://github.com/pytorch/pytorch/pull/188636)。
- **Triton 与代码生成**：添加 `triton.cudagraph_max_recorded_sizes` 限制动态形状重录制 [PR#188913](https://github.com/pytorch/pytorch/pull/188913)；修复嵌套 reduction 中 block_ptr 跨外层循环回绕 [PR#188771](https://github.com/pytorch/pytorch/pull/188771)；支持混合阶 reduction 的 cpp_wrapper [PR#188887](https://github.com/pytorch/pytorch/pull/188887)；引入 TLX flex attention 模板（Blackwell）[PR#188644](https://github.com/pytorch/pytorch/pull/188644)。
- **AOTI / CUDA 图**：支持通过 `cuLaunchKernelEx` 的 PDL 启动属性 [PR#188886](https://github.com/pytorch/pytorch/pull/188886)；添加外部常量 API 实现零拷贝权重共享 [PR#188643](https://github.com/pytorch/pytorch/pull/188643)；修复 autotune 模块卸载导致的“misaligned address” [PR#188607](https://github.com/pytorch/pytorch/pull/188607)。
- **Dynamo 修复**：保留 Event/Stream 子类身份跨图断点 [PR#188993](https://github.com/pytorch/pytorch/pull/188993)；修复生成器 exhausted 重建 [PR#188622](https://github.com/pytorch/pytorch/pull/188622)；正确实现 SEND 操作码 [PR#188639](https://github.com/pytorch/pytorch/pull/188639)；支持 `operator.concat`/`iconcat` [PR#188966](https://github.com/pytorch/pytorch/pull/188966)。

### 2. 分布式训练（DTensor / FSDP / c10d / NCCL）
- **DTensor 分片**：注册 `aten.as_strided.default` 分片策略 [PR#188997](https://github.com/pytorch/pytorch/pull/188997)；修复 TP‑FSDP 中不均匀分片的偏移量错误 [PR#188947](https://github.com/pytorch/pytorch/pull/188947)；添加 `searchsorted` 的分片策略 [PR#188448](https://github.com/pytorch/pytorch/pull/188448)。
- **FSDP**：修复 `to_cpu` 在 flat_param 已在 CPU 时的错误释放 [PR#188990](https://github.com/pytorch/pytorch/pull/188990)；捕获 `redistribute()` 返回值以修复优化器状态重建 [PR#188946](https://github.com/pytorch/pytorch/pull/188946)。
- **c10d / NCCL**：引入全新 `ProcessGroupNCCL`（nccl2）后端栈 [PR#188582](https://github.com/pytorch/pytorch/pull/188582) 至 [PR#188588](https://github.com/pytorch/pytorch/pull/188588)；移除冗余的 functional collective 拷贝 [PR#188944](https://github.com/pytorch/pytorch/pull/188944)；对称内存分配通过 CUDACachingAllocator v2 [PR#188650](https://github.com/pytorch/pytorch/pull/188650)。
- **流水线 / 检查点**：保存/恢复流水线缓冲区以防动态元数据推理污染 [PR#188763](https://github.com/pytorch/pytorch/pull/188763)；公开 Fsspec 文件系统检查点并支持异步保存 [PR#188698](https://github.com/pytorch/pytorch/pull/188698)。
