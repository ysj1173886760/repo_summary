# Pull Request Digest for pytorch/pytorch (20260530-20260606)

本周核心趋势是系统性地**加固 Dynamo/Inductor 编译管线在动态形状、子类及复杂控制流下的正确性与可观测性**，共 664 个 PR，深度覆盖编译追踪、代码生成及后端适配，其中最活跃领域依次为：**[1] Dynamo 追踪与守卫修正**、**[2] Inductor 与 AOTInductor 代码生成/性能**、**[3] 分布式 (DTensor/FSDP2/Pipelining)**、**[4] ROCm/MPS/XPU 多后端修复**、**[5] 导出与动态形状约束**。

### Dynamo 追踪与守卫修正
- **内存与生命周期**：修复 AOTAutograd/Dynamo 内存泄漏 [PR#186455]；优化器调度器全局状态泄漏 [PR#186447]；清理图断裂后残留的弱引用 [PR#185953]；防止守卫验证意外修改 ShapeEnv [PR#186364]。
- **追踪语义**：修正 FakeTensor 对 mkldnn [PR#186435]、子类梯度 [PR#186427]、非可追踪子类分派钩子 [PR#186425]、张量构造 [PR#186415, #186188]、`functorch` 包裹张量 [PR#185718] 的处理；支持 `torch._assert` 张量条件 [PR#186306]，保留 `torch._check` 消息 [PR#185734]；避免 `autograd.Function` 实例化 [PR#186421] 及支持 `vmap` 规则 [PR#186366, #186362]。
- **守卫与图断裂**：修复 `mark_dynamic` 大小无感知守卫 [PR#186451]；默认关闭鸭子规格 [PR#186373]；处理分派模式栈 [PR#186448]；禁止条件依赖帧跳过缓存 [PR#186003]；改进 `torch._dynamo.disable` 等 API 的图解提示 [PR#185763, #185903]。

### Inductor 与 AOTInductor 代码生成/性能
- **正确性修复**：避免 float `x * 0` 常量折叠丢失 NaN/Inf [PR#186379]；C++ 内核整数除零硬守卫 [PR#186021]；修复 `as_strided_copy` 存储边界 [PR#185809]；`bitwise` 无效浮点类型拒绝 [PR#186016]；CPU 低精度标量舍入 [PR#185869]；`truncdiv` 在 CUDA 上的近似误差 [PR#186252]；Triton `neg` 保留有符号零 [PR#185834]；`minimum/maximum` 正确处理 -0.0 [PR#185765]；智能缓存不完整 CUDA 内核缓存条目 [PR#186346]。
- **性能与融合**：高速路径 `sizevars` 与融合候选评估减少编译时间 [PR#186106, #186095, #186319]；`FlexAttention` 反向改进切分 [PR#185759] 及长序列 FP32 内核选择 [PR#185755]；CUTLASS 尾光融合基准测试 [PR#186059]；`NVGEMM` 尾光融合及渲染重构 [PR#186183, #186184]。
- **AOTInductor**：修复共享存储常量序列化膨胀 [PR#186445]；Windows 上 mmap 大小溢出 [PR#186386]；可选异步固定 H2D 拷贝 [PR#186258]；C-ABI 安全模型创建 [PR#185729]。

### 分布式（DTensor/FSDP2/Pipelining）
- **DTensor**：支持 `scatter` 分片 [PR#186149]；修复深度可分离卷积分片 [PR#186129]；`unflatten` 多网格轴处理 [PR#186282]；单维策略基础架构 [PR#186419]；添加 `logspace` [PR#186398]。
