# Pull Request Digest for pytorch/pytorch (20260727-20260803)

**关键摘要**：本周 604 个 PR 中，最显著的趋势是**大规模测试重构以支持设备无关性**，通过 `hw_classification` 和 `instantiate_device_type_tests` 将数千个测试用例从硬编码 CUDA 迁移到通用加速器抽象。活跃领域：① 测试基础设施重构 (约 80+ PR) ② 分布式/DTensor 修复与特性 (约 60+ PR) ③ Inductor 编译器优化与修复 (约 50+ PR) ④ Dynamo 图捕获与守卫系统 (约 30+ PR) ⑤ 新硬件后端支持 (ROCm/XPU/MPS, 约 40+ PR)。

---

### 1. 测试基础设施重构 (设备无关性迁移)
大规模系统性重构，为测试类添加 `hw_classification` 属性并采用 `instantiate_device_type_tests` 模式，消除硬编码 CUDA 依赖。
*   **核心机制**：引入 `HardwareClassification` 枚举 (`GENERIC`, `ACCELERATOR`, `CUDA` 等) 标记测试类，配合 `instantiate_device_type_tests` 实现按设备类型参数化测试。例如 [PR#191890](https://github.com/pytorch/pytorch/pull/191890) 为 `TestOpCompleteness` 添加 `GENERIC` 标记。
*   **分布式测试解耦**：大量 FSDP/DTensor/流水线并行测试从硬编码 `["cuda", "hpu", "xpu"]` 白名单迁移到 `except_for="cpu"` 或添加 `privateuse1` 支持。例如 [PR#191728](https://github.com/pytorch/pytorch/pull/191728) 启用 PrivateUse1 测试，[PR#191476](https://github.com/pytorch/pytorch/pull/191476) 泛化容错测试。
*   **Dynamo/Inductor 测试分类**：为数百个测试类添加 `GENERIC` 标记，如 [PR#191832](https://github.com/pytorch/pytorch/pull/191832) 为 316 个 CPython 测试子类添加标记，[PR#191722](https://github.com/pytorch/pytorch/pull/191722) 覆盖 Inductor 测试。
*   **设备泛化工具**：多个 PR 将 `test_flop_counter`、`test_fake_tensor` 等文件中的 `HAS_CUDA` 替换为 `TEST_ACCELERATOR`，使用 `torch.accelerator` API 替代 `torch.cuda`。

### 2. 分布式训练与 DTensor
涵盖通信库、DTensor 操作语义、弹性训练及检查点修复。
*   **NCCL 后端增强**：新增 `nccl-legacy` 后端入口 [PR#191272](https://github.com/pytorch/pytorch/pull/191272)，支持非阻塞通信器 [PR#191528](https://github.com/pytorch/pytorch/pull/191528)，修复嵌套 CUDA Graph 捕获冲突 [PR#191827](https://github.com/pytorch/pytorch/pull/191827)。
*   **DTensor 修复与特性**：支持 `Shard(1) -> Partial("sum")` 重分布 [PR#191828](https://github.com/pytorch/pytorch/pull/191828)，修复 `loss_parallel` 中非交叉熵消费者的梯度错误 [PR#191606](https://github.com/pytorch/pytorch/pull/191606)，优化不均匀分片填充 [PR#191580](https://github.com/pytorch/pytorch/pull/191580)。
*   **弹性与检查点**：修复 `find_free_port` 的 `UnboundLocalError` [PR#191874](https://github.com/pytorch/pytorch/pull/191874)，关闭 `mkstemp` 文件描述符泄漏 [PR#191875](https://github.com/pytorch/pytorch/pull/191875)，修复异步检查点内存保留问题 [PR#191558](https://github.com/pytorch/pytorch/pull/191558)。
*   **对称内存**：添加多流使用警告 [PR#191482](https://github.com/pytorch/pytorch/pull/191482)，验证 `put_signal`/`wait_signal` 的 peer rank [PR#191842](https://github.com/pytorch/pytorch/pull/191842)。

### 3. Inductor 编译器优化与修复
聚焦于内核融合、代码生成正确性及新硬件特性支持。
*   **FlexAttention 与 GEMM 融合**：修复 FlexAttention 在消费级 GPU 上的共享内存溢出 [PR#191269](https://github.com/pytorch/pytorch/pull/191269)，支持 `score_mod` 中的 `q-by-kv` 收缩融合 [PR#191691](https://github.com/pytorch/pytorch/pull/191691)。NVGEMM/FlexGEMM 系列重构 epilogue 融合基础设施 [PR#191513](https://github.com/pytorch/pytorch/pull/191513) 等。
*   **CUDA Graph 与内存**：修复 `resize_()` 导致的图输出存储重分配错误 [PR#191611](https://github.com/pytorch/pytorch/pull/191611)，支持图树热身重试 [PR#191386](https://github.com/pytorch/pytorch/pull/191386)，优化条件节点内存复用 [PR#191533](https://github.com/pytorch/pytorch/pull/191533)。
*   **代码生成修复**：修复 `cat` 目标分配顺序导致的未绑定符号错误 [PR#191615](https://github.com/pytorch/pytorch/pull/191615)，修复动态形状下 `saved-activation` 步幅固化问题 [PR#191885](https://github.com/pytorch/pytorch/pull/191885)，修复 `tile2d` 原子加的双重偏移应用 [PR#191861](https://github.com/pytorch/pytorch/pull/191861)。
*   **AOTInductor**：支持标量在 Tensor 参数中的代理执行器回退 [PR#191380](https://github.com/pytorch/pytorch/pull/191380)，修复 `_local_scalar_dense` 在精简模式下的回退 [PR#191254](https://github.com/pytorch/pytorch/pull/191254)。

### 4. Dynamo 图捕获与守卫系统
提升图捕获覆盖率，修复嵌套图断裂，重构守卫基础设施。
*   **图捕获改进**：支持 `datetime.datetime.now()` 追踪 [PR#191583](https://github.com/pytorch/pytorch/pull/191583)，支持列表子类 `__new__` [PR#191512](https://github.com/pytorch/pytorch/pull/191512)，支持 `min/max` 的 `key` 参数 [PR#191401](https://github.com/pytorch/pytorch/pull/191401)。
*   **嵌套图断裂修复**：修复 `mark_static_input` 在非张量 VT 上的崩溃 [PR#191264](https://github.com/pytorch/pytorch/pull/191264)，修复空 `nn.Module` 钩子字典问题 [PR#191388](https://github.com/pytorch/pytorch/pull/191388)。
*   **守卫系统重构**：将 `install_guard` 和 `Source` 子类迁移到 `torch._guards` 包 [PR#191525](https://github.com/pytorch/pytorch/pull/191525) 等，为解耦守卫系统做准备。
*   **符号形状**：修复子图复用中 SymInt 输入的对象标识匹配问题 [PR#191806](https://github.com/pytorch/pytorch/pull/191806)。

### 5. 新硬件后端支持 (ROCm, XPU, MPS)
持续改进 AMD、Intel 和 Apple 硅的支持与 CI 稳定性。
*   **ROCm**：修复 CUDA guard 误报 [PR#191870](https://github.com/pytorch/pytorch/pull/191870)，跳过 MI200 的 fp16 精度问题 [PR#191869](https://github.com/pytorch/pytorch/pull/191869)，添加 gfx950 FlyDSL Grouped GEMM [PR#191475](https://github.com/pytorch/pytorch/pull/191475)。
*   **XPU**：添加 `_addmm_activation` 到低精度转换策略 [PR#191802](https://github.com/pytorch/pytorch/pull/191802)，支持 SYCL IPC 内存共享 [PR#191725](https://github.com/pytorch/pytorch/pull/191725)，融合 `gelu/relu` 到 oneDNN matmul [PR#191431](https://github.com/pytorch/pytorch/pull/191431)。
*   **MPS**：添加 `torch.mps.Stream` 和上下文管理器 [PR#191415](https://github.com/pytorch/pytorch/pull/191415)，修复复杂 `bmm` 的静默错误结果 [PR#191835](https://github.com/pytorch/pytorch/pull/191835)，修复 macOS 26 的 MPP 预填充注意力 [PR#191794](https://github.com/pytorch/pytorch/pull/191794)。
