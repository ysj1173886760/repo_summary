# Pull Request Digest for pytorch/pytorch (20260720-20260727)

本周共 554 个 PR，最显著趋势为**测试基础设施的大规模加速器无关化迁移（50+ PR 全部转向 `torch.accelerator` / `instantiate_device_type_tests`），同时 Inductor 内核融合、分布式 nccl2 后端强化及 Dynamo 追踪优化密集推进**。活跃领域：① 测试加速器泛化 (50+)，② Inductor 编译与融合 (60+)，③ 分布式通信 / 后端 (30+)，④ Dynamo 动态编译 (25+)，⑤ ROCm 支持与 CI (20+)。

## 分类摘要

### 1. Inductor & AOTInductor
- **融合与调度**：引入 `masked_store` 与近尺寸 reduction epilogue 融合 [PR#190925], [PR#190926]；实现连续分块 sub‑parent reduction 融合 [PR#190594], [PR#190595], [PR#190596]；支持 NVGEMM 多输出及分组 reduction epilogue [PR#190643], [PR#190810], [PR#190817]。
- **AOTI CUDA Graph**：激活 cpp wrapper 中 `cudagraph_mgr_->run_partition()` 代码生成，使 AOTI 模型默认开启 CUDA Graph [PR#190981], [PR#190982], [PR#190983]；增加错误码检查散列/ index_put 回退 shim [PR#190909], [PR#190910]。
- **Triton 后端**：支持自动 TMA（`PromoteLoadToTMA`）在静态/快速 launcher 中的描述符传递 [PR#190967]；Blackwell `tl.dot(two_ctas=True)` 及 auto‑WS knobs 进入 max‑autotune GEMM 空间 [PR#190767], [PR#190768], [PR#190769]。
- **向量化与精度**：CPU 代码生成使用 Sleef `expm1` 避免精度损失 [PR#190533]；`add` 空输出替换为 `empty_strided` [PR#190530]；带符号整型算术在 CPU 代码中包转为无符号再回 [PR#191132]。
- **FlyDSL 模板体系**：新增 FlyDSL 模板编译基础设施与 `torch.mm` 自动调优 [PR#190902], [PR#190903]。

### 2. 分布式 (c10d / NCCL / FSDP)
- **nccl2 后端功能**：支持 `split_group`、`gather_single`，暴露 `commConfig` 到 Python [PR#190943], [PR#191067], [PR#191068]；为单 op P2P 包裹 `ncclGroupStart/End` 修复事件顺序 [PR#190622]；集合同步 barrier 在 host 侧阻塞 [PR#190682]。
- **故障与调试**：迁移 flight recorder 到 `FlightRecorderHook` 架构并覆盖 nccl2/nccl‑lazy [PR#190738]；添加后端无关的 NaN 检查钩子 [PR#191064]；`TORCH_DISTRIBUTED_DEBUG=DETAIL` 自动启用 C++ 栈追踪 [PR#191075]。
- **功能性集合**：`all_reduce` 支持 `premul_sum`、`min`/`max` 及 `avg` 反向传播 [PR#190942], [PR#191114], [PR#190630]；`reduce_scatter` 支持 `avg` 反向 [PR#191115]。
- **FSDP2**：修复非 DP‑mesh 梯度 all‑reduce 未应用 `reduce_dtype` 的问题 [PR#190627]。
- **对称内存**：nccl2 通过注册钩子发布 host comm 到对称内存 [PR#191109]；MemPool slot 失配时快速失败避免静默错误 [PR#191004]。
- **进程组生命周期**：`new_group(use_local_synchronization=True)` 与 `split_group` 统一返回 `NON_GROUP_MEMBER` [PR#190588], [PR#190725]。

### 3. Dynamo & torch.compile
- **常量优化**：延迟常量支持一元运算、二元按位/比较及内置函数（`len`, `str` 等），减少无意义的 guard 与重编译 [PR#191143], [PR#191144], [PR#191145]。
- **追踪正确性**：支持 `requires_grad` 属性赋值于编译区域内创建的 tensor [PR#191129]；`static_method` 上直接应用 `torch.compile` [PR#190673]；修复 `torch.autograd.Function.apply` 融入 graph 且非 tensor 输出被丢弃的问题 [PR#191030]。
- **性能与开销**：将 `autograd.Function.apply` 包装移至 C++ 并内联属性名以减少调用开销 [PR#190694], [PR#190695]；默认关闭 `record_runtime_overhead` 消除每调用的 marker 开销 [PR#190623]。
- **预编译与序列化**：`CompilePackage.install()` 避免全局名重用导致的 `NameError` [PR#191128]；修复透明 tensor 子类预编译 guard 序列化 [PR#190576]。
- **系统监控**：添加基于 `sys.monitoring` 的替代帧钩子机制 [PR#190733]。

### 4. ROCm 与 AMD GPU
- **新后端**：gfx1250 TDM（Tensor Data Mover）测试分支，支持稠密 `mm`/`addmm` 及 OCP FP8 缩放矩阵乘法 [PR#191166]；FlyDSL 原生 RMS‑Norm（前向+反向）与 topk 重载 [PR#191164], [PR#190843], [PR#190849]。
- **基础设施**：启用 `hipFile` 及 GDS 测试 [PR#191069]；设备 kernel assert 使用 OCKL 扁平字面路径 [PR#191062]；修复 `Module.to(meta)` 错误信息保留 C++ 栈 track [PR#191151]。
- **精确度与元数据**：ROCm 7.14+ 更新 `log10`、`sampled_addmm` 支持表 [PR#191155]；MIOpen convolution 开启 TF32 [PR#190711]；禁用仅 gfx1250 架构下的 CK GEMM/SDPA [PR#190683]。
- **CI**：新增 `periodic-rocm-mi350` 多 GPU 分布式测试支持 [PR#190680]；`trunk-rocm-sandbox` 接入 amd‑vtr 实验 runner [PR#191031]。

### 5. CUDA 与 GPU 系统
- **CUDA Graph**：增加 replay 开始/结束 hook 及图销毁回调 [PR#190602], [PR#190570], [PR#190582]；支持无条件子图节点 [PR#191022]。
- **内存与 IPC**：可扩展段 Win32 NT handle IPC 路径 [PR#190978]；`ExpandableSegment` 清理时避免 `std::get<int>` 在 fabric handle 上的崩溃 [PR#190860]；移除 `masked_fill_` 中禁止 graph 捕获的 host 同步 [PR#190512]。
- **新特性**：CUDA 13.4 Green Context 地域域支持 [PR#190656]；`sm_107` (Rubin) 初步支持 [PR#190654]；`_scaled_mm` 恢复对 float8 输出 `scale_result` 的处理 [PR#190979]。
- **精度与算法**：`cumsum` 启用确定性模式时路由至碎片化浮点扫描确保可复现 [PR#190980]；`avg_pool2d` 反向在无重叠窗口时采用专用 fast path [PR#191086]。

### 6. MPS
- **Reduction 重写**：全新 Metal reduction 栈：内维度、跨步/批量外维度、argmin/argmax、min/max 从 MPSGraph 迁至 Metal [PR#191097], [PR#191098], [PR#191099], [PR#191100]；跳过不必要的输入 up‑cast 与 vec4 全 reduction [PR#191101]；修复 int64 min/max 在部分 simdgroup 下的错误 [PR#191104]。
- **其他**：小整数范围 `linspace` 使用 float 内核加速 [PR#191060]；`uniform` 上界舍入对齐 [PR#190931]；长序列 SDPA bf16 精度通过分块+fp32 Q 恢复 [PR#190791]。

### 7. Profiler
- **CUPTI 改进**：在 CUDA graph 销毁时清理 graph‑node 注册表 [PR#190851]；为 .pftrace 导出绘制 CUDA graph 节点依赖箭头 [PR#190850]；修复 PM 采样中垃圾时间戳导致的 `OverflowError` [PR#191066]；仅发出低 32 位 node id 到 chrome trace [PR#191119]。
- **功能**：`profile_all_threads` 下内存报告现在可正常工作 [PR#190871]；自定义 inductor chrome trace 逻辑移入专用 trace handler [PR#190787]。
