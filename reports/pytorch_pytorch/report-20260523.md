# Pull Request Digest for pytorch/pytorch (20260516-20260523)

**关键要点**：本周最显著的趋势是围绕 `torch.compile` 和 `Inductor` 的深度正确性修复与性能优化，共涉及 796 个 PR。最活跃的领域依次为：1. `module: inductor` (编译后端与代码生成)，2. `module: dynamo` (动态图捕获与追踪)，3. `release notes: export` (模型导出与序列化)，4. `release notes: mps` (Apple Metal 后端)，5. `module: rocm` (AMD GPU 支持)。

### 1. 核心组件与特性
*   **Dynamo (动态图捕获)**
    *   **正确性修复**：修复了 `.grad` 读取、`torch.Size` 构造、`autograd.Function` 重复输入、`set`/`dict` 操作语义、`hasattr` 及 `torch.compiler.disable` 类型注解等一系列问题 [PR#184972](https://github.com/pytorch/pytorch/pull/184972), [PR#184618](https://github.com/pytorch/pytorch/pull/184618), [PR#184281](https://github.com/pytorch/pytorch/pull/184281), [PR#184766](https://github.com/pytorch/pytorch/pull/184766), [PR#184712](https://github.com/pytorch/pytorch/pull/184712), [PR#184947](https://github.com/pytorch/pytorch/pull/184947)。
    *   **性能与内存**：通过运行完整 GC 释放编译期 CUDA 内存 [PR#184969](https://github.com/pytorch/pytorch/pull/184969)；优化 `FunctionIdSet` 使用弱引用避免内存泄漏 [PR#184920](https://github.com/pytorch/pytorch/pull/184920)；为无 guard 的缓存命中提供快速路径 [PR#184683](https://github.com/pytorch/pytorch/pull/184683)。
    *   **新特性**：支持 `ConstDict` 的动态键查找 [PR#184858](https://github.com/pytorch/pytorch/pull/184858)；支持 `record_function` 装饰器 [PR#184703](https://github.com/pytorch/pytorch/pull/184703)；支持 `exec` 简单常量语句 [PR#184040](https://github.com/pytorch/pytorch/pull/184040)。

*   **Inductor (编译后端)**
    *   **性能优化**：启用循环重排序融合 [PR#184314](https://github.com/pytorch/pytorch/pull/184314)；为 Gram 矩阵添加对角对称 Triton 模板 [PR#184886](https://github.com/pytorch/pytorch/pull/184886)；支持 Stream-K 矩阵乘法后端 [PR#184302](https://github.com/pytorch/pytorch/pull/184302)；优化 `foreach` 组合内核 [PR#184323](https://github.com/pytorch/pytorch/pull/184323)；为小 CUDA 归约使用两步方差计算 [PR#184383](https://github.com/pytorch/pytorch/pull/184383)。
    *   **正确性修复**：修复了 `int64` 索引表达式溢出 [PR#184492](https://github.com/pytorch/pytorch/pull/184492)、`ModularIndexing` 语义 [PR#184392](https://github.com/pytorch/pytorch/pull/184392)、`grid_sampler_2d` 使用 `int32` 索引 [PR#184269](https://github.com/pytorch/pytorch/pull/184269) 以及 `index_add`/`index_copy` 分解的形状检查 [PR#184373](https://github.com/pytorch/pytorch/pull/184373), [PR#184338](https://github.com/pytorch/pytorch/pull/184338)。
    *   **新特性**：为 `torch.cond` 和 `torch.while_loop` 添加 AOTI 双包装器支持 [PR#184736](https://github.com/pytorch/pytorch/pull/184736)；支持 `get_attr` 模式匹配 [PR#184419](https://github.com/pytorch/pytorch/pull/184419)；添加 Helion 后端 [PR#184909](https://github.com/pytorch/pytorch/pull/184909)。

*   **AOTAutograd**
    *   修复了前向输出被反向突变覆盖 [PR#184938](https://github.com/pytorch/pytorch/pull/184938)、扩展输出切线步长处理 [PR#184519](https://github.com/pytorch/pytorch/pull/184519) 以及输入别名布局 guard [PR#184481](https://github.com/pytorch/pytorch/pull/184481) 等问题。

### 2. 硬件后端
*   **ROCm (AMD GPU)**
    *   移除了 `bf16`/`fp16` 矩阵乘法精度跳过的版本上限 [PR#184962](https://github.com/pytorch/pytorch/pull/184962)；修复了 `test_origami` 自动调优比较 [PR#184389](https://github.com/pytorch/pytorch/pull/184389)；为 MI350 上的 `topk` 跳过 CUDA Graphs [PR#184265](https://github.com/pytorch/pytorch/pull/184265)；将 AOTriton 升级至 0.12b [PR#184288](https://github.com/pytorch/pytorch/pull/184288)。

*   **MPS (Apple Metal)**
    *   **性能大幅提升**：为 `torch.unique` [PR#184780](https://github.com/pytorch/pytorch/pull/184780)、`bincount` [PR#184779](https://github.com/pytorch/pytorch/pull/184779) 和 `torch.roll` [PR#184778](https://github.com/pytorch/pytorch/pull/184778) 实现了原生 Metal 内核，带来了数个数量级的加速。
    *   **正确性修复**：修复了 `sort` 越界索引 [PR#184620](https://github.com/pytorch/pytorch/pull/184620)、`cholesky` 的 NaN 处理 [PR#184588](https://github.com/pytorch/pytorch/pull/184588) 以及 `std`/`var` 对空输入的处理 [PR#184510](https://github.com/pytorch/pytorch/pull/184510)。

*   **CPU**
    *   修复了向量化 `logit` 的 clamp 优先级 [PR#184733](https://github.com/pytorch/pytorch/pull/184733) 和整数除零溢出 [PR#184497](https://github.com/pytorch/pytorch/pull/184497)；为 `torch.trace` 添加了 `Half` 和 `BFloat16` 支持 [PR#184874](https://github.com/pytorch/pytorch/pull/184874)；修复了 `fp8` 量化线性层在无 AMX 的 x86 CPU 上的段错误 [PR#184317](https://github.com/pytorch/pytorch/pull/184317)。

*   **XPU (Intel GPU)**
    *   修复了反射/复制填充的输出内存格式 [PR#184484](https://github.com/pytorch/pytorch/pull/184484)；为 SDPA 添加了 flash attention 前向分发 [PR#184724](https://github.com/pytorch/pytorch/pull/184724)；无条件强制执行确定性算法 [PR#184565](https://github.com/pytorch/pytorch/pull/184565)。

### 3. 分布式
*   **DTensor**: 修复了 `_StridedShard` 偏移量导致的 `PendingUnbackedSymbolNotFound` 错误 [PR#184945](https://github.com/pytorch/pytorch/pull/184945)；为 `local_map` 添加了 pytree 感知 [PR#184483](https://github.com/pytorch/pytorch/pull/184483)；修复了 `to_local()` 丢失 `nn.Parameter` 标记的问题 [PR#184422](https://github.com/pytorch/pytorch/pull/184422)。
*   **分布式通信**: 为 `new_group` 添加了自定义 PG 子类委托 [PR#184262](https://github.com/pytorch/pytorch/pull/184262)；移除了对称内存对 NCCL PG 的显式依赖 [PR#184260](https://github.com/pytorch/pytorch/pull/184260)；为 XPU PG 路由了 `_set_pg_timeout` [PR#184767](https://github.com/pytorch/pytorch/pull/184767)。

### 4. 导出 (Export)
*   修复了动态维度在 0/1 样本大小时的问题 [PR#184837](https://github.com/pytorch/pytorch/pull/184837)；支持 `linspace`/`logspace` 的 `SymInt` 步长 [PR#184939](https://github.com/pytorch/pytorch/pull/184939)；修复了 `torch.cond` 分支中的张量常量问题 [PR#184667](https://github.com/pytorch/pytorch/pull/184667)；在 C++ 中反序列化 PT2 模式以加速加载 [PR#184787](https://github.com/pytorch/pytorch/pull/184787)。

### 5. 其他
*   **文档**: 修复了 `torch.addcdiv` 公式 [PR#184885](https://github.com/pytorch/pytorch/pull/184885)；明确了 `torch.searchsorted` 的未定义行为 [PR#184888](https://github.com/pytorch/pytorch/pull/184888)；为 `torch.compiler` 的 `backward_pass_autocast` 添加了警告 [PR#184839](https://github.com/pytorch/pytorch/pull/184839)。
*   **构建/CI**: 添加了 Python 3.15 的 wheel 构建 [PR#184600](https://github.com/pytorch/pytorch/pull/184600)；修复了 `torch_version` 生成 [PR#184786](https://github.com/pytorch/pytorch/pull/184786)；将 `docker-builds` 工作流迁移至 OSDC [PR#184664](https://github.com/pytorch/pytorch/pull/184664)。
