**PR 统计**：共 601 个（已合并 202 · 进行中 195 · 草稿 173 · 已关闭 31），另有 22 个机器人 PR 未计入

## 本周概览
本周重点围绕 Inductor 编译性能优化、MPS 数值精度修复、分布式文档与 API 规范化展开。FlexAttention/FlexGEMM 在 Blackwell 架构上持续获得模板融合与性能调优，Dynamo 的 precompile 序列化/反序列化健壮性大幅增强，MPS 端修复了多个复数运算和 SVD 的精度问题。

**最活跃领域**：1. inductor；2. dynamo；3. mps；4. distributed (c10d/fsdp)；5. rocm
