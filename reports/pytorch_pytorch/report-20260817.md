# Pull Request Digest for pytorch/pytorch (20260810-20260817)

**本周框架开发动态**：测试基础设施重构（硬件分类与加速器泛化）几乎贯穿全部 PR，同时 Dynamo/Inductor 编译性能与正确性修复高发，分布式 NCCL2 迁移持续推进，MPS 后端修复密集，CI 管线多项关键优化。本周共处理 937 个 PR。

**最活跃领域**：
1. 测试重构（硬件分类、`hw_classification`、`instantiate_device_type_tests`）
2. Dynamo/Inductor（性能、正确性、缓存）
3. 分布式（NCCL2、FSDP、弹性、checkpoint）
4. MPS 后端（死代码清理、性能修复、诊断）
5. CI & 构建（B200 覆盖、Manywheel 分拆、GPU 覆盖检查）

---

### 1. 测试重构：硬件分类与加速器泛化

- 本轮成千上百的 PR 为各测试文件添加了 `hw_classification = HardwareClassification.GENERIC/ACCELERATOR/CUDA`，并大量使用 `instantiate_device_type_tests` 替换硬编码设备字符串。例如 [PR#193716] 重构 `TestAsArray`，[PR#193701] 泛化 `test_autograd` 等。
- 新能力框架 `@requires_capabilities(Capability.lib.triton)` 被广泛引入，替代 `@requires_gpu` 等旧装饰器（如 [PR#193296]、[PR#193077]）。
- 分布式测试中大量启用 `requires_world_size` 兼容 NPU/HPU/XLA 等外部后端（[PR#192694]）。
- 引入硬件分类 test linter 和 GPU 覆盖检查（[PR#193229]），防止测试丢失在 CI 烟雾列表中。

### 2. Dynamo & Inductor

- **缓存与元编程加速**：[PR#193697] 使 Dynamo 帧缓存并发安全；[PR#193289] 延迟 full GC 以减少编译暂停；[PR#193219] 缓存符号二元运算结果（99.4% 重复）；[PR#193158] 避免不必要的 `reindex` 等，多项编译期优化落地。
- **正确性**：[PR#193660] 修复浮点求和 signed‑zero 语义；[PR#193268] 禁止 CUDAGraph 跨越代的错误复用；[PR#193708] 避免图清理误删 placeholders。
- **Inductor 新特性**：
  - [PR#193208]‑[PR#193199] 扩展严格数值模式至 `prod`、`logsumexp`、`mean`、`vector_norm` 等，保证内树归序与 eager 比特一致。
  - [PR#193614] 支持动态对齐 Triton kernel 运行时分发，减少性能损失。
  - [PR#193598] 为 AOTI C++ 包装器启用嵌套归约融合。
- **FlexAttention / FlexGEMM**：[PR#193631] 使 varlen 注意力遵守 `sdpa_kernel` 后端选择；[PR#193459] 支持 inline asm 在 FlexAttention 中使用；[PR#193468] 修复 CuteDSL 位移和 pack>1 asm。

### 3. 分布式（c10d, FSDP, 弹性, Checkpoint）

- **NCCL2 迁移与修复**：[PR#193744] 在 ROCm 上跳过 NCCL2 重配置测试；[PR#193237] 绑定 local rank 避免启动冲突；[PR#193239] 释放未使用的 Function Work 结果；[PR#193686] 修复 FSDP2 reduce‑scatter 输出流记录。
- **FSDP / DCP 重构**：[PR#193442]‑[PR#193441] 使 FSDP 测试设备无关；[PR#193262]‑[PR#193384] 添加硬件分类；[PR#193000]‑[PR#193013] 量子化测试标注。
- **弹性 & 工具**：[PR#193663] 修复 `find_free_port` 未初始化变量；[PR#193666] 修复 FileStore 文件描述符泄露。
- **Checkpoint**：[PR#193566] 修复 meta/fake 设备加载时 storage 共享丢失；[PR#193010] 按存储偏移排序读取请求。

### 4. MPS 后端

- **死代码清理**：系列 PR [PR#193730]‑[PR#193734] 移除 MPSGraph 旧代码、JIT 编译偏移生成器等。
- **修复与性能**：[PR#193623] 修复 conv2d backward 对 channels_last 的性能（提升约 1.3x）；[PR#193167] Metal kernel 加速 conv3d 权重变换；[PR#193385] 修复 macOS 14 上 `out=` slice 产生的垃圾输出。
- **诊断**：[PR#193572] 添加命令缓冲区故障诊断环境变量（默认关闭）。
- **新操作**：[PR#193153] 支持 native `_int_mm`；[PR#193737] 用双‑单精度计算 `arange` 以匹配 CPU 舍入。

### 5. CI & 构建

- **Blackwell (B200) 覆盖**：[PR#193739] 将微基准测试拆分为 per‑operator 矩阵以加速（从 7.5h 到 ~143min）；[PR#193647] 引入 pytest‑xdist；[PR#193471] 添加 B200 设备信息图。
- **许多wheel 构建**：[PR#193234] 将 manywheel 构建/测试/上传拆分为独立 per‑arch 链，消除尾延迟。
- **GPU 覆盖检查**：[PR#193229] 添加 `gpu‑coverage` 作业，要求添加 H100/B200 测试时必须修正烟雾列表。
- **其他**：ROCm 预览通道 nightly 构建 [PR#193185]；cuDNN 9.25 升级 [PR#193247]；Docker 镜像编译器升级 [PR#193636]；修复 Windows CUDA 构建 randomtemp 下载 [PR#193225]。

### 6. 硬件后端：CUDA, ROCm, XPU

- **CUDA**：[PR#193645] 加速 CPU sort 操作（打包 value/index）；[PR#193016] 修复 layer_norm 大 M 场景下 gamma/beta 梯度越界；[PR#193046] 使 cuBLAS workspace 与 graph capture 共存。
- **ROCm**：[PR#193291] 修复跨 CTA 归约潜在错误结果（丢失 acquire fence）；[PR#193321] 类似修复；[PR#193585] 在 RDNA4 (gfx1200/1201) 启用 CK SDPA；[PR#193339] 将 ROCm 基准测试工作流拉齐至 CUDA。
- **XPU**：[PR#193399] 添加 XPUEvent IPC 支持；[PR#193477] 修复 LinearCrossEntropyLoss 测试 XPUT 容忍度。
