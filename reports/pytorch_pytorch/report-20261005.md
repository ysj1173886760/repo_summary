# Pull Request Digest for pytorch/pytorch (20260928-20261005)

**PR 统计**：共 673 个（已合并 184 · 进行中 265 · 草稿 166 · 已关闭 58），另有 13 个机器人 PR 未计入

## 本周概览
本周 PyTorch 在 MPS 后端全面迁移至 Metal 内核、Inductor 异步编译优化、Dynamo 嵌套图断点默认启用以及分布式 NCCL2 重构方面取得显著进展。同时，ROCm 稳定性修复、CUDA 图序列化探索和测试设备无关化重构也在持续推进。

**最活跃领域**：1. Inductor；2. MPS；3. Dynamo；4. 分布式；5. ROCm

## 重点进展
- **MPS 算子全面迁移至 Metal 内核**：卷积、上采样、排序等核心算子改用 Metal 实现，大幅减少 MPSGraph 依赖并提升性能，同时修复了 bf16 argmax/argmin 等精度问题 [#198878](https://github.com/pytorch/pytorch/pull/198878) [#198960](https://github.com/pytorch/pytorch/pull/198960) [#199278](https://github.com/pytorch/pytorch/pull/199278) [#199687](https://github.com/pytorch/pytorch/pull/199687)
- **Inductor 组合内核基准测试异步编译**：将组合内核的基准测试编译提交至异步进程池，消除调度线程阻塞，加速编译流程 [#198881](https://github.com/pytorch/pytorch/pull/198881) [#198970](https://github.com/pytorch/pytorch/pull/198970)
- **Dynamo 默认启用嵌套图断点**：在 OSS 中默认开启嵌套图断点，改善复杂模型的图捕获能力，并修复了相关边界情况 [#198950](https://github.com/pytorch/pytorch/pull/198950) [#198949](https://github.com/pytorch/pytorch/pull/198949)
- **分布式 NCCL2 后端增强**：新增 `comm_ptr` 属性以兼容旧接口，并移植了非阻塞的通信器收缩/增长快速路径，提升动态扩展效率 [#198865](https://github.com/pytorch/pytorch/pull/198865) [#198887](https://github.com/pytorch/pytorch/pull/198887) [#199240](https://github.com/pytorch/pytorch/pull/199240) [#199263](https://github.com/pytorch/pytorch/pull/199263)
- **修复 CUDA 内存高效注意力机制的竞态条件**：补全缺失的 `cp.async` 排空操作，解决了 Ampere/Ada/Blackwell GPU 上非确定性 NaN 问题 [#198922](https://github.com/pytorch/pytorch/pull/198922)
