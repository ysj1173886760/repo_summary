# Pull Request Digest for pytorch/pytorch (20260509-20260516)

**关键要点**：本周大量由自动化 Agent（主要为 `jansel` 的 ghstack）生成的 PR 涌入，集中修复 Inductor 在 CUDA/ROCm/XPU 上的数值精度、动态形状与编译稳定性问题。共计 801 个 PR，最活跃领域为：1) Inductor 编译器核心与代码生成, 2) Dynamo 图捕获与跟踪, 3) 分布式训练（DTensor/FSDP/c10d）, 4) 硬件后端适配（ROCm/CUDA/MPS/XPU）。

---

### 1. Inductor 编译器核心修复与优化
- **数值精度与数学库对齐**：大量 PR 修复 Inductor 与 eager 模式在 CUDA/ROCm 上的数值偏差，包括 `gelu` backward 使用 opmath dtype [PR#183985](https://github.com/pytorch/pytorch/pull/183985)、`atan` CUDA 数值匹配 [PR#183984](https://github.com/pytorch/pytorch/pull/183984)、`log` 通过 libdevice 严格数值 [PR#183844](https://github.com/pytorch/pytorch/pull/183844)、`frac` 分解保留有符号零 [PR#183640](https://github.com/pytorch/pytorch/pull/183640)。
- **动态形状与未限定符号整数**：强化对 `unbacked symint` 的处理，如 FlexAttention 动态形状 chunk 支持 [PR#183838](https://github.com/pytorch/pytorch/pull/183838)、稳定内存规划测试 [PR#184005](https://github.com/pytorch/pytorch/pull/184005)、符号步幅排序使用 hint [PR#183840](https://github.com/pytorch/pytorch/pull/183840)、延迟运行时断言避免未定义符号 [PR#183908](https://github.com/pytorch/pytorch/pull/183908)。
- **融合与代码生成**：广播归约拆分 [PR#184006](https://github.com/pytorch/pytorch/pull/184006)、拆分扫描与归约融合禁止 [PR#183653](https://github.com/pytorch/pytorch/pull/183653)、C++ 循环拆分对齐 [PR#183715](https://github.com/pytorch/pytorch/pull/183715)、分桶传递优化与编译时间加速 [PR#183619](https://github.com/pytorch/pytorch/pull/183619)。
- **算子特异性修复**：`unfold_backward` 重叠窗口分解 [PR#183996](https://github.com/pytorch/pytorch/pull/183996)、`embedding_renorm` 负索引规范化 [PR#183998](https://github.com/pytorch/pytorch/pull/183998)、`conv` bias 视图 lowering [PR#183642](https://github.com/pytorch/pytorch/pull/183642)、`set_.source_Tensor` 视图源处理 [PR#183724](https://github.com/pytorch/pytorch/pull/183724)、`scatter_add` TMA 核分配 [PR#183479](https://github.com/pytorch/pytorch/pull/183479)。
