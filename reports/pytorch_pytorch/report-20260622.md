# Pull Request Digest for pytorch/pytorch (20260615-20260622)

411个PR揭示的趋势集中于**MPS后端大规模算子原生Metal化以消除MPSGraph形状缓存瓶颈，以及Inductor编译器对多硬件后端（ROCm/CDNA、XPU）的架构特定调优和分布式对称内存零拷贝路径的落地**。活跃领域依次为：① MPS原生内核迁移与修复，② Inductor编译器优化，③ Dynamo追踪与守卫系统修复，④ 分布式训练，⑤ ROCm后端适配。

1. **关键趋势与技术主题**
   - **MPS原生Metal内核迁移**：多个PR组成系列（`#187455`），将`softmax`/`log_softmax`/`cross_entropy`、`mse_loss`/`smooth_l1_loss`/`huber_loss`、`nll_loss`、`binary_cross_entropy`、`prod`、`var/std`等损失与规约算子从MPSGraph迁移至手写Metal shader，[PR#187456](https://github.com/pytorch/pytorch/pull/187456)、[PR#187457](https://github.com/pytorch/pytorch/pull/187457)、[PR#187458](https://github.com/pytorch/pytorch/pull/187458)、[PR#187553](https://github.com/pytorch/pytorch/pull/187553)、[PR#187556](https://github.com/pytorch/pytorch/pull/187556)、[PR#187557](https://github.com/pytorch/pytorch/pull/187557)、[PR#187559](https://github.com/pytorch/pytorch/pull/187559)、[PR#187787](https://github.com/pytorch/pytorch/pull/187787)、[PR#187788](https://github.com/pytorch/pytorch/pull/187788)等密集提交，消除动态形状下的图缓存无限增长和性能悬崖。
   - **Inductor编译器架构调优**：ROCm CDNA架构（MI300/MI350）引入NHWC卷积默认通道和`decide_layout_opt`乘法器校准，[PR#187606](https://github.com/pytorch/pytorch/pull/187606)、[PR#187622](https://github.com/pytorch/pytorch/pull/187622)；XPU后端补充设备数据表与路由修正[PR#187308](https://github.com/pytorch/pytorch/pull/187308)、[PR#187315](https://github.com/pytorch/pytorch/pull/187315)；同时Blackwell相关修复[PR#187371](https://github.com/pytorch/pytorch/pull/187371)、Triton内核命名截断与编译隔离[PR#187641](https://github.com/pytorch/pytorch/pull/187641)、[PR#187408](https://github.com/pytorch/pytorch/pull/187408)。
   - **Dynamo核心语义修复**：聚焦图断裂、属性查找与守卫生成，[PR#187782](https://github.com/pytorch/pytorch/pull/187782)跳过无用函数输入守卫，[PR#187708](https://github.com/pytorch/pytorch/pull/187708)移除`GetAttrVariable`，[PR#187631](https://github.com/pytorch/pytorch/pull/187631)修复列表推导式段错误，[PR#187532](https://github.com/pytorch/pytorch/pull/187532)纠正`__getattr__`/`__getattribute__`语义，以及一系列清理`BaseListVariable`、`call_obj_hasattr`的重构。
   - **分布式训练零拷贝与可组合性**：`TokenSwitch`通过NCCL对称内存实现专家并行分发/合并零拷贝[PR#187785](https://github.com/pytorch/pytorch/pull/187785)、[PR#187805](https://github.com/pytorch/pytorch/pull/187805)，并支持expert-major布局[PR#187784](https://github.com/pytorch/pytorch/pull/187784)；`all_gather_offset`参数连续all-gather[PR#187642](https://github.com/pytorch/pytorch/pull/187642)；FSDP2部分卸载策略[PR#187620](https://github.com/pytorch/pytorch/pull/187620)、`spmd_types`注解恢复[PR#187394](https://github.com/pytorch/pytorch/pull/187394)；后端注册入口点[PR#187388](https://github.com/pytorch/pytorch/pull/187388)与Python后端trampoline[PR#187479](https://github.com/pytorch/pytorch/pull/187479)。
   - **ROCm/XPU CI与适配**：ROCm CI添加gfx950镜像[PR#187464](https://github.com/pytorch/pytorch/pull/187464)，hipify映射`CUBLAS_COMPUTE_16F`[PR#187752](https://github.com/pytorch/pytorch/pull/187752)；XPU增加BMG客户端目标[PR#187421](https://github.com/pytorch/pytorch/pull/187421)、修复LSTM oneDNN集成[PR#187334](https://github.com/pytorch/pytorch/pull/187334)以及multiprocess测试跳过[PR#187314](https://github.com/pytorch/pytorch/pull/187314)。
