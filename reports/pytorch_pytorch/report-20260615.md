# Pull Request Digest for pytorch/pytorch (20260608-20260615)

本周共有 **562** 个活跃 PR。  
最突出的趋势是 **MPS 后端从 MPSGraph 向原生 Metal 内核的大规模算子迁移** 与 **FlexGEMM/QuACK 灵活 GEMM epilogue 融合基础设施的密集迭代**，同时 Dynamo 针对大模型推理的缓存与 guard 延迟优化显著增强。

**Top 活跃领域**：  
1. MPS Metal 内核迁移  
2. Inductor (FlexGEMM/QuACK, TMA, AOTI, combo kernel)  
3. Dynamo (guard/cache 优化, 迭代器 polyfill, 方法分发)  
4. XPU / ROCm (combo 裁切, CUTLASS 优雅降级, CK 架构分级)  
5. Distributed (DTensor, FSDP2, ProcessGroup trampoline)  
6. 分布式 / C10D (NCCL 守卫, 新 collective 方法)  
7. Profiler (CUPTI monitor, refcount 修复)  
8. CUDA (cuDNN 启发式, topk 稳定, SDPA 溢出)  
9. Export / compile (non\_strict\_compile, dynamic\_shapes, safetensors)  
10. RNG 设备无关化 (torch.accelerator)

---

### 1. MPS 后端算子迁移至 Metal
- `argmin/argmax` [PR#187304](https://github.com/pytorch/pytorch/pull/187304)、`log_sigmoid` [PR#187228](https://github.com/pytorch/pytorch/pull/187228)、`sigmoid_backward` [PR#187151](https://github.com/pytorch/pytorch/pull/187151)、`median/nanmedian` [PR#187060](https://github.com/pytorch/pytorch/pull/187060)、`index_add/index_select` [PR#187109](https://github.com/pytorch/pytorch/pull/187109)、`lu_factor` [PR#187038](https://github.com/pytorch/pytorch/pull/187038)、`upsample nearest` [PR#186989](https://github.com/pytorch/pytorch/pull/186989)、`Binomial` [PR#187078](https://github.com/pytorch/pytorch/pull/187078) 等大量算子从 MPSGraph 迁移至手工 Metal 内核，带来数倍乃至数十倍的性能提升，并消除诸多精度问题。
- Cholesky 分解采用 panel factorization + `matmul2d` trailing update [PR#187022](https://github.com/pytorch/pytorch/pull/187022)，性能提升 1.2–3 倍。
- 关键修复：`argmax/argmin` 非连续输入崩溃 [PR#187051](https://github.com/pytorch/pytorch/pull/187051)、NaN 传播错误 [PR#187039](https://github.com/pytorch/pytorch/pull/187039)、`fill_` 字节视图对齐 [PR#186821](https://github.com/pytorch/pytorch/pull/186821)、二元运算 CPU 标量偏移 [PR#187229](https://github.com/pytorch/pytorch/pull/187229)、`fft` 高维 partial dims 崩溃 [PR#186896](https://github.com/pytorch/pytorch/pull/186896)、以及 `functorch` 下丢失 MPS dispatch key 导致 autocast 失效 [PR#187282](https://github.com/pytorch/pytorch/pull/187282)。

### 2. Inductor：FlexGEMM/QuACK 与 AOTI/TMA
- **FlexGEMM**：新增 dense QuACK tuning [PR#187108](https://github.com/pytorch/pytorch/pull/187108)、swap\_ab 方向 sweep [PR#187259](https://github.com/pytorch/pytorch/pull/187259)、BMM 支持 [PR#187218](https://github.com/pytorch/pytorch/pull/187218)、captured tensor epilogue 参数 [PR#187254](https://github.com/pytorch/pytorch/pull/187254) 等，构建完整的 MoE/MLP 融合路径。
- **辅助输出**：`FlexGEMM` 支持 1 个辅助返回 [PR#187278](https://github.com/pytorch/pytorch/pull/187278)，并计划变长辅助输出 [PR#187285](https://github.com/pytorch/pytorch/pull/187285)。
- **Host-side TMA**：B200 GEMM 模板 [PR#186752](https://github.com/pytorch/pytorch/pull/186752)、pointwise TMA [PR#187184](https://github.com/pytorch/pytorch/pull/187184) 以及 pointwise kernel host TMA [PR#186904](https://github.com/pytorch/pytorch/pull/186904)，降低内核负载。
- **AOTI**：新增 `torch.non_strict_compile` [PR#187258](https://github.com/pytorch/pytorch/pull/187258)、默认开启输入 rank 检查 [PR#186898](https://github.com/pytorch/pytorch/pull/186898)、SDPA 走 dispatcher 以支持 PrivateUse1 覆写 [PR#186920](https://github.com/pytorch/pytorch/pull/186920)、最小用户流支持 [PR#186609](https://github.com/pytorch/pytorch/pull/186609)。
- **combo kernel**：动态 persistent reduction 维度修复 [PR#187275](https://github.com/pytorch/pytorch/pull/187275)、超大型 reduction 拆分 [PR#186668](https://github.com/pytorch/pytorch/pull/186668)、RBLOCK 缩放 [PR#186957](https://github.com/pytorch/pytorch/pull/186957)。
- **其他**：`reorder_for_locality` 训练图 [PR#186643](https://github.com/pytorch/pytorch/pull/186643)、`cat_linear` 融合 [PR#187074](https://github.com/pytorch/pytorch/pull/187074)、RMSNorm smem budget 回退 [PR#186941](https://github.com/pytorch/pytorch/pull/186941)、FlexAttention shared memory 编译提示 [PR#186880](https://github.com/pytorch/pytorch/pull/186880)。

### 3. Dynamo：Guard 延迟与功能增强
- **Guard 优化**：`partial memo` 快路径 [PR#187249](https://github.com/pytorch/pytorch/pull/187249) 和 `guard lookup fast paths` [PR#187004](https://github.com/pytorch/pytorch/pull/187004) 显著降低大型 `nn.Module` 树的 cache lookup 开销。
- **迭代器**：`itertools.chain/zip_longest/islice` 原生实现 [PR#186973](https://github.com/pytorch/pytorch/pull/186973), [PR#186974](https://github.com/pytorch/pytorch/pull/186974), [PR#186975](https://github.com/pytorch/pytorch/pull/186975) 替代 polyfill 以减少编译时间；添加 `itertools.combinations` polyfill [PR#187080](https://github.com/pytorch/pytorch/pull/187080)。
- **方法分发**：`MethodTrampolineVariable` [PR#187113](https://github.com/pytorch/pytorch/pull/187113) 统一方法调度，`object_generic_getattr` 成为 VT 默认 getattr [PR#187196](https://github.com/pytorch/pytorch/pull/187196)。
- **类型支持**：`object()` 构造 [PR#186976](https://github.com/pytorch/pytorch/pull/186976)、`contextvars.ContextVar.get()` [PR#186965](https://github.com/pytorch/pytorch/pull/186965)、protobuf enum 成员访问 [PR#187032](https://github.com/pytorch/pytorch/pull/187032)、`deque.__init__` [PR#187128](https://github.com/pytorch/pytorch/pull/187128)、`range`/`slice` 参数 `__index__` 强制 [PR#187129](https://github.com/pytorch/pytorch/pull/187129)。
- **集合与字典正确性**：fix dict/set key 自定义 `__eq__` [PR#186669](https://github.com/pytorch/pytorch/pull/186669)、set subclass 比较 guards [PR#186763](https://github.com/pytorch/pytorch/pull/186763)、dict/set 构建不再 rehash [PR#186759](https://github.com/pytorch/pytorch/pull/186759)、`remove/discard` key 规范化 [PR#186761](https://github.com/pytorch/pytorch/pull/186761) 等。
- **其他**：`non_strict_export` 修复 vmap tensor 索引 [PR#186894](https://github.com/pytorch/pytorch/pull/186894)、dynamic size-1 重编译 [PR#186893](https://github.com/pytorch/pytorch/pull/186893)、`raw unbacked SymInt` 输入 [PR#187273](https://github.com/pytorch/pytorch/pull/187273)、`fake/proxy views` 恢复 [PR#186859](https://github.com/pytorch/pytorch/pull/186859)、`custom op` fake 失败触发 graph break [PR#186923](https://github.com/pytorch/pytorch/pull/186923)。
