# Pull Request Digest for pytorch/pytorch (20260622-20260629)

本周共 447 个 PR，最显著的趋势是围绕 Inductor 峰值内存优化与可配置融合策略的系统性提交，以及 Dynamo 守卫性能的深度改进。活跃领域集中在 1) Inductor 编译器优化、2) Dynamo 守卫与缓存、3) MPS 后端、4) ROCm 修复、5) 分布式与 DTensor。

### 1. Inductor 编译器优化
- **峰值内存控制**：引入 `allow_peak_memory_increasing_fusion` 配置开关 [PR#187840]，并实现一组细粒度融合约束（避免跨外部融合 [PR#187842]、避免不相交水平融合 [PR#187841/#188058]、避免晚期输出垂直融合 [PR#187843] 等），同时改进缓冲区复用策略以降低峰值压力 [PR#187846]。
- **组合内核与代码生成**：组合内核编译时自动调优默认开启 [PR#188119]，支持子内核独立调优 [PR#187961]；修复与组合内核峰值内存相关的 KeyError [PR#188203]；C++ wrapper 支持带 `Any` 参数的 fallback ops [PR#188124]。
- **持久化约简**：使用分块感知提示选择持久化方式 [PR#188179]，复用全范围分片以保持公共表达式 [PR#188180]。
- **CUDA Graph 改进**：支持对用户可见输出进行克隆 [PR#188078/#188161]，允许将改变 CUDA Graph 管理的输入降级为拷贝输入以避免重复录制 [PR#188161]。
- **其他**：修复 NVGEMM 线程安全及冗余重编译 [PR#188303]；C++ wrapper 宿主编译耗时纳入专用计时器 [PR#187936]；启用 `invoke_subgraph` 内图分区 [PR#188126]。

### 2. Dynamo 守卫与缓存
- **递归字典标签守卫**：默认开启（3.12+ 非自由线程）[PR#188103]，通过 `PyDict_Watch` 安全检测字典变更 [PR#188101]；添加守卫评测基准 [PR#187868]。
- **对象别名守卫**：从 Python lambda 迁移至 C++ 实现以降低开销 [PR#187992]。
- **符号形状守卫**：避免每个符号分配元组 [PR#187883]；将 `nn.Module` 的 float 属性特殊化以减小守卫开销 [PR#187882]。
- **重编译隔离**：强化测试以捕获隔离回归 [PR#187885]。
- **其他**：修复 `str.split/rsplit/splitlines` 返回可变列表问题 [PR#188306]；支持 `deque` 的 `copy`/`__copy__` [PR#188220]；支持 `range_iterator` 的 `__setstate__` [PR#188221]；将 `random.random` 路由至 `RandomVariable` [PR#188235]；支持异常对象的自定义属性 [PR#188105]。

### 3. MPS 后端
- **内核迁移**：`argmin/argmax` 从 MPSGraph 迁移至 Metal [PR#188160]；`prod` 约简迁移至原生 Metal 内核 [PR#188156/#188333]；`mish` 迁移至 Metal [PR#187906]；`ctc_loss` 添加反向传播 [PR#188187]。
- **性能与正确性**：同 dtype 连续拷贝和 `cat` 改用计算编码器以恢复性能 [PR#188200]；更好的内存分配器设计 [PR#188045]；修复 BatchNorm channels_last 反向崩溃 [PR#188371]；修复 `conv2d` 在大 kernel size 下输出错误 [PR#188359]；在注意力核中传播 NaN [PR#188147]；支持 `flex_attention` 的 `return_aux(max_scores=True)` [PR#188362]。
- **其他**：移除对 macOS 14 的支持 [PR#188365]。

### 4. ROCm 后端
- **正确性**：修复 `torch.pdist` 正确性问题并重新启用测试 [PR#188006]；修复变长 flash-attention LSE 返回格式以匹配 CUDA [PR#187899]；修复 hipBLASLt FP32 在 MI300X 上的精度退化 [PR#188168]。
- **CUDA Graph 安全**：将 MIOpen 卷积算子加入 `FORBIDDEN_CUDAGRAPH_OPS` 列表 [PR#188357]。
- **流与内存**：根据 `hsa_queue` 数量限制 HIP 流池大小 [PR#188316]；修复 round-robin 计数器重置问题 [PR#188252]。
- **Flex Attention**：默认启用 `PRESCALE_QK` 并自动检测连续块 [PR#188095]；重新启用 Inductor-Triton 调试断言 [PR#188075]。
- **其他**：支持 ROCm 7.14 的 Address Sanitizer [PR#188242]；更新 hipCUB 兼容 CCCL 版本 [PR#188072]；修复 GFX 等待指令 [PR#188067]。

### 5. 分布式与 DTensor
- **NCCL 集成**：集成 `ncclScatter` 和 `ncclGather` [PR#188321/#188320]。
- **FSDP2**：支持每参数 FQN 卸载策略和预算助手 [PR#188120]；添加 MORI SDMA all-gather 后端及零拷贝输出 [PR#188276]。
- **DTensor**：添加 FFT c2c 的分片策略 [PR#188369]；修复 `local_map` 的分片维度规范化 [PR#188188]；`distribute_module` 文档字符串改进 [PR#188071]；启用 XPU 上的可追踪 DTensor RNG 操作 [PR#187969]。
- **Compile-on-one-rank**：设备无关的 Inductor 代码生成和启动器 [PR#187870]；将标志移至 `torch.compiler.config` [PR#187869]。
- **其他**：添加 `_watchdog` 超时服务 [PR#187878]；修复 `isend`/`irecv` 传递全局 rank 问题 [PR#187924]；`ShardedTensor` 设备转移方法硬件无关化 [PR#187939]。

### 6. 高阶算子 (HOP)
