# Pull Request Digest for pytorch/pytorch (20260831-20260907)

**PR 统计**：共 605 个（已合并 277 · 进行中 164 · 草稿 99 · 已关闭 65），另有 20 个机器人 PR 未计入

## 本周概览
本周集中在 Inductor/Dynamo 的编译正确性与性能优化，包括 scaled addmm 公开 API、Blackwell TMA BMM 模板、TorchFunctionMode 追踪支持；MPS 继续大规模 Metal 化并修复 SVD 正确性；ROCm 与分布式在 CK、NCCL、FSDP2 上有多项稳定性改进。

**最活跃领域**：1. Inductor/Dynamo；2. MPS；3. ROCm；4. Distributed；5. CUDA

## 重点进展
- **scaled addmm 公开 API 与编译集成**：新增 `scaled_addmm` 功能/原地 API，并接入 Dynamo/Inductor，支持 cuBLASLt 的 scaled-mm recipe，用于 WGRAD 累积等场景 [#195408](https://github.com/pytorch/pytorch/pull/195408) [#195409](https://github.com/pytorch/pytorch/pull/195409) [#195410](https://github.com/pytorch/pytorch/pull/195410)
- **Dynamo 完善 TorchFunctionMode/autograd.Function 追踪**：支持 `handle_torch_function`、monkey-patched `Function.apply`、`has_torch_function` 语义及类行为，显著提升自定义 dispatch 的编译覆盖 [#196044](https://github.com/pytorch/pytorch/pull/196044) [#196045](https://github.com/pytorch/pytorch/pull/196045) [#196046](https://github.com/pytorch/pytorch/pull/196046) [#196047](https://github.com/pytorch/pytorch/pull/196047) [#196048](https://github.com/pytorch/pytorch/pull/196048)
- **CUDA graph 内存管理**：引入 per-device `CUDAGraphMemory` 跟踪，将 active-capture 计数从 caching allocator 中解耦，为后续 graph-deferred 生命周期管理打基础 [#195510](https://github.com/pytorch/pytorch/pull/195510)
- **Blackwell persistent TMA BMM 模板**：新增 config-gated 的 rank-3 BMM 模板与有界 autotuning 选择，支持 TMA descriptor 和 2CTA/decompose-K 变体 [#195808](https://github.com/pytorch/pytorch/pull/195808) [#195780](https://github.com/pytorch/pytorch/pull/195780)
- **MPS SVD 正确性修复**：修复 Jacobi SVD 的 Metal 编译崩溃、共轭/列主序输入错误及秩亏时 U 非正交问题，并移除小输入 CPU 回退 [#195949](https://github.com/pytorch/pytorch/pull/195949) [#195950](https://github.com/pytorch/pytorch/pull/195950) [#196128](https://github.com/pytorch/pytorch/pull/196128) [#196139](https://github.com/pytorch/pytorch/pull/196139)
