# Pull Request Digest for pytorch/pytorch (20260831-20260907)

**关键要点**
- 本周 613 个 PR 的最显著趋势是：Dynamo/Inductor 编译器栈与分布式训练后端（FSDP2/NCCL/DTensor）围绕大规模模型（MoE、Blackwell、TorchTitan）进行深度端到端优化与硬件适配。
- 顶级活跃领域：1. `dynamo` 图捕获/追踪与类型化；2. `inductor` 代码生成、调度与自动调优；3. 分布式 c10d/FSDP2/DTensor；4. 硬件后端（ROCm/XPU/MPS/CUDA）；5. 测试重构与 CI；6. AOTInductor/导出；7. Profiler。

---

**1. 编译器栈：Dynamo / Inductor / AOTAutograd**
- **Dynamo 追踪与语义修复（ezyang 系列）**：为 `__torch_function__`/`TorchFunctionMode`、`autograd.Function` 类（`hasattr`/`issubclass`/`super().__init__` 等）提供内联支持，避免 graph break；`AutogradFunctionVariable` 现在正确解析 `cls.apply`，并支持被 monkey-patch 的 `Function.apply`（[PR#196049](https://github.com/pytorch/pytorch/pull/196049)、[PR#196059](https://github.com/pytorch/pytorch/pull/196059)、[PR#196048](https://github.com/pytorch/pytorch/pull/196048)、[PR#196040](https://github.com/pytorch/pytorch/pull/196040)）。
- **`precompile` 多图捕获/服务（bobrenjc93 系列）**：引入 `torch.compiler.precompile` 公开捕获入口、guard 状态序列化与诊断，支持多图 artifact 安装与负载（[PR#195921](https://github.com/pytorch/pytorch/pull/195921)、[PR#195924](https://github.com/pytorch/pytorch/pull/195924)、[PR#195929](https://github.com/pytorch/pytorch/pull/195929)）。
- **`compile_on_one_rank`（aorenste 系列）**：修复缓存键中的设备索引、RNG 状态、报错与 RNG 关键字参数，使多 rank 编译产物可跨 rank 复用（[PR#196146](https://github.com/pytorch/pytorch/pull/196146)、[PR#196153](https://github.com/pytorch/pytorch/pull/196153)、[PR#196152](https://github.com/pytorch/pytorch/pull/196152)）。
- **类型化改进**：将 Dynamo/Inductor 内部多处 `Any` 替换为 `object`（[PR#196176](https://github.com/pytorch/pytorch/pull/196176)、[PR#196175](https://github.com/pytorch/pytorch/pull/196175)、[PR#196135](https://github.com/pytorch/pytorch/pull/196135)、[PR#196054](https://github.com/pytorch/pytorch/pull/196054)、[PR#196021](https://github.com/pytorch/pytorch/pull/196021)）。
- **Inductor 严格数值模式**：新增 `numerics="strict"` 下与 eager 位级对齐的 `relu`/`neg`/`sigmoid`/`hypot`/`log_ndtr` 等修复（[PR#196029](https://github.com/pytorch/pytorch/pull/196029)-[PR#196039](https://github.com/pytorch/pytorch/pull/196039)）。
- **AOTAutograd/AOTI**：`compile_to_python` 支持训练（[PR#195885](https://github.com/pytorch/pytorch/pull/195885)）；AOTI 包加载按需模型与路径归一化（[PR#196026](https://github.com/pytorch/pytorch/pull/196026)、[PR#196023](https://github.com/pytorch/pytorch/pull/196023)）；`TORCHINDUCTOR_LITE_MODE` 全 fallback CI（[PR#195880](https://github.com/pytorch/pytorch/pull/195880)、[PR#196076](https://github.com/pytorch/pytorch/pull/196076)）。

**2. 分布式：c10d / NCCL / FSDP2 / DTensor**
- **NCCL/后端生命周期**：`WorkNCCL` 事件缓存改为弱引用，避免 `destroy_process_group` 后 use-after-free（[PR#195485](https://github.com/pytorch/pytorch/pull/195485)）；修复 `NCCL4PyBackend` 子通信器绑定到错误 GPU（[PR#195766](https://github.com/pytorch/pytorch/pull/195766)）；`setBackend` 缺少后端时不再解引用（[PR#195536](https://github.com/pytorch/pytorch/pull/195536)）；`nccl_all_gather_offset` 改用 `get_window_offset`（[PR#195588](https://github.com/pytorch/pytorch/pull/195588)）。
- **FSDP2**：为访问已 reshard 释放的 storage 数据指针新增诊断/报错（[PR#195862](https://github.com/pytorch/pytorch/pull/195862)、[PR#196009](https://github.com/pytorch/pytorch/pull/196009)、[PR#196019](https://github.com/pytorch/pytorch/pull/196019)）；支持 per-parameter compute-dtype 混合精度（[PR#195946](https://github.com/pytorch/pytorch/pull/195946)）。
- **DTensor/其他**：修复 CPU offloading 导致 RNG 状态重置（[PR#196072](https://github.com/pytorch/pytorch/pull/196072)）；保留 zero-size op 在图形捕获中的一致性（[PR#195641](https://github.com/pytorch/pytorch/pull/195641)）；`all_gather_object` 使用 `all_gather_single` 减少 d2d/cat（[PR#196185](https://github.com/pytorch/pytorch/pull/196185)）；新增 Python 分布式传输注册表及 TCP/UCXX/RDMA 后端（d4l3k 系列 [PR#195643](https://github.com/pytorch/pytorch/pull/195643)-[PR#195648](https://github.com/pytorch/pytorch/pull/195648)）。
- **分散工具**：修复 `FileStore` 文件描述符泄漏（[PR#195711](https://github.com/pytorch/pytorch/pull/195711)、[PR#196096](https://github.com/pytorch/pytorch/pull/196096)）；`find_free_port` 异常时隐藏 `UnboundLocalError`（[PR#195710](https://github.com/pytorch/pytorch/pull/195710)）。
