# Pull Request Digest for pytorch/pytorch (20260803-20260810)

**关键要点**：本周最显著的趋势是测试基础设施的大规模重构，持续推进硬件分类（`hw_classification`）与设备无关化改造，共涉及 **715** 个 PR，主要活跃领域为：1. 测试重构与硬件分类、2. Inductor 编译器、3. 分布式训练、4. Dynamo、5. ROCm/HIP、6. MPS、7. CUDA 特性、8. Bug 修复、9. XPU 支持、10. CI/CD 与构建。

---

### 1. 测试基础设施重构（硬件分类与设备无关化）
- 大量 PR 为测试类添加 `hw_classification` 属性（`GENERIC` / `ACCELERATOR` / `CUDA` / `CPU` 等），并迁移至 `instantiate_device_type_tests` 模式，以支持多后端设备无关运行。
- 典型 PR：
  - [PR#192714] 为 `test_scaled_matmul_cuda.py` 添加 `ACCELERATOR` 分类。
  - [PR#192713] 将 `test_max_autotune` 迁移至 `instantiate_device_type_tests`。
  - [PR#192712] 为 FSDP 冻结权重测试添加 `ACCELERATOR` 标签。
  - [PR#192711] 解耦 `test_codecache.py` 中的 CUDA 硬编码。
  - [PR#192710] 为 Dynamo 测试添加 `GENERIC` 分类。
  - [PR#192708] 等系列 PR 为 Dynamo 动态规格、字典、推导式等测试添加硬件分类。
- 分布式测试也大量迁移至能力门控（`requires_capabilities`）替代 `skip_if_lt_x_gpu`，如 [PR#192701] 等 FSDP 系列。
- 新增 `hw_available_devices` 属性用于声明所需设备数量（[PR#192360]）。
