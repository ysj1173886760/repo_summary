# Pull Request Digest for pytorch/pytorch (20260713-20260720)

**关键要点：** 本周最显著的趋势是围绕 `torch.accelerator` 和 `PrivateUse1` 的硬件抽象层（HAL）测试重构大规模铺开，同时 Inductor 在 NVGEMM、组合内核和确定性模式上持续进行深度性能优化。共 662 个 PR，最活跃的领域依次为：1. 测试基础设施与硬件分类 2. Inductor 编译器 3. MPS 后端 4. 分布式（c10d/DTensor） 5. Dynamo 性能与追踪。

### 1. 测试基础设施与硬件分类 (Tests & Hardware Abstraction)
*   **硬件分类 (`hw_classification`) 大规模落地**：大量 PR 为测试类添加 `hw_classification` 属性，以区分 `GENERIC`、`MULTI_ACCELERATOR` 等类别，并引入新的 `HW_CLASSIFICATION` linter 强制检查 [PR#190173](https://github.com/pytorch/pytorch/pull/190173)。
*   **去 CUDA 硬编码**：数十个测试文件将 `torch.cuda` 调用替换为 `torch.accelerator` 或 `torch.get_device_module`，并启用 `PrivateUse1` 测试，覆盖分布式、ONNX、FX 等模块 [PR#190507](https://github.com/pytorch/pytorch/pull/190507), [PR#190422](https://github.com/pytorch/pytorch/pull/190422)。
*   **分布式测试泛化**：引入 `skip_if_lt_x_devices` 替代 `skip_if_lt_x_gpu`，重构 FSDP、DTensor 等测试以支持多加速器 [PR#190309](https://github.com/pytorch/pytorch/pull/190309), [PR#190695](https://github.com/pytorch/pytorch/pull/190695)。

### 2. Inductor 编译器 (Inductor Compiler)
*   **NVGEMM 后端增强**：支持 `addmm` 的 epilogue 融合，通过 `swap_ab` 优化小 M 维度，迁移至 `cutlass.operators` API，并启用子进程预编译 [PR#189774](https://github.com/pytorch/pytorch/pull/189774), [PR#189771](https://github.com/pytorch/pytorch/pull/189771), [PR#189772](https://github.com/pytorch/pytorch/pull/189772)。
*   **组合内核 (Combo Kernel) 优化**：引入编译时自动调优、内存峰值感知的融合守卫，并支持统一分发策略 [PR#190384](https://github.com/pytorch/pytorch/pull/190384), [PR#190344](https://github.com/pytorch/pytorch/pull/190344), [PR#189733](https://github.com/pytorch/pytorch/pull/189733)。
*   **Triton 内核改进**：使用原生 NaN 传播的 min/max，支持标量累加器，并为用户自定义 Triton 内核修复代码生成 [PR#190404](https://github.com/pytorch/pytorch/pull/190404), [PR#190207](https://github.com/pytorch/pytorch/pull/190207), [PR#190341](https://github.com/pytorch/pytorch/pull/190341)。
*   **确定性模式控制**：新增 `deterministic_ops` 配置，允许细粒度控制算子确定性行为 [PR#190265](https://github.com/pytorch/pytorch/pull/190265)。

### 3. MPS 后端 (MPS Backend)
*   **内存与分配器**：引入统一内存地址作为数据指针，并添加 placement heaps 以减少碎片 [PR#190373](https://github.com/pytorch/pytorch/pull/190373), [PR#190438](https://github.com/pytorch/pytorch/pull/190438)。
*   **算子修复与补全**：修复 `layer_norm` 混合精度、`embedding_bag` 边界检查、`linear` 零特征维度崩溃等问题，并实现 `logspace`、`linalg.polar` 等新算子 [PR#190055](https://github.com/pytorch/pytorch/pull/190055), [PR#190183](https://github.com/pytorch/pytorch/pull/190183), [PR#190495](https://github.com/pytorch/pytorch/pull/190495)。
*   **性能优化**：为 `prelu` 迁移至 Metal 内核，并启用计算编码器的并发调度 [PR#189703](https://github.com/pytorch/pytorch/pull/189703), [PR#189785](https://github.com/pytorch/pytorch/pull/189785)。

### 4. 分布式 (Distributed)
*   **c10d 后端增强**：集成 `ncclGather`，添加 PyBackend 蹦床以支持 Python 子类化，并修复 `destroy_process_group` 挂起问题 [PR#190159](https://github.com/pytorch/pytorch/pull/190159), [PR#189817](https://github.com/pytorch/pytorch/pull/189817), [PR#190431](https://github.com/pytorch/pytorch/pull/190431)。
*   **DTensor 与 RNG**：引入无状态 RNG 视图和布局，支持 `reduce_scatter` 的 Dynamo 追踪，并修复 `all_reduce` 的 `avg` 归约反向传播 [PR#190447](https://github.com/pytorch/pytorch/pull/190447), [PR#190429](https://github.com/pytorch/pytorch/pull/190429), [PR#190304](https://github.com/pytorch/pytorch/pull/190304)。
*   **检查点 (DCP)**：支持 `strict=False` 加载，优化子模块前缀过滤，并支持 HF safetensors 存储 [PR#190389](https://github.com/pytorch/pytorch/pull/190389), [PR#189761](https://github.com/pytorch/pytorch/pull/189761), [PR#189945](https://github.com/pytorch/pytorch/pull/189945)。

### 5. Dynamo 与自动微分 (Dynamo & Autograd)
*   **性能优化**：将 `autograd.Function.apply` 包装器移至 C++，减少指令数约 12.8%，并优化 `torch._dynamo.disable` 的调用开销 [PR#190336](https://github.com/pytorch/pytorch/pull/190336), [PR#190392](https://github.com/pytorch/pytorch/pull/190392)。
*   **追踪与修复**：支持 XPU 设备属性常量，修复 `TorchDispatchMode` 导致的永久跳过问题，并添加 `_io.text_encoding` 的 polyfill [PR#190323](https://github.com/pytorch/pytorch/pull/190323), [PR#190287](https://github.com/pytorch/pytorch/pull/190287), [PR#189984](https://github.com/pytorch/pytorch/pull/189984)。

### 6. 其他值得注意的变更
*   **ROCm 平台**：添加 gfx950 的预交错 MX 尺度布局，将 nightly CI 迁移至 MI350，并修复 Python 3.15 构建 [PR#190290](https://github.com/pytorch/pytorch/pull/190290), [PR#190263](https://github.com/pytorch/pytorch/pull/190263), [PR#189722](https://github.com/pytorch/pytorch/pull/189722)。
*   **线性代数**：实现 MAGMA 风格的批量 LU 分解内核，并添加 `linalg.polar` 的反向传播 [PR#190329](https://github.com/pytorch/pytorch/pull/190329), [PR#189732](https://github.com/pytorch/pytorch/pull/189732)。
*   **构建与 CI**：修复 CMake 中的死代码和错误条件，将 manywheel 构建迁移至 OSDC 运行器，并启用 Windows Arm64 CUDA 构建 [PR#190467](https://github.com/pytorch/pytorch/pull/190467), [PR#189818](https://github.com/pytorch/pytorch/pull/189818), [PR#190448](https://github.com/pytorch/pytorch/pull/190448)。
