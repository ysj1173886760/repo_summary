# Pull Request Digest for pytorch/pytorch (20260824-20260831)

## 关键要点

本周最显著的趋势是 PyTorch 测试基础设施的大规模设备无关化重构——通过 `hw_classification` 和 `instantiate_device_type_tests` 系统性解耦测试与 CUDA/ROCm 硬编码，为第三方加速器（XPU、NPU、PrivateUse1）铺路。共 **710 个 PR**，活跃领域：1) 测试重构与设备泛化 2) Dynamo/Inductor 编译器 3) MPS 后端算子补齐 4) ROCm/AMD GPU 5) `torch.compiler.precompile` 新特性 6) 分布式训练 7) CUDA/NVGEMM 内核。

---

## 2. 新功能

### `torch.compiler.precompile`（bobrenjc93 大型 stack）
- 目标：将计算 AOT 编译为可部署的 Python 源码 + 二进制加速缓存产物，对用户透明地加载（`precompile.load`）。
- 核心 PR：[PR#195360](https://github.com/pytorch/pytorch/pull/195360) 实现 Dynamo tracer；[PR#195288](https://github.com/pytorch/pytorch/pull/195288) 支持多示例输入与增量捕获；[PR#195361](https://github.com/pytorch/pytorch/pull/195361) 将训练图前向+反向组合为独立源码。
- 配套硬化：guard 重建与序列化（[PR#195346](https://github.com/pytorch/pytorch/pull/195346)、[PR#195350](https://github.com/pytorch/pytorch/pull/195350)）、帧缓存并发安全（[PR#195355](https://github.com/pytorch/pytorch/pull/195355)）、guard-drop 策略（[PR#195371](https://github.com/pytorch/pytorch/pull/195371)）。

### `scaled_addmm` 公开 API + `torch.compile` 集成（drisspg stack）
- 新增 `torch.nn.functional.scaled_addmm(..., out=...)` 与 `scaled_addmm_` 原位形式（[PR#195409](https://github.com/pytorch/pytorch/pull/195409)）。
- Dynamo/Inductor 支持：Dynamo 图中绑定 functional/mutating 算子，Inductor 通过 external-kernel fallback lowering，并实现 reinplacing（[PR#195410](https://github.com/pytorch/pytorch/pull/195410)）。
- 此前置重构：提取 scaled-matmul 元校验共用逻辑（[PR#195408](https://github.com/pytorch/pytorch/pull/195408)）。

### 其他
- 原生 `aten::associative_scan` 算子（[PR#195218](https://github.com/pytorch/pytorch/pull/195218)）：CPU/CUDA kernel 支持 `add`/`mul`/`max`/`min` 和 Mamba 风格的 `linear_recurrence` combine，服务 SSM/Mamba 与贝叶斯滤波负载。
- 对比学习损失 `nn.InfoNCELoss` 和 `SupConLoss`（[PR#195380](https://github.com/pytorch/pytorch/pull/195380)）。
- `grid_sample` 前向 AD 支持（[PR#195280](https://github.com/pytorch/pytorch/pull/195280)）：2D/3D/cuDNN 路径的 JVP 规则。
- `grid_sample` 5-D bicubic 前向/反向/双反向（[PR#194787](https://github.com/pytorch/pytorch/pull/194787)）。
- AMP BF16 梯度 unscale（[PR#194947](https://github.com/pytorch/pytorch/pull/194947)）。

### 正确性修复
- **循环局部 load CSE lifetime**（[PR#194786](https://github.com/pytorch/pytorch/pull/194786)）：修复间接 load 在 reduction loop 内定义、epilogue 后引用导致的 `NameError`（#194490），已 cherry-pick 到 2.14。
- **argmax/argmin 逻辑索引**（[PR#195063](https://github.com/pytorch/pytorch/pull/195063)）：修复 reduction 融合时返回物理迭代索引而非逻辑 row-major 索引的问题。
- **低精度舍入保持**（[PR#195223](https://github.com/pytorch/pytorch/pull/195223)）：比较操作前保持 fp16/bf16 存储舍入，避免融合 pointwise 产生未舍入中间值。
- **`tl.constexpr` 枚举代码生成**（[PR#194756](https://github.com/pytorch/pytorch/pull/194756)）：`Enum` vs `IntEnum` 的 repr 语义正确处理。
