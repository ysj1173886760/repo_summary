# Pull Request Digest for pytorch/pytorch (20260824-20260831)

## 本周概览
本周主干围绕 `torch.compile` 的全新 precompile/guard 序列化体系密集落地，多个 stack 合入使 artifact 可在进程间可移植地保存与恢复；同时 Inductor 在 CUDA Graph 方向性决策、AOTI C++ wrapper 与核心正确性上做了大量加固。分布式侧重 NCCL backing state 生命周期重构，MPS、ROCm/XPU 及各类 CI/构建问题也有显著进展。

**最活跃领域**：1. Dynamo / precompile；2. Inductor / AOTI；3. 分布式 / NCCL；4. MPS；5. ROCm / XPU
