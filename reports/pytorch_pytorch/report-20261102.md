# Pull Request Digest for pytorch/pytorch (20261026-20261102)

**PR 统计**：共 753 个（已合并 209 · 进行中 302 · 草稿 204 · 已关闭 38），另有 28 个机器人 PR 未计入

## 本周概览
本周主线围绕编译基础设施的完善展开：precompile 流程在多轮迭代中趋于稳定，AOTI 正式获得 CUDA graph 支持；MPS 后端继续向 Metal 大规模迁移，多个 loss 和规约算子完成重写；ROCm 侧集中修复了数值精度、流同步和 profiler 稳定性问题。Dynamo 加强了对字典、描述符等 Python 语义的追踪，分布式方面则完成了 `FakeProcessGroup` 的 Python 化。

**最活跃领域**：1. Inductor / AOTI；2. MPS；3. ROCm；4. Dynamo；5. Distributed；6. CI / Releng

## 重点进展
- **Precompile 流程成熟化**：artifact 现在会导入注册自定义 op 的模块，并在加载时检查 op 已注册；Triton 内核在 capture 期间完成 autotune，C++ 内核的缓存键不再依赖安装路径，使跨机器复用更可靠 [#202257](https://github.com/pytorch/pytorch/pull/202257) [#202258](https://github.com/pytorch/pytorch/pull/202258) [#202255](https://github.com/pytorch/pytorch/pull/202255) [#202254](https://github.com/pytorch/pytorch/pull/202254) [#202430](https://github.com/pytorch/pytorch/pull/202430)
- **AOTI 支持 CUDA graph**：新增 C shim 和运行时 `CudaGraphManager`，提供 `aot_inductor.cudagraphs` 检查与 C API，允许 AOT 编译模型以 CUDA graph 方式运行 [#202181](https://github.com/pytorch/pytorch/pull/202181) [#202182](https://github.com/pytorch/pytorch/pull/202182) [#202183](https://github.com/pytorch/pytorch/pull/202183) [#202186](https://github.com/pytorch/pytorch/pull/202186)
- **MPS 算子批量迁移 Metal**：`prelu`、`mse_loss`、`smooth_l1_loss`、`huber_loss` 等 backward 及 `addmv`/`mv`、`dot`/`vdot`、`unique` 等前向算子从 MPSGraph 切换到 Metal 内核，部分场景性能提升明显 [#202301](https://github.com/pytorch/pytorch/pull/202301) [#202302](https://github.com/pytorch/pytorch/pull/202302) [#202311](https://github.com/pytorch/pytorch/pull/202311) [#202312](https://github.com/pytorch/pytorch/pull/202312) [#202539](https://github.com/pytorch/pytorch/pull/202539) [#202601](https://github.com/pytorch/pytorch/pull/202601) [#202742](https://github.com/pytorch/pytorch/pull/202742)
- **FakeProcessGroup 纯 Python 化**：测试用的 `FakeProcessGroup` 从 C++ 迁移为 Python `PyBackend`，避免每次语义变更需重编译 C++，并修复了 `split_group` 等路径的选项传递 [#202141](https://github.com/pytorch/pytorch/pull/202141) [#202176](https://github.com/pytorch/pytorch/pull/202176) [#202177](https://github.com/pytorch/pytorch/pull/202177) [#202194](https://github.com/pytorch/pytorch/pull/202194)
- **Dynamo 字典语义增强**：新增对字典构造、更新、复制、视图及 `OrderedDict` 顺序的 guards，修复了 `dict` 长度 guard 缺失和 `not` 对用户对象真值处理错误 [#202216](https://github.com/pytorch/pytorch/pull/202216) [#202217](https://github.com/pytorch/pytorch/pull/202217) [#202374](https://github.com/pytorch/pytorch/pull/202374) [#202375](https://github.com/pytorch/pytorch/pull/202375) [#202376](https://github.com/pytorch/pytorch/pull/202376)

## 分领域动态
### Inductor / AOTI
- **Triton 内核冻结**：从未运行过的 autotuned 内核现在用第一个配置冻结，避免 `finalize_cache` 拒绝 [#202065](https://github.com/pytorch/pytorch/pull/202065) [#202074](https://github.com/pytorch/pytorch/pull/202074)
- **FMA 收缩控制**：新增 `triton.enable_fp_fusion` 标志，允许关闭 FMA 以获得 bitwise 确定性 [#202218](https://github.com/pytorch/pytorch/pull/202218)

- **AOTI 常量折叠修复**：修复运行时常量折叠在 buffer 被变异时的错误折叠，以及 inactive refold 失败时恢复活跃常量 [#202807](https://github.com/pytorch/pytorch/pull/202807) [#202479](https://github.com/pytorch/pytorch/pull/202479)
