# Pull Request Digest for pytorch/pytorch (20260601-20260608)

**关键摘要**：本周 687 个 PR 主要聚焦于 `Dynamo`、`Inductor` 和 `AOTAutograd` 的正确性与稳定性修复，核心趋势是编译路径中大量边界条件、符号形状和动态维度问题的收敛。最活跃的技术领域为：1. 编译器前端（Dynamo/torch.compile） 2. 编译器后端（Inductor/Triton/CUTLASS） 3. 导出与序列化（export/AOTI） 4. 分布式（c10d/FSDP/DTensor） 5. 硬件后端（MPS/XPU/ROCm/CUDA） 6. 自动微分与功能化（autograd/functionalization） 7. 测试与 CI。

---

### 1. 编译器前端（Dynamo / `torch.compile`）
- **图断点与恢复改进**：修复 f-string 日志引起的图断点恢复 [PR#186500]、`Parameter.data` 形状变更图断点 [PR#186512]、动态 `ModuleList` 索引图断点 [PR#186472]、以及 `OptimizedModule` 委托方法路由 [PR#186063] 等关键问题。
- **字节码与跟踪增强**：支持 `random.random` [PR#185961]、`random.Random` 重放 [PR#185971]、`time.time` 运行时输入 [PR#186249]；修复 `autograd.Function` 的 vmap 规则 [PR#186330]、`itertools` polyfill [PR#186240]；引入循环展开节点数限制 `max_loop_unroll_nodes` [PR#186539]。
- **符号与动态形状**：修正 `mark_dynamic` 对 `Parameter` 的支持 [PR#186479]、禁止默认 duck sizing 避免误保护 [PR#186373]、修复 `SymInt` 向量签名检测 [PR#186533]、改善 `SymBool` 的 `not` 降级 [PR#186043]。
- **缓存与性能**：使 `CompiledFxGraph` 调用跨线程安全 [PR#186192]，阻止导入时加载可选库 [PR#186044]，修复 lazy compilation 的 cProfile 支持 [PR#186214]。
- **其他修复**：修复 `torch.combinations` 符号尺寸 [PR#186329]、`as_strided_` 元数据传播 [PR#186205]、`torch.kron` 非连续输入 [PR#186334] 等。

### 2. 编译器后端（Inductor / Triton / CUTLASS）
- **NV GEMM（CUTLASS/QuACK）进展**：重大特性 —— 启用 NVGEMM Epilogue 融合（relu/sigmoid/add/mul 等）[PR#186183]，重构代码生成 [PR#186184]，并添加 QuACK GEMM epilogue 适配器 [PR#186483]。同时支持 CUTLASS EVT epilogue 融合穿透 view/reshape [PR#185796] 和 gelu 重组合 [PR#185824]。
- **融合与调度**：修复融合中 fanout 计算 [PR#186534]、CPU 高 fanout 点真实化 [PR#186356]、inplace 决策性能优化 [PR#186101/186095/186096/186097]、以及组合内核每子块配置选择 [PR#186006]。
- **CPU 后端**：修复低精度标量舍入 [PR#185869]、整数除零保护 [PR#186021]、NaN 保留 [PR#186018]、batch_norm erf 数值 [PR#185866]、以及 `as_strided_copy` 越界 [PR#185809]。
- **Triton 后端**：修复卷积反向权重 IMA [PR#186440]、TMA xoffset 陈旧 [PR#186492]、截断除精度 [PR#186252]、负号保留有符号零 [PR#185834]。
- **Halide/其他**：修复 Halide inplace 变异别名读取 [PR#186121]、`conv_transpose2d` Triton 回退 [PR#186116] 等。

### 3. 自动微分与功能化（AOTAutograd / Functionalization）
- **视图与变异支持**：保留功能化 inplace 视图的 autograd 元数据 [PR#186561]、修复 `resize_` 输出变异 [PR#186478]、支持 `cross-device tensor.data = ...` [PR#185980]。
- **子类与导出**：修复嵌套 wrapper subclass 输入 [PR#186342]、`out_dtype` HOP 子类 [PR#185811]、以及 subclass 视图动态元数据 [PR#186409]。
- **正确性修复**：保留依赖输出梯度钩子 [PR#186554]、未使用输出反向剪枝 [PR#186355]、`index_add` 分解越界 [PR#186532]、自定义 op `set_` 存储变异 [PR#186179]、以及联合导出未使用参数梯度 [PR#186542]。

### 4. 导出与 AOTI（torch.export / AOTInductor）
- **符号与动态形状**：修复 size-one 动态维 [PR#186485]、`cond` 分支局部形状断言 [PR#186210]、`SymInt` 绑定保留 [PR#186520]、以及 `torch.combinations` 符号 [PR#186112]。
- **序列化与加载**：AOTI 常量共享存储去重 [PR#186445]、C++ wrapper 符号恢复 [PR#186841]、Windows self-mmap 大小寻址 [PR#186386]、以及 `GraphModule` 序列化修复 [PR#186418]。
- **错误与调试**：提升导出设备不匹配错误 [PR#185892]、自定义 op AOTI 错误信息 [PR#186305]、非严格导出 raw Triton 内核提示 [PR#185827]。

### 5. 分布式（c10d / FSDP / DTensor / Pipeline）
- **API 重命名**：`all_gather_into_tensor` → `all_gather_single`，`reduce_scatter_tensor` → `reduce_scatter_single` 等（[PR#186123] 等系列）。
- **FSDP2**：增加 `set_separate_reduce_scatter_group` 实现 AG/RS overlap [PR#186335]，`set_reduce_scatter_max_input_buffers` 缓解反向阻塞 [PR#186000]。
- **DTensor**：添加 `logspace` [PR#186398]、`scatter` 分片支持 [PR#186149]、修复 conv1d 输出放置 [PR#186129]。
- **其他**：弹性分布式立即刷新脏 rendezvous 状态 [PR#185930]、`c10d` 添加 abort 和 pre/post hook 接口 [PR#186300]。

### 6. 硬件后端
- **MPS**：MPSGraph 矩阵乘 port 到 Metal [PR#186541]；添加 `segment_reduce` [PR#186540]、`lcm` 核 [PR#186279]；修复 LayerNorm 方差 [PR#186367]、`fast::tanh` 溢出 [PR#186286]；改进 im2col/col2im 模板化 [PR#185860]；以及编译 attention 修复 [PR#186399]。
- **XPU**：修复 conv fp16 精度测试 [PR#186581]；oneDNN matmul 确定性默认 [PR#186337]；移除 `max_pool2d_with_indices_backward` workaround [PR#186087]；CUTLASS SiLU epilogue 融合 [PR#186198]。
- **ROCm**：启用 Inductor-Triton debug asserts [PR#186422]；修复 `linalg.qr` float64 崩溃 [PR#185944]；MI200 addmm 容差调整 [PR#186407]；CK flash-attn GQA 修复 [PR#186434]。
- **CUDA**：添加 TunableOp 支持 cublasLt 和 scaled GEMM [PR#186270/186271]；优化 `index_put_`/`copy_to` 避免流同步 [PR#186486/186482/186484]；修复 cuDNN SDPA varlen 反向 [PR#186142]。

- **算子修复**：`torch.ldexp` 负指数梯度 [PR#186569/186566]；`clamp` 边界次梯度规范 [PR#185831]；`multilabel_margin_loss` 分解 [PR#186074]；`torch.kron` 非连续输入 [PR#185913]；`torch.range` 步长零除 [PR#186489]。
