# Pull Request Digest for pytorch/pytorch (20260907-20260914)

**关键趋势**  
本周最显著的趋势是围绕 Dynamo AOT 编译与预编译基础设施的大规模加固，涵盖守卫序列化、跨设备兼容性及 AOTInductor CUDA Graph 区域捕获，同时 MPS 与 ROCm 后端持续获得大量优化与修复。  
**总 PR 数**：613  
**最活跃领域**：  
1. Dynamo / AOT 编译与预编译  
2. Inductor 后端优化（Blackwell、FlyDSL、内存规划、融合）  
3. MPS 后端（Metal 内核迁移、新算子、性能）  
4. ROCm 支持（测试修复、新架构、hipBLASLt、FlyDSL）  
5. 分布式（FSDP2、流水线、c10d、对称内存）  
6. XPU 测试移植与设备无关化  
7. Dynamo CPython 测试移植  

---

**分类摘要**

- **Dynamo / AOT 编译与预编译**  
  - 大规模守卫序列化与函数重建栈（[#196474](https://github.com/pytorch/pytorch/pull/196474), [#196476](https://github.com/pytorch/pytorch/pull/196476), [#196479](https://github.com/pytorch/pytorch/pull/196479), [#196481](https://github.com/pytorch/pytorch/pull/196481), [#196505](https://github.com/pytorch/pytorch/pull/196505) 等），使 `aot_compile` 可安全 pickle 守卫状态。  
  - 模块级 AOT 编译派遣增强：守卫作用域解析、全局变量重绑定、缺失守卫报告（[#196815](https://github.com/pytorch/pytorch/pull/196815), [#196818](https://github.com/pytorch/pytorch/pull/196818), [#196823](https://github.com/pytorch/pytorch/pull/196823), [#196896](https://github.com/pytorch/pytorch/pull/196896)）。  
  - 流与设备秩可移植性（`compile_on_one_rank`）：[#196937](https://github.com/pytorch/pytorch/pull/196937) - [#196940](https://github.com/pytorch/pytorch/pull/196940)。  
  - 随机数重放修复（[#196921](https://github.com/pytorch/pytorch/pull/196921)）、`random.Random` 状态不再被冻结。  
  - 大量 CPython 3.13 测试移植（[#196238](https://github.com/pytorch/pytorch/pull/196238) 系列），覆盖 `test_abc`, `test_string`, `test_hash` 等。

- **Inductor 后端优化**  
  - Blackwell 架构深度集成：TMA 描述符加载/存储、cat/cast 融合、分解-K 规划（[#196857](https://github.com/pytorch/pytorch/pull/196857), [#196858](https://github.com/pytorch/pytorch/pull/196858), [#196516](https://github.com/pytorch/pytorch/pull/196516), [#196517](https://github.com/pytorch/pytorch/pull/196517)）。  
  - AOTInductor CUDA Graph 全图与区域捕获（[#196778](https://github.com/pytorch/pytorch/pull/196778)-[#196841](https://github.com/pytorch/pytorch/pull/196841)），含内存规划与分区调度。  
  - 内存规划增强：`NonOwningLayout` 处理、峰值内存候选（[#196847](https://github.com/pytorch/pytorch/pull/196847), [#196848](https://github.com/pytorch/pytorch/pull/196848)）。  
  - 严格数值模式：逐点运算匹配 eager（[#196789](https://github.com/pytorch/pytorch/pull/196789)-[#196799](https://github.com/pytorch/pytorch/pull/196799)）。  
  - 设备无关化：`pad_mm`、`compile_fx` 设备上下文、TF32 启发式等（[#196260](https://github.com/pytorch/pytorch/pull/196260), [#196307](https://github.com/pytorch/pytorch/pull/196307), [#196556](https://github.com/pytorch/pytorch/pull/196556)）。  
  - 融合改进：循环重排迭代至不动点、子父 epilogue 提升、嵌套 reduction 多 kernel 支持（[#196332](https://github.com/pytorch/pytorch/pull/196332)-[#196335](https://github.com/pytorch/pytorch/pull/196335)）。

- **MPS 后端**  
  - 三元运算全面迁移至 Metal 共享内核，`lerp`/`addcmul`/`addcdiv` 统一，性能提升最高 5 倍（[#196922](https://github.com/pytorch/pytorch/pull/196922)-[#196924](https://github.com/pytorch/pytorch/pull/196924)）。  
  - FP8 支持扩展：`gather`、`eye`、`_scaled_mm`（[#196915](https://github.com/pytorch/pytorch/pull/196915), [#196918](https://github.com/pytorch/pytorch/pull/196918), [#196916](https://github.com/pytorch/pytorch/pull/196916)）。  
  - 稀疏压缩张量启用（[#196205](https://github.com/pytorch/pytorch/pull/196205)），三角求解分块优化（[#196241](https://github.com/pytorch/pytorch/pull/196241)）。  
  - 事件同步与计时可靠性修复（[#196395](https://github.com/pytorch/pytorch/pull/196395)），大量冗余测试清理。

- **ROCm 支持**  
  - FlyDSL 集成：gfx950 GEMM 模板、MXFP8/MXFP4 `scaled_mm`、epilogue 融合、动态形状缓存（[#196261](https://github.com/pytorch/pytorch/pull/196261)-[#196277](https://github.com/pytorch/pytorch/pull/196277), [#196719](https://github.com/pytorch/pytorch/pull/196719)）。  
  - 新硬件支持：MI355X 设备信息、gfx1250 TDM 描述符代码生成（[#196365](https://github.com/pytorch/pytorch/pull/196365), [#196525](https://github.com/pytorch/pytorch/pull/196525)）。  
  - hipBLASLt 修复：CUDA Graph 捕获中句柄创建、工作空间预分配（[#196399](https://github.com/pytorch/pytorch/pull/196399), [#196920](https://github.com/pytorch/pytorch/pull/196920)）。  
  - 大量测试重新启用与稳定性修复（[#196484](https://github.com/pytorch/pytorch/pull/196484), [#196485](https://github.com/pytorch/pytorch/pull/196485), [#196511](https://github.com/pytorch/pytorch/pull/196511) 等）。

- **分布式**  
  - FSDP2 异步梯度最终化与流水线交错（[#196724](https://github.com/pytorch/pytorch/pull/196724), [#196706](https://github.com/pytorch/pytorch/pull/196706)），支持外部梯度累积。  
  - 流水线调度：有向 P2P 组派生、接收缓冲区复用、资源槽着色（[#196464](https://github.com/pytorch/pytorch/pull/196464)-[#196666](https://github.com/pytorch/pytorch/pull/196666)）。  
  - 对称内存：纯 Python SymmemBackend、NVSHMEM 团队复用、信号填充竞态修复（[#196524](https://github.com/pytorch/pytorch/pull/196524), [#196349](https://github.com/pytorch/pytorch/pull/196349), [#196546](https://github.com/pytorch/pytorch/pull/196546)）。  
  - NCCL 等待跨 CUDA Graph 边界修复（[#196919](https://github.com/pytorch/pytorch/pull/196919)），检查点文件系统竞态修复（[#196591](https://github.com/pytorch/pytorch/pull/196591)）。

- **XPU 与设备无关化**
