# Pull Request Digest for pytorch/pytorch (20260907-20260914)

**PR 统计**：共 591 个（已合并 325 · 进行中 150 · 草稿 64 · 已关闭 52），另有 16 个机器人 PR 未计入

## 本周概览
本周主线集中在编译器数值严格性、AOT 产物序列化与 CUDA graph 捕获，以及 FlexGEMM/FlyDSL 等 GEMM 路径扩展。Dynamo 继续大规模移植 CPython 3.13 测试并修复用户可见错误，分布式与 ROCm/MPS 的测试解耦和稳定性工作也很活跃。

**最活跃领域**：1. Inductor / GPU 代码生成；2. Dynamo / torch.compile；3. 分布式训练；4. ROCm / AMD；5. MPS
