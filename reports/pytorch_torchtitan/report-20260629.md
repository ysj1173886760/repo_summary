# Pull Request Digest for pytorch/torchtitan (20260622-20260629)

**关键趋势**：本周 72 个 PR 中，RL 训练栈（权重同步、生成器路由、检查点）与新型并行化方案（`GraphPP` 预编译、`FlexShard`）密集迭代，同时修复了大量模型兼容性与硬件后端问题。  
**活跃领域**：① RL 训练基础设施 ② Graph Trainer 与图编译 ③ 模型支持（DeepSeek V3.2、Qwen3.5、GPT-OSS） ④ 并行化与分片（FlexShard、SPMD 类型、管道并行） ⑤ 硬件后端与量化（ROCm、float8、Helion RoPE）

---

### 1. 新功能与特性
- **Graph Trainer 预编译**：[PR#3815] 为 `GraphPP` 添加预编译支持，实现单进程保存 rank-local 图包，训练时加载并跳过 tracing/partitioning/compilation，端到端 bitwise 一致。
- **FlexShard 灵活分片框架**：[PR#3782] 引入实验性 `FlexShard` API，支持按 bucket 分组参数并分配可插拔 placement；[PR#3783] 使其可被 `torch.compile` 追踪；[PR#3784] 添加 DeepSeek V3 的 eager 训练入口；[PR#3785] 设计 FP8 all-gather 在 `GroupedRaggedShard` 上的方案。
- **DeepSeek V3.2 模型**：[PR#3800] 添加 DeepSeek-V3.2 模型，包含 Lightning Indexer 与 DeepSeek Sparse Attention (DSA)，依赖 [PR#3787]。
- **RL 权重同步优化**：[PR#3810] 将 trainer→generator 的权重同步与下一步训练重叠；[PR#3795] 通过 `StorageVolume` 快照进行异步权重同步，避免直接 RDMA 读取 live tensor。
- **RL 检查点与恢复**：[PR#3751] 实现 RL 训练循环的中断检查点保存与恢复。
- **RL 生成器路由**：[PR#3743] 使 generator actor 感知 DP rank 布局，按 DP 分配请求；[PR#3765] 添加 DP fan-in 机制；[PR#3768] 引入 `DPRequestRouter` 并重构路由策略。
- **SLURM 启动器**：[PR#3748] 为 `torchtitan_rl` 添加 SLURM 启动器（控制器在首个 worker 节点）。
- **成本估算器**：[PR#3798] 为 joint fwd+loss+bwd 图添加静态内存/运行时/传输时间估算器及测试。

### 2. 组件改进
- **RoPE 统一与扩展**：[PR#3787] 统一 `CosSinRoPE` 和 `ComplexRoPE` 的 YaRN 计算；[PR#3767] 为 `ComplexRoPE` 添加 Helion 覆盖。
- **注意力机制**：[PR#3801] 为 Qwen3.5 `GatedDeltaNet` 添加 varlen attention 支持；[PR#3814] 修复 GPT-OSS 的 flex `BlockMask` 构建，使用共享 decoder helper；[PR#3789] 修复 `score_mod` 未传递给 `flex_attention` 的问题。
- **MoE 与 DeepEP**：[PR#3808] 升级至 DeepEP v2 API，支持 cudagraphable 模式；[PR#3799] 探索 DeepEP 低延迟模式用于 cudagraphable MoE；[PR#3769] 修复 `minAsyncMoE` 的 int32 索引溢出；[PR#3771] 修复 Triton 元数据输入连续性。
- **损失与优化**：[PR#3788]/[PR#3813] 支持 GRPO chunked loss；[PR#3812] 修复 dangling backward `seq_nr` 的元数据传播。
- **SPMD 类型后端**：[PR#3762] 在 `resolve_placements` 中规范化 size-1 mesh 轴上的 `Partial`；[PR#3742] 支持不均匀 MoE 序列组合；[PR#3741] 添加 Helion RoPE 和 fused SwiGLU 规则；[PR#3763] 启用 llama3；[PR#3803] 启用 SPMD 后端选择；[PR#3804] 修复 generator 权重同步。
- **量化**：[PR#3781] 修复 scaled bias rowwise linear 在 `inference_mode` 下的 DTensor 重分布问题。

### 3. 硬件后端与兼容性
- **ROCm 支持**：[PR#3738] 从 `has_cuda_capability` 中排除 ROCm，避免错误触发 NVIDIA-only 路径；[PR#3760] 在 ROCm gfx942+ 上启用 float8；[PR#3758] 在 ROCm CI 中跳过 float8 集成测试。
- **PyTorch 版本兼容**：[PR#3811] 使 torchtitan 兼容稳定版 torch 2.12（已关闭，wontfix）。
- **Helion RoPE**：[PR#3767] 为 DeepSeek V3 添加 Helion 加速支持。

### 4. 修复与稳定性
- **管道并行修复**：[PR#3773] 修复 PP 下 varlen attention 的 `cu_seqlens` 损坏；[PR#3777] 禁用 Varlen + PP 组合。
- **权重加载修复**：[PR#3807] 修复 FSDP > n_kv_heads 时 fused qkv 权重加载；[PR#3794] 修复 RL 中 fused qkv 加载 hook 被绕过的问题；[PR#3772] 修复 HF 后端加载预训练 dense 模型时的 RoPE 与权重初始化错误；[PR#3764] 修复权重绑定导致 safetensors 文件损坏。
- **数值与确定性**：[PR#3770] 修复 DSv3 GraphTrainer 多节点 eager bitwise 数值的 bucketing 顺序；[PR#3745]/[PR#3744] 刷新 eager bitwise 确定性基线；[PR#3791] 修复 flex attention trace 与确定性基线测试。
- **其他修复**：[PR#3802] 设置 debug 配置 `drop_zero_std_reward_groups=False` 防止挂起；[PR#3796] 修复模型最大序列长度检查；[PR#3776] 标注 varlen Attention 的 cudagraph 能力；[PR#3737] 提高 GPT-OSS Dynamo 重编译限制；[PR#3753] 修复 TP+SP 下 DTensor scatter；[PR#3747] 尝试修复 `TestLossParallelCrossEntropy` 不稳定问题。

### 5. CI/测试与工程
- **CI 优化**：[PR#3792] 在 feature CI 中跳过 torchcomms 安装；[PR#3774] 在 PyTorch CI 中禁用 qwen3_5；[PR#3746] 避免使用 Meta 内部代码搜索工具；[PR#3766] 在 release candidate 标签上触发 binary wheel 构建；[PR#3754] 升级 GitHub Actions 依赖。
- **测试扩展**：[PR#3740] 将模型集成测试扩展到 `full_dtensor` 和 `spmd_types` 后端；[PR#3805] 使 AutoParallel 测试 GPU 无关，支持 Intel XPU。
- **RL 配置与工具**：[PR#3778] 添加 RL 性能运行配置；[PR#3759] 添加 vllm All-reduce 补丁（手动）；[PR#3749] 切换回 v1 vllm model runner；[PR#3739] 清理 `disable_loss_parallel` 标志。
