# Pull Request Digest for pytorch/torchtitan (20261019-20261026)

**PR 统计**：共 83 个（已合并 36 · 进行中 21 · 草稿 18 · 已关闭 8）

## 本周概览
本周主线是 TorchTitan 0.4.0 发布候选的密集验证与 CI 修复，同时性能优化集中在 MLA/RoPE 编译与 Profiler 可观测性。模型侧继续补齐 Llama3/Kimi 配置正确性，并出现多个新模型与并行策略的 draft。RL 与 GraphTrainer 方向有大量进行中的设计与实现。

**最活跃领域**：1. 发布与 CI；2. 性能与编译；3. 模型与配置；4. RL；5. GraphTrainer

## 重点进展
- **Cuspy profiling 后端**：`Profiler.Config.cuspy` 将 CUDA activity 采集从 Kineto 切换到 Cuspy，支持 PM sampling、环境计数器、sync events、graph dependencies 与可选 Perfetto 输出 [#5525](https://github.com/pytorch/torchtitan/pull/5525)
- **MLA RoPE 性能**：DeepSeek-V3/Kimi K2.5 的 q/k RoPE 在 `mla_qk` 区域内按 int32 对旋转，prefill/train 快 30-36% [#5529](https://github.com/pytorch/torchtitan/pull/5529)
- **模型配置正确性**：修复 Llama3 1B/3B 的 `rope_scaling` 与 Kimi K2.x 的 `rms_norm_eps`，使其与发布 checkpoint 一致 [#5528](https://github.com/pytorch/torchtitan/pull/5528) [#5548](https://github.com/pytorch/torchtitan/pull/5548)
- **FlashAttention 后端安全回退**：FA3/FA4 不可用时自动回退到内置 FA2，避免模型构建 `ModuleNotFoundError` [#5546](https://github.com/pytorch/torchtitan/pull/5546)
- **Muse Spark RL 128 GPU 布局**：FSDP8×TP4×CP4×EP16 替代 256 GPU 布局，减少 expert all-gather/reduce-scatter 跨 rack 流量 [#5581](https://github.com/pytorch/torchtitan/pull/5581)
