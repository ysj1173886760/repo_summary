# Pull Request Digest for pytorch/torchtitan (20260516-20260523)

本周46个PR中，最具影响力的趋势是**MoE架构的深度重构以实现清洁的DTensor边界，同时声明式SPMD分片配置向多模态模型全面推广**。活跃领域集中在：MoE并行化与声明式分片(1)、Graph Trainer编译器优化与稳定性(2)、强化学习异步管线与TITO生成器(3)、FlexShard异构分片布局(4)以及数据管线重构提案(5)。

### 1. MoE架构重构与DTensor边界清理
* 核心重构栈（#3386、#3384、#3389、#3423）：将`shared_experts`移出`TokenDispatcher.combine()`，`GroupedExperts`内部执行`view(-1, dim)`，使Router和共享专家保持3D DTensor（避免边界`StridedShard`），仅路由专家在`GroupedExperts`边界转为local。
* 声明式MoE分片（#3400、#3401）：用`ShardingConfig`替换命令式`apply_moe_ep_tp`，支持全DTensor模式下的sparse FSDP/EP网格。
* 模块化重构（#3398）：移除`Module.from_nn_module`动态类生成，改用显式Module子类以便于分片配置。
* 辅助清理（#3387、#3385、#3383等）：提取`local_reorder`辅助函数，拆分`DeepEPTokenDispatcher`与`HybridEPTokenDispatcher`。

### 2. 声明式SPMD分片与FlexShard扩展
* #3406、#3422：为Qwen3-VL和FLUX模型加入SPMD分片支持，并配置MoE sharding。
* #3399：将Qwen3-VL Vision Encoder转为Module协议并提供声明式dense sharding配置。
* #3407、#3402：引入`GroupedRaggedShard`布局及RaggedShard placement示例，提供灵活的异构参数分桶与视图进出unshard。
* #3417：推进`flex_shard`中的flatshard支持。

### 3. Graph Trainer编译器集成与稳定性
* #3420：实验性离线Triton内核融合工作流（Extract→Generate→Replace），探索FX图算子融合加速。
* #3419：用上游`_move_overlap_nodes`替换`stable_topological_sort`，节点位移从~97%降至~5%，增强可组合性。
* #3397：修复eager SAC策略中全局mm计数器导致的跨层激活重计算不对称问题，恢复逐层行为。
* #3416：兼容上游`BitsetAncestors` API变更，修复`JointManualOverlapScheduler`。
* #3394：重开FlexAttention测试（上游`TransformGetItemToIndex`回归已修复）。
* #3390：将DeepEP安装失败改为非致命，避免H100 CI全线中断。
* #3388：为graph trainer添加XPU后端支持。

### 4. 强化学习(RL)管线
* #3404：引入OPUS异步off-policy多轮管线，用asyncio实现连续rollout和训练分离。
* #3391：生成器改为Token-in/Token-out（TITO），添加生成指标并启用wandb记录。
* #3408：CI中显式禁用wandb，避免无凭证环境失败。

### 5. 数据管线重构提案
* #3415（RFC）：提议用Grain-based的`Op`组合管线替代现有`hf_datasets`/`StatefulDataLoader`，解决处理行为不可配置、text/chat路径重复、恢复逻辑手工复杂等问题。

* RoPE重构：#3395（seq_len超模型上限升为硬错误，修正vLLM wrapper缓存）
* Checkpoint可读性：#3393（重构`torchtitan.components.checkpoint`，清理结构残留）
* 导入兼容：#3414（修复最新DeepEP库的导入路径）
* CI保障：#3403（强制perf运行至少10次迭代，避免Agent默认1次）
