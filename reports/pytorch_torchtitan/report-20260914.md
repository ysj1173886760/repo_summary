# Pull Request Digest for pytorch/torchtitan (20260907-20260914)

**PR 统计**：共 137 个（已合并 99 · 进行中 19 · 草稿 7 · 已关闭 12）

## 本周概览
本周工作围绕模型表示现代化与分布式训练效率两条主线展开：MoE 专家参数被重构为结构化 `GroupedLinear` 并默认启用 fused gate-up/QKV 投影，同时独立 DistMoE 后端完成集成。HSDP 梯度累积、FSDP 对称内存等优化进一步降低通信开销，RegionAC 则通过自注册与模式校验显著提升了可靠性。

**最活跃领域**：1. MoE 与模型架构；2. 分布式训练优化；3. 激活检查点与 RegionAC；4. GraphTrainer 运行时；5. 训练器与流程

## 重点进展
- **MoE 专家投影重构为结构化 GroupedLinear**：`RoutedExperts` 不再使用不透明的 `inner_experts`，改为直接的 `w13`、`w2` 子模块并引入可重用的 `GroupedLinear`，其 W13 布局 `[E, 2, F, D]` 与 DistMoE 原生对齐，门控/上行维度显式可拆分。fused gate-up 和 QKV 投影均已设为默认实现。 [#4647](https://github.com/pytorch/torchtitan/pull/4647) [#4646](https://github.com/pytorch/torchtitan/pull/4646) [#4643](https://github.com/pytorch/torchtitan/pull/4643) [#4535](https://github.com/pytorch/torchtitan/pull/4535) [#4546](https://github.com/pytorch/torchtitan/pull/4546)
- **HSDP 跳过非最后累计步的复制 all-reduce**：`dp_replicate > 1` 时，非最后微批次上的 replicate all-reduce 被取消，仅最终优化器累计组执行，减少了不必要的梯度同步通信。 [#4505](https://github.com/pytorch/torchtitan/pull/4505)
- **RegionAC 区域自注册与模式验证**：模块通过 `register_remat_region` 自声明区域，配置中无效区域名会被捕获并给出可操作的错误，彻底避免拼写错误导致的静默无效配置。 [#4520](https://github.com/pytorch/torchtitan/pull/4520) [#4522](https://github.com/pytorch/torchtitan/pull/4522) [#4523](https://github.com/pytorch/torchtitan/pull/4523)
- **DistMoE 独立后端完成集成**：通过薄适配器将专家计算、内存规划、VMM 等委托给独立包，TorchTitan 保有参数、FSDP 和进程组所有权；已提供 DeepSeek V3 的 BF16 与异步 MXFP8 配方及配套文档。 [#4624](https://github.com/pytorch/torchtitan/pull/4624) [#4625](https://github.com/pytorch/torchtitan/pull/4625) [#4626](https://github.com/pytorch/torchtitan/pull/4626) [#4571](https://github.com/pytorch/torchtitan/pull/4571)

## 分领域动态
### MoE 与模型架构
- **DeepSeek V3/V4 MTP 修复与完善**：MTP 支持 CP [#4544](https://github.com/pytorch/torchtitan/pull/4544)，MTP 调度器和模块协议初始化修复 [#4515](https://github.com/pytorch/torchtitan/pull/4515)，MTP SPMD 输入布局修复（进行中） [#4521](https://github.com/pytorch/torchtitan/pull/4521)。
- **量化平衡路由**：新增 `QuantileBalancedTopKRouter`，为 Kimi K3 MoE 提供量化平衡与共享偏置优化。 [#4577](https://github.com/pytorch/torchtitan/pull/4577)
- **负载均衡与路由钩子**：路由支持 `padding_mask` 以过滤填充令牌统计量 [#4594](https://github.com/pytorch/torchtitan/pull/4594)，暴露 `_compute_scores`/`_normalize_topk_scores` 方法便于定制 [#4609](https://github.com/pytorch/torchtitan/pull/4609)，节点限制路由移至 DeepSeek V3 [#4631](https://github.com/pytorch/torchtitan/pull/4631)。
- **VLM 流水线泛化**：`pipeline_vlm` 重构为 `pipeline_with_first_stage_modules`，支持自定义首阶段模块列表（如 Muse Glimmer）。 [#4560](https://github.com/pytorch/torchtitan/pull/4560)
- **其余模型修复**：VLM 编码器修复 CPU offload 崩溃 [#4512](https://github.com/pytorch/torchtitan/pull/4512)，NoPE 注意力的 rope 配置改为可选 [#4513](https://github.com/pytorch/torchtitan/pull/4513)，词汇并行嵌入修复填充梯度错误 [#4637](https://github.com/pytorch/torchtitan/pull/4637)。

### 分布式训练
- **FSDP 与对称内存**：`enable_fsdp_symm_mem` 现已对 Qwen3.5/Kimi K2.7 生效 [#4562](https://github.com/pytorch/torchtitan/pull/4562)；支持仅对密集 FSDP 模块启用对称内存 [#4642](https://github.com/pytorch/torchtitan/pull/4642)。
- **TP/SP 与 CP 相关修复**：SimpleFSDP 修复 TP/EP 局部张量 DP 分片时的不均匀尺寸推断错误 [#4593](https://github.com/pytorch/torchtitan/pull/4593)；CP 数值测试改用非 CP 种子配置 [#4608](https://github.com/pytorch/torchtitan/pull/4608)；EP 重节点去重 [#4516](https://github.com/pytorch/torchtitan/pull/4516) 和 chunk 具体化修复 [#4529](https://github.com/pytorch/torchtitan/pull/4529)；CP 输入与元数据解耦重构（进行中） [#4617](https://github.com/pytorch/torchtitan/pull/4617)。
- **梯度与通信优化**：`skip_dp` 扩展至 Llama 3、DeepSeek V3 等模型以便推理跳过 FSDP [#4507](https://github.com/pytorch/torchtitan/pull/4507)；bfloat16 归约现已可用 [#4597](https://github.com/pytorch/torchtitan/pull/4597)；NIXL 权重同步在 RDMA 固定地址分配上支持 [#4549](https://github.com/pytorch/torchtitan/pull/4549)。
