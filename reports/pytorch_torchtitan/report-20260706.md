# Pull Request Digest for pytorch/torchtitan (20260629-20260706)

**关键要点**: 本周 44 个 PR 的核心趋势是 **GraphPP 流水线并行基础设施的集中提交**与 **RL 训练管线中 MoE/SPMD 的稳定性及正确性修复**，主要活跃于 ① GraphPP/GraphTrainer 图编译、② RL Trainer 修复与增强、③ `spmd_types` 后端完善、④ 硬件平台适配 (ROCm/H100) 及 ⑤ 配置/依赖升级等领域。

**按类别总结**:

1.  **GraphPP & GraphTrainer 图编译管线 (基础设施)**：
    *   一组 PR 为 `graph_trainer` 引入了完整的 **GraphPP 流水线并行支持**，包括分区 ([PR#3840](https://github.com/pytorch/torchtitan/pull/3840))、dI/dW 反向图切分 ([PR#3841](https://github.com/pytorch/torchtitan/pull/3841))、FSDP 集合通信拆分 ([PR#3842](https://github.com/pytorch/torchtitan/pull/3842))、图编译器运行时集成 ([PR#3843](https://github.com/pytorch/torchtitan/pull/3843)) 和复用图构造 ([PR#3844](https://github.com/pytorch/torchtitan/pull/3844))。
    *   为 DualPipeV 调度预留占位符 ([PR#3845](https://github.com/pytorch/torchtitan/pull/3845))，并增加了 GraphPP 测试。
    *   其他改进：修复 TP>1 时 `lift_fresh_copy` 节点导致的模型无法 CUDA Graph 化问题 ([PR#3818](https://github.com/pytorch/torchtitan/pull/3818))；实现 HSDP/DDP 下 `all_reduce` 的分桶调度 ([PR#3821](https://github.com/pytorch/torchtitan/pull/3821))；新增成本模型/运行时估算器 ([PR#3828](https://github.com/pytorch/torchtitan/pull/3828))；重新启用自动并行测试 ([PR#3838](https://github.com/pytorch/torchtitan/pull/3838))。

2.  **RL Trainer 修复与增强 (功能)**：
    *   **关键正确性修复**：解决异步 RL MoE 运行中因 CUDA Graph 环境变量导致的“幻觉”生成问题 ([PR#3829](https://github.com/pytorch/torchtitan/pull/3829))；修复连续批处理端点，使生成吞吐量提升 5 倍 ([PR#3831](https://github.com/pytorch/torchtitan/pull/3831))。
    *   **核心功能**：为 `PolicyTrainer` 添加可选的 AOT FX Trace + 单秩编译预编译路径 ([PR#3850](https://github.com/pytorch/torchtitan/pull/3850))。
    *   **稳定性与监控**：修复 `spmd_types` 后端的日志概率梯度、生成器 TP all-reduce 和 `FusedSwiGLU` 权值同步以达成位级一致 ([PR#3827](https://github.com/pytorch/torchtitan/pull/3827)，替代 [PR#3822](https://github.com/pytorch/torchtitan/pull/3822))；在打包前丢弃超大样本 ([PR#3855](https://github.com/pytorch/torchtitan/pull/3855))；利用检查点工具避免缓冲区 dtype 静默降级 ([PR#3861](https://github.com/pytorch/torchtitan/pull/3861))；为训练器添加熵和 KL 散度指标以防止奖励坍塌 ([PR#3848](https://github.com/pytorch/torchtitan/pull/3848))；更新位级一致性文档和性能数据 ([PR#3854](https://github.com/pytorch/torchtitan/pull/3854))；修复 MoE 分组专家与 Fused SwiGLU 的覆盖冲突 ([PR#3859](https://github.com/pytorch/torchtitan/pull/3859))。
    *   **大规模 RL 运行**：合并 Qwen3-30B-A3B DeepEP Search-R1 的有效配置 ([PR#3819](https://github.com/pytorch/torchtitan/pull/3819))，并更新了搜索运行 ([PR#3824](https://github.com/pytorch/torchtitan/pull/3824))。

3.  **`spmd_types` 后端完善 (组件)**：
    *   为 `spmd_types` 文档化 ([PR#3853](https://github.com/pytorch/torchtitan/pull/3853))；覆盖 FLUX 模型 ([PR#3823](https://github.com/pytorch/torchtitan/pull/3823))；对所有 EP `TokenDispatcher` 进行类型检查 ([PR#3849](https://github.com/pytorch/torchtitan/pull/3849))；并为 Fused SwiGLU、Helion RoPE 等覆盖增加位级测试 ([PR#3839](https://github.com/pytorch/torchtitan/pull/3839))。

4.  **训练基础设施与硬件/平台适配**：
    *   **流水线并行规范化**：预处理微批次切分，从数据加载器直接产出流水线微批次 ([PR#3856](https://github.com/pytorch/torchtitan/pull/3856))。
    *   **全 DTensor 模式**：允许 `ShardingConfig` 自动包装显式声明的普通输入为 `DTensor` ([PR#3860](https://github.com/pytorch/torchtitan/pull/3860))。
    *   **数值与崩溃处理**：检测到 NaN/Inf Loss 时立即报错 ([PR#3863](https://github.com/pytorch/torchtitan/pull/3863))；为 ROCm 特性测试的损失对比使用 1e-5 的相对容差 ([PR#3847](https://github.com/pytorch/torchtitan/pull/3847))。
    *   **新特性**：添加基于序列的 MoE 负载均衡辅助损失 ([PR#3864](https://github.com/pytorch/torchtitan/pull/3864))。

5.  **依赖与工具链更新 (杂项)**：
    *   修复因 PyTorch 升级 Triton 3.8 导致的损失对比失败 ([PR#3858](https://github.com/pytorch/torchtitan/pull/3858))；将 `transformers` 从 4.57.1 升级到 5.3.0 ([PR#3857](https://github.com/pytorch/torchtitan/pull/3857))。
    *   使用 `HostMesh.spawn` 的 `bootstrap_command` 参数设置环境变量以避免竞争 ([PR#3851](https://github.com/pytorch/torchtitan/pull/3851))；固定 `MONARCH_ACTOR_QUEUE_DISPATCH` 为 0 ([PR#3832](https://github.com/pytorch/torchtitan/pull/3832))。
    *   修复 Helion RoPE Fake strides 并跳过有问题的 DTensor 组合测试 ([PR#3862](https://github.com/pytorch/torchtitan/pull/3862))。
