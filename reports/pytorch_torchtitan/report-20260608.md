# Pull Request Digest for pytorch/torchtitan (20260601-20260608)

本周最显著的趋势是 **GraphTrainer 系统持续深化，从 CUDA 图分段捕获到 CPU 激活卸载、死代码消除与大量上游回归修复，同时 torchchat HF 适配器因往返测试暴露出一批命名失步问题而统一修正**。本周共 88 个 PR，顶级活跃领域为：1) GraphTrainer（图训练器）、2) 强化学习（RL）与 vLLM 集成、3) MoE 专家并行与内核、4) HuggingFace 检查点适配器修复与测试、5) SPMD 类型/全 DTensor 迁移、6) ROCm CI 与兼容性。

### 按类别摘要

- **GraphTrainer 系统（核心推进）**
  - **CUDA 图动态化**：引入分段分区引擎（[PR#3548]），将前向+损失+反向联合图按不安全算子拆分为多个可捕获子图，使 DeepSeek V3 MoE 在 H100 上支持 CUDA 图。配套建设包括：可复用节点安全谓词（[PR#3533]）、非静态输入预复制缓冲（[PR#3534]、[PR#3536]）、移除自定义代码生成管道冲突（[PR#3535]）。
  - **内存与计算优化**：新增强制保存 `sym_size/shape` 操作的内存策略（[PR#3546]）；添加 DCE 清除死码，并先删除 `_assert_async` 运行时断言以避免妨碍捕获（[PR#3545]）；消除无操作 `lift_fresh_copy` 常量克隆（[PR#3544]）；移除连续 `aten.t` 往返传递（[PR#3488]）；启用 aot_eager 下 `FlexAttention` 的 regional_inductor 编译（[PR#3563]）。
  - **CPU 激活卸载增强**：支持视图链（transpose/reshape/permute）卸载，通过在后向中重放视图（[PR#3522]、[PR#3521]）；修复非 Tensor 消费者的 `wait_tensor` 依赖边（[PR#3523]）；默认启用 NUMA 绑定提升带宽（[PR#3489]）。
  - **AC 兼容与模型支持**：添加 `activation_checkpoint.mode=none` 等价实现（[PR#3564]）；提供与 Trainer 标志兼容的映射层（[PR#3516]）；新增 `MinimalAsyncEP` 与 offset-aware SwiGLU 内核实现无丢弃 MoE（[PR#3561]）；Mixture of Experts FP32 崩溃修复（`scatter_add` dtype 不匹配）（[PR#3567]）。
  - **测试与基础修复**：根除因 DTensor 传播产生空 `empty_strided` 阴影节点导致的 14 项测试失败（[PR#3480]）；重新启用多个 MoE / cuDNN / AutoParallel 相关测试（[PR#3512]、[PR#3495]）；修复 DSv3 与 Qwen3 MoE 的位确定性哈希基线（[PR#3482]、[PR#3484]）；修复 `SimpleFSDP` 重包装时 DTensor 形状丢失（[PR#3549]）。

- **RL / vLLM 集成**
  - 修复 vLLM 1.0 KV-cache 布局变更（key/value 分裂维度从 dim 0 移到 dim 1）（[PR#3542]）。
  - 启用 RL GRPO 循环的数据并行与专家并行配置（[PR#3525]），以及 chunked CE loss 的 RFC 设计讨论（[PR#3477]）。
  - 修复 `_collect_rollouts` 异步测试（[PR#3518]）、实验性 CI 触发条件与权限错误（[PR#3541]）。

- **HuggingFace 检查点适配器体系修复**
  - 新增参数化 HF 检查点往返测试（native → HF → native → HF），验证位级等价与文件字节一致（[PR#3553]）。
  - 依据测试一次性修复各模型适配器中 MoE 专家权重命名与 `expert_bias` 遗漏问题：`Llama4`（[PR#3554]）、`GptOss`（[PR#3555]）、`DeepSeekV3`（[PR#3556]）、`Qwen3`（[PR#3557]）。
  - 修复 `Llama3` 适配器未尊重显式配置的 head dimension（[PR#3570]）。

- **SPMD 类型与全 DTensor 迁移**
  - 将 `parallelism.full_dtensor` 重命名为 `parallelism.spmd_backend`，新增 `spmd_types` 后端选项，并添加配置标志（[PR#3540]）。
  - 为 Llama4 和 MoE 模型增加 SPMD sharding 配置（[PR#3551]、[PR#3550]）；引入支持 DTensor 与命名放置混合的 `SpmdLayout`（[PR#3501]）。
  - 推动 `graph_trainer` 迁移至全 DTensor 路径（[PR#3503]）。

- **MoE / 专家并行基础能力**
  - 扔掉 `local_map` 变通方案，直接使用 DTensor `scatter_` 新 sharding 规则（[PR#3515]）。
  - 添加 `HybridEP` 配置支持（[PR#3559]），并准备 CUDA 图兼容的无同步通信后端。
  - 构建 FlexShard 的通信免费 Muon 优化器（[PR#3502]）和块级 FP8 all-gather 设计文档（[PR#3537]）。

- **ROCm 与硬件后端**
  - ROCm CI 集成测试迁移到 `linux_job_v2` 修复 ECR 认证（[PR#3562]）；移除对称内存 hip 支持检查（[PR#3485]）；修复 MoE 模型损失比对（[PR#3526]）；更新损失基线并去除 `torchdata` 版本固定（[PR#3494]）。
  - 通用 H100 集成测试迁移至 OSDC（ARC）运行器（[PR#3479]）。

- **CI / 实验流程与文档**
  - 修复实验性 CI 触发与矩阵设置，确保 RL 和 GraphTrainer 正确运行（[PR#3541]、[PR#3479]）。
  - 压缩 Kineto 跟踪文件为 `.json.gz`（[PR#3483]）；跳过 torchcomms TP+PP+compile 风味待 PG 注册修复（[PR#3493]）。
  - 文档澄清 nightly torch 安装方法（[PR#3492]）、添加 `.venv` 等目录到 `.gitignore`（[PR#3490]、[PR#3491]）。

- **模型配置与新功能**
  - 新增 kimi 2.5 模型支持（[PR#3532]）。
  - 添加 qwen3 30b_a3b 配置（[PR#3527]）。
  - 添加 ATE-Bench 复现基础（[PR#3481]）。
  - 移除冗余 ETP 标志（[PR#3568]）；禁用 autograd 多线程实验（[PR#3565]）。
