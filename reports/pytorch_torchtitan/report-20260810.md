# Pull Request Digest for pytorch/torchtitan (20260803-20260810)

本周核心趋势是围绕 `DistributedMuon` 分布式优化器与 Kimi K2.7 模型支持展开密集迭代，同时 `Grain` 数据管道重构和 RL 权重同步传输机制取得重要进展。共 39 个 PR，活跃领域：① 分布式优化器与 Muon ② 数据加载器重构 ③ 强化学习基础设施 ④ MoE 优化 ⑤ 并行策略与 spmd_types ⑥ 视觉模型修复 ⑦ 工具与配置。

### 1. 分布式优化器与 Muon（`DistributedMuon`）
- [PR#4060](https://github.com/pytorch/torchtitan/pull/4060) 引入 `DistributedMuon` 和 `flex_optimizer_reshard`，实现 packed all-to-all 重分布与优化器计算的重叠，支持 FSDP2+EP，默认按头计算，用于 Kimi K2.7/2.5 和 Moonlight 配方。
- [PR#4077](https://github.com/pytorch/torchtitan/pull/4077) 增加显式 `Replicate()` 作为 `DistributedMuon` 的计算布局，本地计算并保持复制存储，不进入 bucket all-to-all 路径。
- [PR#4078](https://github.com/pytorch/torchtitan/pull/4078) 支持 oversharded QKV heads：将 FSDP2 行分片重组为完整逻辑头矩阵供 Muon 计算，更新后写回原存储布局。
- [PR#4061](https://github.com/pytorch/torchtitan/pull/4061)（已关闭）支持 TP 分片矩阵在 `DistributedMuon` 中的处理。
- [PR#4096](https://github.com/pytorch/torchtitan/pull/4096)（已关闭）细化分布式 Muon 重分布契约。
- [PR#4056](https://github.com/pytorch/torchtitan/pull/4056)（已关闭）将优化器重分布拓扑绑定到每个 bucket，引入运行时 `DeviceMesh` 并移除优化器全局控制网格协调。

### 2. 数据加载器重构（Grain）
- [PR#4088](https://github.com/pytorch/torchtitan/pull/4088)（open）与 [PR#4087](https://github.com/pytorch/torchtitan/pull/4087)（closed）用 `Grain` 统一替换各模型专用数据加载器，支持文本预训练、SFT、Qwen 多模态和 Flux，提供可复用的 source、mixing、packing、collation、分布式分片和 checkpoint 扩展点。

### 3. 强化学习基础设施
- [PR#4082](https://github.com/pytorch/torchtitan/pull/4082) 为跨节点 trainer→generator 权重同步增加传输方式拨盘和手动 CPU 暂存逃生通道，解决 GPUDirect RDMA 在不同集群的兼容性问题。
- [PR#4083](https://github.com/pytorch/torchtitan/pull/4083) 添加独立的权重同步传输基准测试，避免完整 RL 作业的启动开销和噪声。
- [PR#4072](https://github.com/pytorch/torchtitan/pull/4072) 将 `InterGeneratorRouter` 封装为 Monarch Actor，解决其可变状态在多线程/多进程下的并发安全问题。
- [PR#4073](https://github.com/pytorch/torchtitan/pull/4073) 将 rollout 执行逻辑重构到 `RolloutWorker`，为后续进程池化做准备。
- [PR#4074](https://github.com/pytorch/torchtitan/pull/4074) 将 `RolloutWorker` 运行在 Monarch actor mesh 中，解决控制器进程的 CPU 利用率和 GIL 争用瓶颈。
- [PR#4076](https://github.com/pytorch/torchtitan/pull/4076) 从 Rollouter 组 API 中移除 `renderer`，避免跨进程序列化大负载的 IPC 开销。

### 4. MoE 优化
- [PR#4095](https://github.com/pytorch/torchtitan/pull/4095) 将 DeepSeek V3 的路由分数吸收到 SwiGLU 激活前（W2 投影前），利用线性性质避免在 combine 侧保留 `(R, D)` 激活，节省显存。
- [PR#4080](https://github.com/pytorch/torchtitan/pull/4080) 在推理时对 MoE 输入按 expert 序列并行度 padding，确保 TP 分片均匀，移除 token dispatcher 的虚拟填充簿记。
- [PR#4054](https://github.com/pytorch/torchtitan/pull/4054)（已关闭）修复无 EP 时 MoE 梯度放置丢失 reduction 的问题，确保 TP 下专家梯度正确求和。

### 5. 并行策略与 spmd_types
- [PR#4089](https://github.com/pytorch/torchtitan/pull/4089) 使 `MinimalAsyncEP` 支持张量并行，从 TP 分片的每 rank token 上限推导对称缓冲区容量，并恢复完整序列并行视图。
- [PR#4091](https://github.com/pytorch/torchtitan/pull/4091)（WIP）为 `spmd_types` 添加 simpleFSDP 支持（不含 TP）。
- [PR#4085](https://github.com/pytorch/torchtitan/pull/4085) 尝试将 `spmd_types` 设为默认后端。
- [PR#4079](https://github.com/pytorch/torchtitan/pull/4079) 为 Kimi 2.7 启用 `spmd_types`。
- [PR#4070](https://github.com/pytorch/torchtitan/pull/4070)/[PR#4063](https://github.com/pytorch/torchtitan/pull/4063)（均已关闭）修复 Kimi 2.7 在 `spmd_types` 后端下 FSDP mesh 维度名不匹配的问题。
- [PR#4068](https://github.com/pytorch/torchtitan/pull/4068)（已关闭）修复 `get_all_one_dimensional_meshes` 错误包含 fake 后端轴的问题。
- [PR#4071](https://github.com/pytorch/torchtitan/pull/4071)（已关闭）修复 PP 预分割微批次后错误调用 `step()` 导致输入维度不匹配的 bug。

### 6. 视觉模型修复
- [PR#4094](https://github.com/pytorch/torchtitan/pull/4094) 修复图像 patch 预算计算：在 padding 后强制 `max_patches` 限制，保持宽高比，并拒绝无法容纳一个合并 patch 块的预算。
- [PR#4057](https://github.com/pytorch/torchtitan/pull/4057) 修复 VLM MFU 误算，将视觉编码器的 FLOPs 纳入总吞吐计算。

### 7. 工具、配置与修复
- [PR#4092](https://github.com/pytorch/torchtitan/pull/4092)（已关闭）解耦周期性内存快照频率与 trace profiler 调度，新增 `Profiler.Config.memory_snapshot_freq`。
- [PR#4058](https://github.com/pytorch/torchtitan/pull/4058) 为 `torch_checkpointing` 添加保存后端配置管道，支持选择不同后端。
- [PR#4055](https://github.com/pytorch/torchtitan/pull/4055) 支持模型部分加载 checkpoint（`allow_partial_load_on_model`），非模型状态仍严格加载。
- [PR#4075](https://github.com/pytorch/torchtitan/pull/4075) 在文档边界处 mask 损失，避免跨文档预测 BOS token 的潜在问题。
- [PR#4059](https://github.com/pytorch/torchtitan/pull/4059) 文档化环境变量。
- [PR#4081](https://github.com/pytorch/torchtitan/pull/4081) 使用 `DTensor` placements 处理分布式指标。
