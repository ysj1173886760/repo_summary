# Pull Request Digest for pytorch/torchtitan (20260727-20260803)

本周核心趋势是**图训练器（GraphTrainer）稳健性加固与大规模模型并行策略的深化**，共52个PR，活跃领域集中于：① GraphTrainer 编译管线与错误修复、② 分布式优化器与参数初始化重构、③ 大模型（DeepSeekV3/Kimi K3/Qwen3.5）适配、④ CI/测试基础设施抢修、⑤ 硬件后端适配（ROCm/Blackwell）、⑥ MoE/TP 等并行策略演进。

### 1. 图训练器与编译优化
- [PR#4053](https://github.com/pytorch/torchtitan/pull/4053) 临时跳过 H100 上 GraphTrainer DeepSeekV3 FlexAttention EP‑overlap MoE 变体，解耦 FSDP 区域调度别名错误。
- [PR#4048](https://github.com/pytorch/torchtitan/pull/4048) 禁用 FSDP+TP+EP regional‑inductor 配置，回避拓扑排序失败（#4047）。
- [PR#4042](https://github.com/pytorch/torchtitan/pull/4042) 回退 “Always Pre-Split Microbatches for PP”，修复 PP 公共 API 因预切分微批次传入 `step()` 导致的参数数量不匹配。
- [PR#4014](https://github.com/pytorch/torchtitan/pull/4014) 修复单进程预编译路径中 FlexAttention 输入字典顺序错误，保证与训练路径一致。
- [PR#4005](https://github.com/pytorch/torchtitan/pull/4005)/[PR#4004](https://github.com/pytorch/torchtitan/pull/4004)/[PR#4003](https://github.com/pytorch/torchtitan/pull/4003) 引入显式子图区域、FSDP 前向重分片、直通 full‑Inductor 编译 Pass，提升编译灵活性与内存效率。
- [PR#4001](https://github.com/pytorch/torchtitan/pull/4001) 允许 `make_fx` 关闭栈追踪收集，优化大模型编译时间。
- [PR#4019](https://github.com/pytorch/torchtitan/pull/4019)/[PR#4018](https://github.com/pytorch/torchtitan/pull/4018) 支持 Fake Pipeline 逐 rank 模拟与伪造进程组任意 rank 初始化，覆盖 MPMD 代码路径。

### 2. 分布式优化器与参数管理
- [PR#4051](https://github.com/pytorch/torchtitan/pull/4051) 支持 TP 分片矩阵的 `DistributedMuon`，接受带 `Shard(0), Shard(1)` 放置的二维 DTensor。
- [PR#4034](https://github.com/pytorch/torchtitan/pull/4034) 新增独立 CUDA 分布式 Muon 优化器，包含动量与 Newton‑Schulz 数学核心，以及通用的桶状再分布运行时。
- [PR#3991](https://github.com/pytorch/torchtitan/pull/3991) 去除 Muon FlexShard 中的临时张量，通过调用核心 `_compute_muon_update()` 直接写入输出缓冲，降低峰值内存。
- [PR#3993](https://github.com/pytorch/torchtitan/pull/3993) 流水线优化器 FlexShard 支持通信与计算重叠，使用双槽事件调度器将桶全到全再分布与优化器计算并行。
- [PR#4027](https://github.com/pytorch/torchtitan/pull/4027)/[PR#4028](https://github.com/pytorch/torchtitan/pull/4028)/[PR#4029](https://github.com/pytorch/torchtitan/pull/4029) 构建逻辑张量分片元数据归一化、FQN 键值参数初始化，最终启用分布式键值初始化入口。

### 3. 大模型架构支持与配置修复
- [PR#4025](https://github.com/pytorch/torchtitan/pull/4025) 添加 Kimi K3 架构的 FSDP2 快速参考模型，含 KDA、门控 MLA、LatentMoE 等组件及调试模型。
- [PR#4016](https://github.com/pytorch/torchtitan/pull/4016) 修正 Qwen3.5‑122B/397B 的训练配置： KV 头数不足时 TP 度降为 2，避免 QKV 分片校验失败。
- [PR#4008](https://github.com/pytorch/torchtitan/pull/4008) 修复 `float8` 过滤器，将排除键从 `output` 改为 `lm_head`，防止语言模型头被误量化为 fp8。
- [PR#4012](https://github.com/pytorch/torchtitan/pull/4012) 在 Blackwell 上选择 FA4 varlen 注意力实现。

### 4. CI / 测试基础设施修复
- [PR#4050](https://github.com/pytorch/torchtitan/pull/4050)/[PR#4043](https://github.com/pytorch/torchtitan/pull/4043) 修复 CI checkout 重复拉取及固定到事件 SHA，防止使用错误 commit。
- [PR#4036](https://github.com/pytorch/torchtitan/pull/4036) 将 8 GPU 模型测试超时提升至 60 分钟，解决 teardown 清理阶段超时。
- [PR#4030](https://github.com/pytorch/torchtitan/pull/4030)/[PR#4033](https://github.com/pytorch/torchtitan/pull/4033) 修复 DeepEP HybridEP 构建（C++20 要求）并更新至新 pin，适配新版 PyTorch。
- [PR#4006](https://github.com/pytorch/torchtitan/pull/4006) 将 H100 集成测试的 HuggingFace 缓存指向可写临时目录，解决只读挂载问题。
- [PR#4002](https://github.com/pytorch/torchtitan/pull/4002) 临时禁用失败 ROCm CI，后由 [PR#4039](https://github.com/pytorch/torchtitan/pull/4039) 重新启用。
- [PR#4015](https://github.com/pytorch/torchtitan/pull/4015) 新增单 GPU 伪造进程组集成测试层，降低 CI 负载并提供构建/分片计划冒烟覆盖。
- [PR#4024](https://github.com/pytorch/torchtitan/pull/4024) 临时更新 llama3 损失金标准，等待上游数值变更回退。

### 5. 硬件后端适配
- [PR#4032](https://github.com/pytorch/torchtitan/pull/4032) 在 ROCm 上自动设置 `GPU_MAX_HW_QUEUES`，避免流冲突并优化硬件队列分配。
- [PR#4012](https://github.com/pytorch/torchtitan/pull/4012) 已包含在 Blackwell 适配中。
- [PR#4016](https://github.com/pytorch/torchtitan/pull/4016) 涉及 GPU 规模调整。

### 6. 并行策略与通信优化
- [PR#4045](https://github.com/pytorch/torchtitan/pull/4045) 修复异步 TP 在 SPMD 后端上的配置，通过对称内存启用正确 TP 进程组，并传播异步 TP/序列并行设置。
- [PR#3996](https://github.com/pytorch/torchtitan/pull/3996) 重定义 MoE EP/SP 分片契约： token 分发器直接返回局部序列分片，避免构造全局稀疏贡献，降低通信开销。
- [PR#4022](https://github.com/pytorch/torchtitan/pull/4022)/[PR#4021](https://github.com/pytorch/torchtitan/pull/4021)/[PR#4020](https://github.com/pytorch/torchtitan/pull/4020) 为 EP 重叠添加命名调度模式；异步 EP 实现高优先级拷贝路径与接收缓冲区容量绑定，提升 DeepSeek‑v3 671B 配置性能。
- [PR#4031](https://github.com/pytorch/torchtitan/pull/4031) 通过 launcher 环境限制每个进程的 OMP 线程数，避免多进程 CPU 过度抢占导致 GPU 饥饿。

### 7. 工具与开发者体验
- [PR#4023](https://github.com/pytorch/torchtitan/pull/4023) 新增 `--debug.print_config_ranks` 限制配置打印的 rank，解决多节点日志可读性问题。
- [PR#4017](https://github.com/pytorch/torchtitan/pull/4017) 阻止 Pyrefly pre‑commit 自动重写忽略配置。
- [PR#4013](https://github.com/pytorch/torchtitan/pull/4013) 更新安装文档以支持 `uv`。
