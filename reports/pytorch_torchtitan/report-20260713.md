# Pull Request Digest for pytorch/torchtitan (20260706-20260713)

**关键要点：** 本周 33 个 PR 中，最显著的趋势是 `spmd_types` 并行化路径在 Qwen3.5 大规模模型上的全面启用与 RL 训练管线的多后端（XPU、TPU）及混合精度支持，活跃领域依次为：1. `spmd_types` 并行化与模型适配，2. RL 训练管线，3. 硬件后端支持，4. 量化与混合精度训练，5. 分布式通信与图训练器。

### 1. 并行化与模型支持 (`spmd_types`, DTensor, 序列并行)
*   **Qwen3.5 全面启用 `spmd_types`**：[PR#3895] 为 Qwen3.5 的 dense、vision、GatedDeltaNet、MoE 路径添加了 `spmd_types` 并行化契约，并修复了相关的 DTensor TP 位置缓存问题 [PR#3899]，同时 CI 中屏蔽了该模型尚未适配的 `spmd_types` 后端 [PR#3901] 及不兼容的测试变体 [PR#3888]。
*   **DeepSeek V3 修复**：[PR#3866] 修复了 `spmd_types` 下专家并行 (EP) 与分块损失的类型检查问题，[PR#3901] 也一并修复了其编译问题。
*   **序列并行与可变长度**：[PR#3893] 启用了 varlen 的完整 CUDA Graph，[PR#3892] 修复了 GatedDeltaNet 在 RL 打包样本边界处的循环/卷积状态重置问题。
*   **异步 TP 修复**：[PR#3869] 修复了 `enable_async_tensor_parallel` 启用时，因 `is_symm_mem_enabled_for_group` 为 False 导致融合模式替换失败的问题。

### 2. RL 训练管线
*   **混合精度与后端扩展**：[PR#3897] 为 RL 流程添加了 FP16 训练支持（Qwen 模型），[PR#3890] 将 GRPO 管线完整适配到 Intel XPU，包括 vLLM 生成器和 TorchStore 权重同步。
*   **权重同步与生成器修复**：[PR#3867] 修复了 TorchStore 因融合参数（如 `FusedQKVLinear`）导致权重更新失效的问题，[PR#3870] 优化了控制器向生成器 rank0 发送请求的逻辑，[PR#3871] 回退了生成器初始化竞态修复，恢复原有顺序。
*   **配置与覆盖增强**：[PR#3894] 允许 `override.imports` 通过 CLI 和 config 传递 kwargs，方便 RL 等场景共享模型规格但使用不同配置。

### 3. 硬件后端支持
*   **TPU**：[PR#3900] 为 `get_peak_flops` 添加了 Google Cloud TPU 的 BF16 峰值算力值，为 TPU 启用做准备。
*   **AMD ROCm**：[PR#3896] 修复了 8-GPU 特性 CI 中因 gfx950 上 `flex_attention` 编译不稳定导致的确定性比对失败，改为在 ROCm 上 eager 执行。
*   **Intel XPU**：[PR#3890] 为 RL 训练管线适配 XPU，并处理了 `PYTORCH_XPU_ALLOC_CONF` 与 `expandable_segments` 冲突问题。

### 4. 量化与混合精度训练
*   **FP8 块级训练**：[PR#3891] 新增了 `Float8BlockwiseLinear` 和 MoE 分组专家的块级 FP8 训练配方，附带精度自检和向上取整逻辑。
*   **NVFP4 量化感知蒸馏**：[PR#3889] 引入了 NVFP4 假量化和知识蒸馏流程，以恢复量化后的精度损失。
*   **FP16 训练**：[PR#3897] 在 RL 中支持 FP16 混合精度，优化器状态保持 FP32。

### 5. 分布式通信与图训练器
*   **自定义通信框架**：[PR#3883] 实现了一个基于 `torch.library` 的自定义通信框架，当前支持 fixed-size 算法的 allreduce，并利用对称内存缓存。
*   **对称内存 TP 覆盖**：[PR#3905] 通过 `symm_mem` 覆盖了 TP 的 all-reduce 操作，依赖链 [PR#3904, PR#3903] 引入了可覆盖的重分布规格。
*   **图训练器优化**：[PR#3881] 为联合激活检查点与卸载项目，实现了 FX 图的内存/运行时/传输估算器，以及一个朴素的外层 ILP 求解器。
*   **CI 修复与重构**：[PR#3872] 修复了图训练器因 NUMA API 重命名、`OpaqueBase` 启动崩溃等问题导致的 CI 红牌，[PR#3880] 将 `OpaqueBase` 重命名为 `CustomClassBase`。

### 6. 基础设施与杂项
*   **检查点与文件系统**：[PR#3887] 通过 `fsspec` 支持远程 checkpoint 路径（如 `gs://`），[PR#3878] 清理了安装时的文件垃圾。
*   **构建与安装**：[PR#3902] 更新了 README 中的本地安装命令。
*   **其他修复**：[PR#3886] 修复了冻结参数传递 `require_grads` 的问题，[PR#3873] 避免了 `isfinite` 导致的每微批次 D2H 同步，[PR#3879] 移除了 `full_dtensor` 相关的测试。
