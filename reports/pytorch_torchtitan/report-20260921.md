# Pull Request Digest for pytorch/torchtitan (20260914-20260921)

1. 本周核心趋势是全面推进 **DistMuon 优化器与 Kimi K3 系列模型的生产级训练适配**，同时完成 GraphTrainer 流水线运行时的大一统，共 148 个 PR；最活跃的领域依次为：① DistMuon 优化器，② Kimi K3 模型支持，③ GraphTrainer 统一与预编译，④ MoE 组件增强，⑤ RL 训练与生成优化，⑥ 硬件兼容性。

## 1. 新特性与重大重构
### 模型与优化器
- **DistMuon 生产化**：引入参数字面映射与分配校验（[PR#4816](https://github.com/pytorch/torchtitan/pull/4816), [PR#4813](https://github.com/pytorch/torchtitan/pull/4813)），支持 `Shard(0)` 的 `DistMuon` 适配 Kimi `w13` 融合投影（[PR#4811](https://github.com/pytorch/torchtitan/pull/4811), [PR#4812](https://github.com/pytorch/torchtitan/pull/4812)），简化布局规划与矩阵视图（[PR#4809](https://github.com/pytorch/torchtitan/pull/4809)），以及支持变长 BlockShard（[PR#4799](https://github.com/pytorch/torchtitan/pull/4799)）和可选的 QuACK 对称 GEMM 加速（[PR#4781](https://github.com/pytorch/torchtitan/pull/4781)）。
- **Kimi K3 与 ML架构**：激活函数保持（[PR#4814](https://github.com/pytorch/torchtitan/pull/4814)）与注意力残余修正（[PR#4780](https://github.com/pytorch/torchtitan/pull/4780), [PR#4656](https://github.com/pytorch/torchtitan/pull/4656)）；添加 MoonEP 通讯后端（[PR#4751](https://github.com/pytorch/torchtitan/pull/4751)）和 PP 显存负载均衡与卸载（[PR#4764](https://github.com/pytorch/torchtitan/pull/4764), [PR#4765](https://github.com/pytorch/torchtitan/pull/4765)）；CP 通讯优化 MLA（[PR#4760](https://github.com/pytorch/torchtitan/pull/4760)）及 GDN CP 支持（[PR#4803](https://github.com/pytorch/torchtitan/pull/4803)）。
- **LoRA**：重构为 `ModelConfigTransform`（[PR#4684](https://github.com/pytorch/torchtitan/pull/4684)）并修复 LoRA 对 `SoftCappedLinear` 的输出后处理问题（[PR#4785](https://github.com/pytorch/torchtitan/pull/4785)）。
- **量化**：Kimi K3 的 MXFP4 导入与 QAT 配方（[PR#4791](https://github.com/pytorch/torchtitan/pull/4791)），修复量化 FSDP 推理模式视图（[PR#4757](https://github.com/pytorch/torchtitan/pull/4757)），以及 RL 中缓存量化的权重（[PR#4715](https://github.com/pytorch/torchtitan/pull/4715)）。

### 训练框架与运行时
- **GraphTrainer 统一流水线**：通过 `GraphPipelineRuntime` 将 PP=1 与 PP>1 统一，支持梯度积累与延迟 FSDP 同步（[PR#4666](https://github.com/pytorch/torchtitan/pull/4666), [PR#4766](https://github.com/pytorch/torchtitan/pull/4766)），并配套大量指纹识别与修复（如 [PR#4714](https://github.com/pytorch/torchtitan/pull/4714) 预编译 PP=1 图，[PR#4720](https://github.com/pytorch/torchtitan/pull/4720) 模型配置指纹等十几个 PR）。
- **CUDA Graph 增强**：允许分离优化器更新捕获（[PR#4660](https://github.com/pytorch/torchtitan/pull/4660)），重用图内梯度（[PR#4659](https://github.com/pytorch/torchtitan/pull/4659)），捕获全图梯度累积（[PR#4658](https://github.com/pytorch/torchtitan/pull/4658)），并支持循环流水线调度（[PR#4671](https://github.com/pytorch/torchtitan/pull/4671)）。
- **训练引擎抽离**：拆分 `TrainingEngine` 并被 RL 与督导训练器共享（[PR#4773](https://github.com/pytorch/torchtitan/pull/4773)），模型并行化所有权重构（[PR#4810](https://github.com/pytorch/torchtitan/pull/4810)）。
- **Pipeline 扩展**：暴露 FSDP 预取策略（[PR#4670](https://github.com/pytorch/torchtitan/pull/4670)）、未发送预算（[PR#4662](https://github.com/pytorch/torchtitan/pull/4662)）和延迟梯度归约等待（[PR#4661](https://github.com/pytorch/torchtitan/pull/4661)），配置流水线活跃阶段数（[PR#4710](https://github.com/pytorch/torchtitan/pull/4710)）。
- **MoE 改进**：纯 TP 专家分片废弃（[PR#4798](https://github.com/pytorch/torchtitan/pull/4798), [PR#4794](https://github.com/pytorch/torchtitan/pull/4794)），路由专家变为一等 `GroupedLinear`（[PR#4667](https://github.com/pytorch/torchtitan/pull/4667), [PR#4668](https://github.com/pytorch/torchtitan/pull/4668)），并为专家输出添加后处理钩子（[PR#4654](https://github.com/pytorch/torchtitan/pull/4654)）；新增全局批内辅助损失（[PR#4772](https://github.com/pytorch/torchtitan/pull/4772)）。
- **RL 优化**：GDN Prefill 捕获为 native FULL 图（[PR#4738](https://github.com/pytorch/torchtitan/pull/4738)），按组管理 KV 缓存不污染（[PR#4761](https://github.com/pytorch/torchtitan/pull/4761)），TP 下的低通信策略统计（[PR#4685](https://github.com/pytorch/torchtitan/pull/4685)），转换后恢复分片布局（[PR#4787](https://github.com/pytorch/torchtitan/pull/4787)）；命名变更 `Varlen` 后端（[PR#4786](https://github.com/pytorch/torchtitan/pull/4786)）。
- **Fused 前馈投影**：改用堆叠布局 `[2, F, D]` 以利于量化与分片（[PR#4676](https://github.com/pytorch/torchtitan/pull/4676), [PR#4808](https://github.com/pytorch/torchtitan/pull/4808)），并按此调整投影后端（[PR#4704](https://github.com/pytorch/torchtitan/pull/4704)）。融合 SWiGLU 内核上线及内核子模块（[PR#4770](https://github.com/pytorch/torchtitan/pull/4770)）。

### 硬件与兼容性
- 设备 FLOPS 补全与修复（增加 MI350X 等）（[PR#4779](https://github.com/pytorch/torchtitan/pull/4779), [PR#4800](https://github.com/pytorch/torchtitan/pull/4800)）。
- ROCm 平台修复 FA3 误选与 CUDA 图校验跳过（[PR#4778](https://github.com/pytorch/torchtitan/pull/4778), [PR#4790](https://github.com/pytorch/torchtitan/pull/4790)）。
- NPU 基础兼容（[PR#4748](https://github.com/pytorch/torchtitan/pull/4748)），以及 CPU offload 下的 Stream 与 RNG 修复（[PR#4762](https://github.com/pytorch/torchtitan/pull/4762), [PR#4687](https://github.com/pytorch/torchtitan/pull/4687)）。

- **数值正确性**：修复 GPT-OSS 梯度通过默认 FlexAttention 保证 LSE 梯度（[PR#4796](https://github.com/pytorch/torchtitan/pull/4796)），融合 SwiGLU 行偏移溢出（[PR#4698](https://github.com/pytorch/torchtitan/pull/4698)），FP8 融合 QKV 头对齐校验（[PR#4677](https://github.com/pytorch/torchtitan/pull/4677)）。
