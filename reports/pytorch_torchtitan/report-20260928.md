# Pull Request Digest for pytorch/torchtitan (20260921-20260928)

**PR 统计**：共 88 个（已合并 42 · 进行中 27 · 草稿 15 · 已关闭 4）

## 本周概览
本周重点集中在基础设施现代化（OSDC runner 迁移与 CI 重构）、MoE 核心代码显式化（GroupedLinear 默认化、collectives 显式化），以及多项性能优化（FullAC early stopping、MXFP8 融合）。配置系统移除 Tyro 改为纯 Python config，公共命名与模块边界出现较大调整。

**最活跃领域**：1. MoE 与量化；2. GraphTrainer 与编译；3. CI 与基础设施；4. RL 训练栈；5. 配置重构

## 重点进展
- **配置系统替换 Tyro**：移除 Tyro CLI，引入 Python config loading，CLI 仅保留少量启动选项，所有训练参数改为配置文件驱动，影响所有入口点 [#4909](https://github.com/pytorch/torchtitan/pull/4909)
- **MoE 核心重构**：`RoutedExperts` 替换为显式 `GroupedLinear` 子模块，核心 collectives 显式化并支持 remat region 放置，提升可组合性与可维护性 [#4878](https://github.com/pytorch/torchtitan/pull/4878) [#4871](https://github.com/pytorch/torchtitan/pull/4871) [#4872](https://github.com/pytorch/torchtitan/pull/4872)
- **融合 MXFP8 WGRAD 累积**：首个之后每个 microbatch 通过 `scaled_addmm_` 将 WGRAD 累积融合进 GEMM，减少内存和 kernel 启动 [#4911](https://github.com/pytorch/torchtitan/pull/4911)
- **FullAC early stopping 默认启用**：修复早期内存泄漏担忧后默认开启，带来 1-4% 的性能提升 [#4836](https://github.com/pytorch/torchtitan/pull/4836)
- **OSDC runner 全量迁移**：nightly wheel、GPU integration、docker 构建均切换到 OSDC runners，完成 v3 迁移并保持 ROCm 在 v2 [#4873](https://github.com/pytorch/torchtitan/pull/4873) [#4874](https://github.com/pytorch/torchtitan/pull/4874) [#4875](https://github.com/pytorch/torchtitan/pull/4875) [#4880](https://github.com/pytorch/torchtitan/pull/4880)

## 分领域动态

### MoE 与量化
- **自研 Float8/NVFP4 autograd**：TorchTitan 拥有 dense/grouped Float8/NVFP4 autograd 与 FSDP 管理的权重操作数，TorchAO 仅提供底层量化与 GEMM kernel [#4820](https://github.com/pytorch/torchtitan/pull/4820)
- **NVFP4GroupedExpertsConverter（进行中）**：为 DeepSeek-V3 MoE routed experts 添加 NVFP4 量化，支持 671B 配方在 GB300 上验证 [#4821](https://github.com/pytorch/torchtitan/pull/4821)
- **Blockwise FP8 FlexShard（进行中）**：为 DeepSeek V3 添加 blockwise FP8 目标策略并与 FlexShard 感知的 TorchAO consumer 组合 [#4863](https://github.com/pytorch/torchtitan/pull/4863)
