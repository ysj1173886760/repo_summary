# Pull Request Digest for pytorch/torchtitan (20261005-20261012)

**PR 统计**：共 215 个（已合并 101 · 进行中 40 · 草稿 53 · 已关闭 21）

## 本周概览
本周重点围绕 GraphTrainer 的数值对齐与流水线并行优化、RL 训练基础设施的健壮性提升，以及大规模模型局部编译的性能探索展开。仓库进行了重大重组以改善模块化，同时多个关键修复确保了 MoE 和激活检查点在分布式场景下的正确性。

**最活跃领域**：1. GraphTrainer 数值与流水线并行；2. RL 训练基础设施；3. 模型局部编译与性能优化；4. 分布式 MoE 与 DeepEP；5. 仓库结构与 CI

## 重点进展
- **仓库重组与依赖清理**：重新组织仓库结构，将模块移至其所有者附近，修复了依赖漂移和 `import torchtitan.rl` 强制加载 vLLM 的问题 [#5277](https://github.com/pytorch/torchtitan/pull/5277)
- **RL 训练器与生成器模型配置分离**：构建分片模型配置，分离 RL 训练器和生成器的模型构建，消除了共享配置导致的变通方案，使分片在构建时确定 [#5280](https://github.com/pytorch/torchtitan/pull/5280)
- **修复 DeepEP 在 FullAC 下的梯度错误**：在 FullAC 下保存 dispatch 和 combine 而非重放，修复了 MoE 梯度错误（相对 L2 误差 1.41），同时 FullAC 速度提升 4.8% [#5123](https://github.com/pytorch/torchtitan/pull/5123)
- **合并重复的 FSDP 梯度归约**：GraphTrainer 将共享参数的多次梯度归约合并为本地累加后一次归约，匹配 eager FSDP 行为，减少通信开销 [#5092](https://github.com/pytorch/torchtitan/pull/5092)
- **统一激活检查点至 torch_remat**：将 FullAC 迁移到 `torch_remat`，移除 `torch.utils.checkpoint` 路径，所有 AC 策略统一，步骤时间减少 5-6ms，数值一致 [#5101](https://github.com/pytorch/torchtitan/pull/5101)
