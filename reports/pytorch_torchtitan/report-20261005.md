# Pull Request Digest for pytorch/torchtitan (20260928-20261005)

**PR 统计**：共 114 个（已合并 68 · 进行中 22 · 草稿 17 · 已关闭 7），另有 1 个机器人 PR 未计入

## 本周概览
本周核心围绕 **GraphTrainer 架构简化** 与 **RL 训练正确性/性能修复** 展开，大量遗留代码和复杂路径被清理，同时局部编译覆盖了更多算子。配置验证和文档修复也得到系统性加强。

**最活跃领域**：1. GraphTrainer 重构与清理；2. RL 训练与生成器优化；3. 局部编译与性能；4. 分布式容错与基础设施；5. 模型支持与修复

## 重点进展
- **GraphTrainer 大规模简化**：移除 graph-based EP chunking、legacy AOT export、未使用的 hook 注册和节点元数据，标准化 SPMD/PP 执行路径，并将 FSDP 梯度累积配置统一为单一入口，大幅降低维护成本 [#4952](https://github.com/pytorch/torchtitan/pull/4952) [#4979](https://github.com/pytorch/torchtitan/pull/4979) [#5001](https://github.com/pytorch/torchtitan/pull/5001) [#5003](https://github.com/pytorch/torchtitan/pull/5003) [#4999](https://github.com/pytorch/torchtitan/pull/4999) [#5005](https://github.com/pytorch/torchtitan/pull/5005) [#5024](https://github.com/pytorch/torchtitan/pull/5024)
- **RL 训练正确性修复**：修复了 Monarch actor 失败退出码、vLLM 假 eos_token_id 导致提前停止、temperature 未应用到 logprobs 等关键 bug，并默认启用 sticky sessions 提升 prefix cache 命中率 [#4925](https://github.com/pytorch/torchtitan/pull/4925) [#4987](https://github.com/pytorch/torchtitan/pull/4987) [#5049](https://github.com/pytorch/torchtitan/pull/5049) [#4986](https://github.com/pytorch/torchtitan/pull/4986)
- **局部编译持续扩展**：新增 `offset_rmsnorm`、`swiglu`、`cos_sin_rope`、`situglu`、`partial_rope` 等局部编译目标，默认开启，显著降低算子延迟 [#4928](https://github.com/pytorch/torchtitan/pull/4928) [#4931](https://github.com/pytorch/torchtitan/pull/4931) [#4985](https://github.com/pytorch/torchtitan/pull/4985) [#5008](https://github.com/pytorch/torchtitan/pull/5008) [#5039](https://github.com/pytorch/torchtitan/pull/5039)
- **移除 Float8 训练支持**：清理了 TorchTitan 自有的 Float8 实现及相关转换器、配方和文档，聚焦于 MXFP8 和 NVFP4 等活跃格式 [#4961](https://github.com/pytorch/torchtitan/pull/4961)
- **torchft 容错增强**：非有限步改为投票而非断言，避免单点故障级联重启；同时将 generator 权重暂存 CPU 以支持 RDMA 重叠生成 [#5009](https://github.com/pytorch/torchtitan/pull/5009) [#4945](https://github.com/pytorch/torchtitan/pull/4945)

## 分领域动态
### GraphTrainer
- **配置与构造统一**：将 SPMD 梯度累积相关设置合并为 `SPMDGradientAccumulationConfig`，并让 `GraphRuntime` 构造过程只传递一个配置对象 [#5005](https://github.com/pytorch/torchtitan/pull/5005) [#4983](https://github.com/pytorch/torchtitan/pull/4983)
- **PP 阶段适配**：自定义 Kimi 阶段迁移至上游 `_forward_chunk_states` 生命周期，移除已删除的 `fwd_cache` 字段 [#4994](https://github.com/pytorch/torchtitan/pull/4994)
- **图 dump 标准化**：统一使用 `tlparse_log_graph_pass` 替代 `trace_graph_pp_graph`，消除重复的 dump 格式 [#5035](https://github.com/pytorch/torchtitan/pull/5035)
- **跳过未使用的 split 图**：SPMD 梯度累积路径不再构建和 lint 仅用于提取名称的 collective 子图，节省编译开销 [#5038](https://github.com/pytorch/torchtitan/pull/5038)
- **CUDA 图配置修复**：修正 `disable_cuda_graphs=False` 时 GraphTrainer 仍可能不捕获 CUDA 图的问题 [#5023](https://github.com/pytorch/torchtitan/pull/5023)
- **移除“schedule” FSDP 模式**：PP=1 时不再将 FSDP all-gather/reduce-scatter 提取为独立调度动作，简化执行路径 [#5024](https://github.com/pytorch/torchtitan/pull/5024)

### RL 训练与生成器
- **Generator 日志与 token 处理优化**：将日志记录改为每 burst 一次，并跳过不必要的 detokenization，降低开销 [#4975](https://github.com/pytorch/torchtitan/pull/4975) [#4976](https://github.com/pytorch/torchtitan/pull/4976)
- **vLLM 引擎线程化（进行中）**：将 `LLMEngine.step()` 移到独立线程，通过线程安全 inbox 通信，避免阻塞 Monarch actor [#5029](https://github.com/pytorch/torchtitan/pull/5029)
- **compute_logprobs 编译**：将 RL 损失中的 `compute_logprobs` 纳入 `loss` 局部编译区域，H100 上延迟从 21.3ms 降至 3.9ms [#5020](https://github.com/pytorch/torchtitan/pull/5020)
- **拒绝 top_p < 1**：在 trainer 能正确重放截断采样之前，禁止使用 nucleus sampling，防止梯度偏差 [#5021](https://github.com/pytorch/torchtitan/pull/5021)
- **权重同步修复**：修复 tied weight 在 trainer-to-generator 同步时重复传输的问题 [#4940](https://github.com/pytorch/torchtitan/pull/4940)
- **LR 调度器步数修正（进行中）**：让 RL trainer 的 LR 调度器基于 `async_loop.num_training_steps` 而非 `trainer.training.steps` [#4939](https://github.com/pytorch/torchtitan/pull/4939)

### 编译与性能
- **Kimi attention residual 编译（进行中）**：注册 `_apply_attention_residual` 为局部编译目标，并添加可选的 fused Triton 覆盖 [#5033](https://github.com/pytorch/torchtitan/pull/5033)
- **mxfp8 内核切换（进行中）**：尝试使用 PyTorch 核心的 mxfp8 内核替代自定义实现，性能数值不变但峰值内存略有回归 [#4964](https://github.com/pytorch/torchtitan/pull/4964)
- **remat 区域声明**：为 `GroupedLinear` 的 grouped matmul 添加 remat 区域，并统一 MoE dispatch/combine 为单一区域，优化重计算策略 [#5031](https://github.com/pytorch/torchtitan/pull/5031) [#4978](https://github.com/pytorch/torchtitan/pull/4978)

## 值得关注
- **破坏性变更**：`torchtitan_train` 命令已移除，需改用 `python -m torchtitan.train` [#5013](https://github.com/pytorch/torchtitan/pull/5013)；Float8 训练支持被完全移除 [#4961](https://github.com/pytorch/torchtitan/pull/4961)；`torchcomms` 不再为必需依赖 [#4941](https://github.com/pytorch/torchtitan/pull/4941)。
- **限制性变更**：RL 训练暂时拒绝 `top_p < 1` 的采样配置，直到 trainer 能正确重放截断采样 [#5021](https://github.com/pytorch/torchtitan/pull/5021)。
- **进行中的大特性**：DistMuon 支持 DeepSeek V4（[#4920](https://github.com/pytorch/torchtitan/pull/4920)）、Kimi K3 的 PP 存储优化（[#4963](https://github.com/pytorch/torchtitan/pull/4963)）和 FSDP 修复（[#5025](https://github.com/pytorch/torchtitan/pull/5025)）、以及 vLLM 引擎线程化（[#5029](https://github.com/pytorch/torchtitan/pull/5029)）均处于 draft 阶段，值得持续关注。
