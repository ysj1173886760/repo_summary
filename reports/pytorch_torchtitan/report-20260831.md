# Pull Request Digest for pytorch/torchtitan (20260824-20260831)

**本周关键趋势**：Kimi K3 多模态模型的全栈并行化（PP/CP/EP/DEP）与强化学习训练栈的快速迭代构成两大主线，合计 76 个 PR。

**活跃领域**：
1. Kimi K3 模型并行化与内核支持
2. 强化学习（RL）训练栈
3. 量化与低精度训练（MXFP8）
4. 图训练器（GraphTrainer）与编译优化
5. CI/测试与硬件后端（B200/ROCm）
6. 分布式优化器与状态管理
7. 模型升级与修复

---

### 1. 模型与架构支持
- **Kimi K3 全栈并行化**：新增文本侧流水线并行（PP）虚拟 stage 缓存适配器 [PR#4312](https://github.com/pytorch/torchtitan/pull/4312)，上下文并行（CP）支持 MLA Ulysses 与 KDA KCP [PR#4313](https://github.com/pytorch/torchtitan/pull/4313)，专家并行（EP）[PR#4314](https://github.com/pytorch/torchtitan/pull/4314)，以及视觉塔 DEP 调度 [PR#4381](https://github.com/pytorch/torchtitan/pull/4381) 和动态 CP [PR#4380](https://github.com/pytorch/torchtitan/pull/4380)。KDA 内核增加非 SM100/103 设备的 reference 实现 [PR#4374](https://github.com/pytorch/torchtitan/pull/4374)，并支持 sample packing [PR#4347](https://github.com/pytorch/torchtitan/pull/4347)。
- **Qwen3.5 → Qwen3.8 升级**：移除旧版，支持 Qwen3.8-27B 多模态和 2.4T-A95B 文本 MoE [PR#4355](https://github.com/pytorch/torchtitan/pull/4355)。修复 MoE 专家权重布局适配 [PR#4373](https://github.com/pytorch/torchtitan/pull/4373) 和视觉自注意力跨帧问题 [PR#4317](https://github.com/pytorch/torchtitan/pull/4317)。
- **其他模型**：flux FLOPs 估算修正 [PR#4366](https://github.com/pytorch/torchtitan/pull/4366)；`FusedSwiGLU` 改用 `Linear` 表示 [PR#4323](https://github.com/pytorch/torchtitan/pull/4323)，并支持 dist-GEMM TP 重叠 [PR#4321](https://github.com/pytorch/torchtitan/pull/4321)。

### 2. 分布式并行策略
- **FSDP 与 MoE**：处理 FSDP 下不均匀 expert 分片 [PR#4371](https://github.com/pytorch/torchtitan/pull/4371)；`GroupedExperts._grouped_mm` 接口改为传递原始权重 [PR#4368](https://github.com/pytorch/torchtitan/pull/4368)。
- **张量并行（TP）**：修复 rowwise TP bias 梯度缩放 [PR#4332](https://github.com/pytorch/torchtitan/pull/4332)；DistMuon 支持 TP 存储布局 [PR#4353](https://github.com/pytorch/torchtitan/pull/4353)。
- **上下文并行（CP）**：将 K/V all-gather 移入 attention 内核 [PR#4322](https://github.com/pytorch/torchtitan/pull/4322)；GraphTrainer 增加 `simple_cp` 变换 [PR#4330](https://github.com/pytorch/torchtitan/pull/4330)。
- **流水线并行（PP）**：修复 CUDA graph trace 中 PP 依赖箭头绘制 [PR#4375](https://github.com/pytorch/torchtitan/pull/4375)。
- **通信后端清理**：移除 `local_tensor` 和 `torchcomms` 模式 [PR#4306](https://github.com/pytorch/torchtitan/pull/4306)。

### 3. 训练基础设施与性能优化

- **优化器**：修复 Adam/AdamW 初始化后 step 计数器与动量状态 [PR#4382](https://github.com/pytorch/torchtitan/pull/4382)；DistMuon 打包拷贝优化 [PR#4308](https://github.com/pytorch/torchtitan/pull/4308)（重复 PR）。
