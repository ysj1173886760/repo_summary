# Pull Request Digest for pytorch/torchtitan (20260824-20260831)

**PR 统计**：共 77 个（已合并 56 · 进行中 3 · 草稿 9 · 已关闭 9）

## 本周概览
本周重点围绕 Kimi K3 模型的全套并行策略落地、GraphTrainer 的图级优化能力扩展，以及强化学习训练循环的进程隔离重构展开。同时，静默数据损坏检测引擎正式集成进 Trainer，Qwen3.5 升级为 Qwen3.8 并支持文本 MoE 路径，多项数值与 CI 基础设施得到加固。

**最活跃领域**：1. Kimi K3 模型并行支持；2. GraphTrainer 功能增强；3. 强化学习（RL）基础设施；4. 训练稳定性与数值修复；5. CI/测试优化

## 重点进展
- **Kimi K3 获得流水线、上下文与专家并行支持**：新增 `pipeline_kimi_k3` 处理 Block Attention Residual 跨阶段传递，`KCP` 与 MLA All-Gather KV 实现上下文并行，并启用基于 all-to-all 的专家并行，使 K3 成为首个完整覆盖 PP/CP/EP 的 torchtitan 模型 [#4312](https://github.com/pytorch/torchtitan/pull/4312) [#4313](https://github.com/pytorch/torchtitan/pull/4313) [#4314](https://github.com/pytorch/torchtitan/pull/4314)
- **GraphTrainer 引入子图区域与简单 CP 变换**：新增 `subgraph` 上下文管理器与 min-cut 重计算策略，`SimpleCPTransform` 允许在无 DTensor 的情况下实现上下文并行，为后续图级调度打下基础 [#4329](https://github.com/pytorch/torchtitan/pull/4329) [#4330](https://github.com/pytorch/torchtitan/pull/4330)
- **RL 训练循环迁移至独立进程池**：`RolloutWorker` 将 rollout 执行从控制器进程移至 Monarch actor mesh，解决 CPU 利用率与 GIL 争用瓶颈；同时移除 RL 专用 BatchConfig，统一使用 trainer 的批次形状字段 [#4310](https://github.com/pytorch/torchtitan/pull/4310) [#4326](https://github.com/pytorch/torchtitan/pull/4326)
- **SDC 检测引擎集成进 Trainer**：`SDCReplayer` 通过确定性重放前向/反向并比对签名，可检测静默数据损坏；通过 `config.sdc_replay` 按需启用，不影响正常训练路径 [#4333](https://github.com/pytorch/torchtitan/pull/4333) [#4334](https://github.com/pytorch/torchtitan/pull/4334)
- **Qwen3.5 升级为 Qwen3.8**：模型包重命名为 `qwen3_8`，支持 Qwen3.8-27B 多模态与 Qwen3.8-2.4T-A95B 文本 MoE，移除旧版 flavor 与配方，并兼容两种 HF checkpoint 布局 [#4355](https://github.com/pytorch/torchtitan/pull/4355)

- **Qwen3.5 视觉自注意力修复**：修正 segment 长度计算，使每个时间片独立注意力，与 Transformers 实现对齐 [#4317](https://github.com/pytorch/torchtitan/pull/4317)
- **Qwen3.5 MoE 权重布局适配**：修正 state dict 适配器中 `gate_up_proj` 与 `down_proj` 的维度处理，匹配 Transformers 最新布局 [#4373](https://github.com/pytorch/torchtitan/pull/4373)
- **DistMuon TP 存储布局（进行中）**：扩展优化器重分布计划以支持 DP 与 TP 多轴存储，使 Muon 计算可处理 Shard/StridedShard 布局 [#4353](https://github.com/pytorch/torchtitan/pull/4353)
- **Kimi K3 视觉 CP 与 DEP（进行中）**：MoonViT 动态 CP 沿 patch 维度分区并 gather KV，DEP 将视觉塔作为独立流水线阶段以隐藏气泡 [#4380](https://github.com/pytorch/torchtitan/pull/4380) [#4381](https://github.com/pytorch/torchtitan/pull/4381)
