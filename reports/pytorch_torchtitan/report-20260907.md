# Pull Request Digest for pytorch/torchtitan (20260831-20260907)

本周最显著的趋势是围绕大规模分布式训练的性能与可扩展性优化，特别是 CUDA Graph 在流水线并行中的全面集成、多个新模型家族的并行化支持，以及 SPMD 类型系统的深化。共 110 个 PR，最活跃的领域为：1) CUDA Graph 与流水线并行优化，2) 新模型架构支持（Kimi K3、Nemotron-3、Gemma-4 等），3) 上下文并行（CP）扩展，4) GraphTrainer 与 SPMD 类型系统增强，5) 混合专家（MoE）路由与量化。

### 1. 新模型与架构支持
- **Kimi K3 系列**：密集添加 CP 支持 [PR#4500](https://github.com/pytorch/torchtitan/pull/4500)、TP/SP 声明 [PR#4499](https://github.com/pytorch/torchtitan/pull/4499)、完整 SPMD 后端声明 [PR#4492](https://github.com/pytorch/torchtitan/pull/4492)、`spmd_types` 后端启用 [PR#4446](https://github.com/pytorch/torchtitan/pull/4446) 及量化平衡路由 [PR#4412](https://github.com/pytorch/torchtitan/pull/4412)。
- **Nemotron-3**：引入 4B/31B/120B/550B 混合 Mamba-MoE 模型族 [PR#4482](https://github.com/pytorch/torchtitan/pull/4482)。
- **Gemma-4**：支持 12B/31B 等变体，含滑动窗口与全局注意力 [PR#4481](https://github.com/pytorch/torchtitan/pull/4481)。
- **Qwen3.6**：新增配置注册与训练配方 [PR#4453](https://github.com/pytorch/torchtitan/pull/4453)，并添加融合 Triton `OffsetRMSNorm` [PR#4417](https://github.com/pytorch/torchtitan/pull/4417)。
- **DeepSeek V4**：修复 checkpoint 转换 [PR#4498](https://github.com/pytorch/torchtitan/pull/4498)、集成测试 [PR#4490](https://github.com/pytorch/torchtitan/pull/4490)、迁移至 Attention Gym 的 CSA [PR#4452](https://github.com/pytorch/torchtitan/pull/4452)、修正 FLOPs 估算 [PR#4441](https://github.com/pytorch/torchtitan/pull/4441) 及 RMSNorm epsilon [PR#4395](https://github.com/pytorch/torchtitan/pull/4395)。
- **其他**：Qwen3 8B 预训练配方 [PR#4491](https://github.com/pytorch/torchtitan/pull/4491)、Muse Glimmer 最终 norm 初始化修复 [PR#4489](https://github.com/pytorch/torchtitan/pull/4489)、Kimi 2.7 CP 启用 [PR#4448](https://github.com/pytorch/torchtitan/pull/4448)。
