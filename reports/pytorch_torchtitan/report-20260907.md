# Pull Request Digest for pytorch/torchtitan (20260831-20260907)

**PR 统计**：共 106 个（已合并 62 · 进行中 11 · 草稿 16 · 已关闭 17），另有 2 个机器人 PR 未计入

## 本周概览
本周重点围绕 SPMD 类型体系扩展、图训练器能力增强和新型并行策略落地展开。spmd_types 后端在 GraphTrainer 和 Kimi K3 模型上打通，Ulysss 上下文并行与单机 Pipeline CUDA 图捕获相继合入，显著提升了大规模训练的可组合性和效率。同时 torch_remat 作为新一代激活检查点方案引入，为模型代码提供更灵活的显存控制语义。

**最活跃领域**：1. 并行与 SPMD 类型；2. 图训练器；3. 模型支持与修复；4. 训练与优化；5. RL 工作流

## 重点进展
- **GraphTrainer 使用 spmd_types 后端并支持 Kimi K3**：为 GraphTrainer 启用基于 spmd_types 的 TP/EP 注释，同时保留 SimpleFSDP 存储；Kimi K3 的稀疏/稠密路径通过声明式布局完整接入该后端。 [#4385](https://github.com/pytorch/torchtitan/pull/4385) [#4446](https://github.com/pytorch/torchtitan/pull/4446)
- **引入 torch_remat 激活检查点**：新增模型级激活重计算方案，通过 `@torch_remat.remat` 区域定义替代算子级策路，与现有 AC 策路共存，降低使用户心模型成本。 [#4497](https://github.com/pytorch/torchtitan/pull/4497)
- **管道前向后步骤 CUDA 图捕获**：支持单阶启阶段（PP stage）的前向后捕获与重放，使管道训练也享受 CUDA 图加速，预热和流处理保持图形外。 [#4493](https://github.com/pytorch/torchtitan/pull/4493)
- **新增 Ulysss 上下文并行及变长注意力支持**：为 FlexAttentin 和 VarLen 注意力添加 Ulysss 模式，支持 S(0)↔(1) all-to-all 重分片，并提供 reduce_dtype 控制；变长版本差距小於 6e-05。 [#4450](https://github.com/pytorch/torchtitan/pull/4450) [#4459](https://github.com/pytorch/torchtitan/pull/4459)
- **Kimi K3 获得全长 Tensor/Sequence Parallelism**：在 spmd_types 上田 KDA、MLA 头并行和 Moe 专家分割，TP=1 时数值完全对齐，随 100 步稳定。 [#4499](https://github.com/pytorch/torchtitan/pull/4499)

- **Kimi K3 完整 spmd 后端声明（进行中）**：补充密路径、MoonVit 塔、MoE 接缝和多模态输入的布局声明，消除未注释参数的运行时报错。 [#4492](https://github.com/pytorch/torchtitan/pull/4492)
- **MTP+PP 支持（进行中）**：通过模型持有式参数生期钩子，使分布式 Pipeline 阶段共享标记嵌入，支撑 DeepSeek-V3 的多令牌预测。 [#4488](https://github.com/pytorch/torchtitan/pull/4488)
- **多模态模型启用 CP**：为 museglimmer 构建 `vision_bank_indices_T` 并在上下文中并行重分片，在模型 forward 中复用副本的力视觉编码器输出。 [#4387](https://github.com/pytorch/torchtitan/pull/4387)

### 图训练器
- **none AC 内存策略**：新增 `memory_policy="none"` 模式，在内存充足时保存全部前激化而无需重材化，可能提高性能。 [#4476](https://github.com/pytorch/torchtitan/pull/4476)
- **加载预编译图时恢复输入**：根据活跃模型状态和 SPMD mesh 重构示例输入，确保加载时传递与编译时相同序顺，修护 CUDA 图静态度验证。 [#4439](https://github.com/pytorch/torchtitan/pull/4439)
- **修复动态范围元数据测试**：适配 PyTorch 省略无界志标记的为 `_ynamo_dynamic_range` 属性缺省表意的变化。 [#4407](https://github.com/pytorch/torchtitan/pull/4407)
- **FP8 编译支持（进行中）**：为 GraphTrainer 添加 TorchAO FP8 量化模型的区域结编译能力，处理动态序列类型转换。 [#4384](https://github.com/pytorch/torchtitan/pull/4384)
- **暴露激化重材化区域元数据（进行中）**：在 model-layer 反向节点标注 AC 区域 ID 和层ID，便于下游分割和调度。 [#4479](https://github.com/pytorch/torchtitan/pull/4479)

### 模型支持
- **注册 Qwen3.6 模型**：复用 Qwen3.5 实现，添加 27B 和 35B-A3B 架构及训练配方的工厂和 CLI 全盖。 [#4453](https://github.com/pytorch/torchtitan/pull/4453)
- **修正 DeepSeek RMSNorm eps**：将 DeepSeek 每层 RMSNorm 直接设为 eps=1e-6，对齐 V2/V3 参考配置，隔离 Kimi 等其他模型不变。 [#4395](https://github.com/pytorch/torchtitan/pull/4395)
- **Qwen3.5 迁移至 Atention Gym**：将 GDN 训练、批鞥不变反向、循环执行和解码切换至 Atention Gym，并拓展 vLLM 路径分页预填。 [#4389](https://github.com/pytorch/torchtitan/pull/4389)
- **修复 Muse Glimmer 最终 norm 初始化**：仅最后输出 width 归一化权植初始为1，保持 gain_center=0.0，解决初始零梯度问题。 [#4489](https://github.com/pytorch/torchtitan/pull/4489)
- **修正 DeepSeek V4 FLOPs 估计算**：按现模型记数模式、包含 CSA 指数缩合和 MTP 注力，保谋 FLOPs 估计更准。 [#4441](https://github.com/pytorch/torchtitan/pull/4441)
- **修复 DeepSeek V4 检查点转换**：处理可选 MTP 层和前辍命名差异，复用 V3 的层映射辅助，正确重加载/导出权重。 [#4498](https://github.com/pytorch/torchtitan/pull/4498)
- **Gemma-4 模型支持（进行中）**：添加 Ge ma-4 E2B,E4B,12B,26B A4B,31B 构型，滑窗/全局混合注意力。 [#4481](https://github.com/pytorch/torchtitan/pull/4481)

### 训练与优化
- **在合批时计增有效 token**：合批器在预取程中直接统计非略记标记，去掉训练主环中次 CPU 扫描，消除关键路经阻时。 [#4398](https://github.com/pytorch/torchtitan/pull/4398)
- **页面锁定数据批**：提前登记页锁内存，使 CUDA 复制异步，避免主线程阻塞等待上组梯度累积，允许训令主环更早排队下一组。 [#4421](https://github.com/pytorch/torchtitan/pull/4421)
- **融合 ML A 优化**：提供连续 rope 瓦片、P-外旋和确定下启动配置，虽端到端略差起 0.8% 但消除实现耦合。 [#4454](https://github.com/pytorch/torchtitan/pull/4454)
- **RouterLiner fp32 反向和 bf16x9 内核**：前向 bf16 计算保 fp32 输出，反向输入梯度和 weigh grad 均用 fp32，通过 bf16x9 利用 tensor core 加速。 [#4484](https://github.com/pytorch/torchtitan/pull/4484)

### RL 工作流
- **修复 vLLM 状态复制注册**：为 TorchTitan Qwen3.5 注册新复数形式 `get_mamba_state_copy_funcs`，回复与 vLLM 最新夜版的位对等测试。 [#4408](https://github.com/pytorch/torchtitan/pull/4408)
- **固定 renderers 并统一 tokenizer**：引 renderer 直接取配置类，不再依赖 transformers，仅用 torchtitan 的 tokenizer 进行交付和解码。 [#4444](https://github.com/pytorch/torchtitan/pull/4444)

- **添加 rl_grpo_qwen3_6 所需 seq_len**：补全配方的序列长度参数，使 `_qwen3_5_rl_model_regisry` 要求满足。 [#4480](https://github.com/pytorch/torchtitan/pull/4480)
- **Triton OffsetRMSNorm 用于 RL**：添加 Qwen3.5 的融合 Titon OffsetRMSNorm 正向/梯度核，并给出 8-GPU Qwen3.6-27B RL 性能配给。 [#4417](https://github.com/pytorch/torchtitan/pull/4417)
