# Pull Request Digest for pytorch/torchtitan (20260509-20260516)

**关键趋势：** 本周 `graph_trainer` 组件经历大规模重构，重点围绕 EP（专家并行）重叠调度、编译管线简化和 FlexShard 可追踪性增强，共 52 个 PR，活跃领域集中在 1) `graph_trainer` 编译与调度、2) 分布式并行策略（FlexShard/EP/TP）、3) RL 训练基础设施、4) 模型支持（Qwen3.5/DeepSeek）、5) CI/测试修复。

---

### 1. `graph_trainer` 编译管线与调度重构
- **EP 重叠调度体系建立：** 引入完整的 EP 重叠流水线，包括图级分块（[PR#3325](https://github.com/pytorch/torchtitan/pull/3325)）、调度 pass（[PR#3328](https://github.com/pytorch/torchtitan/pull/3328)）、eager 分块脚手架（[PR#3363](https://github.com/pytorch/torchtitan/pull/3363)）和独立 EP 进程组隔离（[PR#3369](https://github.com/pytorch/torchtitan/pull/3369)），避免与 FSDP/TP 的 NCCL 流串行化。
- **编译模式清理：** 移除废弃的 `"aot"` 编译模式，删除 `graph_utils.py` 约 550 行代码（[PR#3327](https://github.com/pytorch/torchtitan/pull/3327)）；重构 `full_inductor_compilation_pass` 通过 `regional_inductor` 路径与 `cudagraph_pass` 协同（[PR#3346](https://github.com/pytorch/torchtitan/pull/3346)），并修复 c10d 集合操作的 functionalization 问题（[PR#3341](https://github.com/pytorch/torchtitan/pull/3341)）。
- **Pass 模块化拆分：** 将单体 `passes.py`（~1037 行）拆分为 `memory_policy.py`、`inductor_passes.py`、`cudagraph.py` 等聚焦模块（[PR#3319](https://github.com/pytorch/torchtitan/pull/3319)）。
- **内存与调度优化：**
  - 移除 `fsdp_reshard_after_fwd_pass`，统一由内存策略框架处理（[PR#3370](https://github.com/pytorch/torchtitan/pull/3370)）。
  - `JointManualOverlapScheduler` 改为独立节点移动，移除全局拓扑排序以提升 pass 可组合性（[PR#3352](https://github.com/pytorch/torchtitan/pull/3352)）。
  - 支持多 FSDP PG 的 `overlap_fsdp_ag_rs_pass`（[PR#3351](https://github.com/pytorch/torchtitan/pull/3351)）。
  - 修复 SAC remat 中 FakeTensor 存储共享导致的 `MemoryTracker` 误判（[PR#3343](https://github.com/pytorch/torchtitan/pull/3343)，后被回退 [PR#3358](https://github.com/pytorch/torchtitan/pull/3358)）。
  - 延迟 cudagraph 兼容性检查至 pass 执行时，支持 `regional_inductor` 消除 `flex_attention` 后再捕获（[PR#3355](https://github.com/pytorch/torchtitan/pull/3355)）。
  - 添加 `torch.ops.bucketing` 到预编译序列化过滤器（[PR#3354](https://github.com/pytorch/torchtitan/pull/3354)）。
  - 改进 SAC 标记和 CPU offload pass 元数据传播（[PR#3321](https://github.com/pytorch/torchtitan/pull/3321)）。
- **符号维度与追踪增强：** 支持 hinted symbolic input dims 用于 EP 分块（[PR#3362](https://github.com/pytorch/torchtitan/pull/3362)）；修复 AutoParallel `input_fn` 缺失 `positions` 张量（[PR#3315](https://github.com/pytorch/torchtitan/pull/3315)）。

### 2. 分布式并行策略
- **FlexShard 演进：**
  - 使 FlexShard 可被 `torch.compile` 追踪（[PR#3317](https://github.com/pytorch/torchtitan/pull/3317)）。
  - 添加 `Owned` placement 及对应集合操作，将 bucket unshard 和梯度规约选择移入 placement 契约（[PR#3359](https://github.com/pytorch/torchtitan/pull/3359)）。
  - 支持分组 reshard-after-forward buckets（[PR#3348](https://github.com/pytorch/torchtitan/pull/3348)）和重叠 reduce-scatter（[PR#3339](https://github.com/pytorch/torchtitan/pull/3339)）。
  - 按 provenance 限定 recompute 策略（[PR#3349](https://github.com/pytorch/torchtitan/pull/3349)）。
- **HybridEP 编译支持：** 将 buffer 初始化移入 custom op 实现，通过 op schema 传递 `ep_size`/`group_name`，使 HybridEP 兼容 `torch.compile`（[PR#3360](https://github.com/pytorch/torchtitan/pull/3360)）。
- **TP + CP 损失日志修复：** 修复 `_dist_reduce` 在 DTensor 路径下忽略 CP mesh 的问题（[PR#3313](https://github.com/pytorch/torchtitan/pull/3313)）。
- **ChunkedCELoss 修复：** 修复无序列并行、无损失并行时 TP 下的 mixed tensor-DTensor 错误（[PR#3364](https://github.com/pytorch/torchtitan/pull/3364)）。
- **DeepEP 兼容性：** 添加 `EventOverlap` 导入回退和 MoE 后端选择日志（[PR#3320](https://github.com/pytorch/torchtitan/pull/3320)）。

### 3. RL 训练基础设施
- **vLLM 引擎升级：** 切换到 vLLM v2 引擎（[PR#3330](https://github.com/pytorch/torchtitan/pull/3330)），并修复 tear down 超时问题（[PR#3365](https://github.com/pytorch/torchtitan/pull/3365)）。
- **RL 数据流水线：** 添加 `Batcher` 组件，支持 micro-batch 和梯度累积（[PR#3347](https://github.com/pytorch/torchtitan/pull/3347)）。
- **内存优化：** 添加可选的分块 logprobs 计算，降低峰值内存（[PR#3314](https://github.com/pytorch/torchtitan/pull/3314)）。
- **权重加载改进：** 使用 `checkpointManager` 统一 trainer 和 generator 的初始权重加载（[PR#3318](https://github.com/pytorch/torchtitan/pull/3318)）。
- **CI 路由：** 使用 pytest markers（`@gpu_test`、`@h100_test`）替代自定义 torchrun 命令（[PR#3357](https://github.com/pytorch/torchtitan/pull/3357)）。

### 4. 模型支持
- **Qwen3.5 引入：** 替代 Qwen3-VL，采用混合注意力架构（75% GatedDeltaNet + 25% full attention），支持 head-sharded TP 和 MoE（[PR#3371](https://github.com/pytorch/torchtitan/pull/3371)）。
- **DeepSeek V3 配置：** 添加 16B SDPA 配置（[PR#3361](https://github.com/pytorch/torchtitan/pull/3361)）。
- **Helion 内核：** 添加实验性 RMSNorm 和融合 Q/K RoPE 内核，B200 上最高 5.58x 加速（[PR#3342](https://github.com/pytorch/torchtitan/pull/3342)）。
- **SPMD Llama3：** 推进 Context Parallelism 支持（[PR#3344](https://github.com/pytorch/torchtitan/pull/3344)）和 R/I/S/P 分片配置（[PR#3337](https://github.com/pytorch/torchtitan/pull/3337)）。

  - 跳过因上游 DTensor 回归导致的 dense numerics 测试（[PR#3372](https://github.com/pytorch/torchtitan/pull/3372)）。
