# Pull Request Digest for pytorch/torchtitan (20260720-20260727)

1. **关键要点**：本周 36 个 PR 的核心趋势是 **GraphTrainer 的 FP8 编译与内存策略深化、强化学习训练管道全面支持多并行与生成器统一，以及优化器分片抽象 FlexShard 的引入**。  
   活跃领域：① GraphTrainer 增强 ② 强化学习（RL）训练 ③ 优化器与分片 ④ 上下文并行（CP） ⑤ 模型与后端 ⑥ 专家并行（EP） ⑦ 基础设施与 CI。

2. **GraphTrainer 增强**
   - [PR#3989](https://github.com/pytorch/torchtitan/pull/3989)：为 `GraphTrainer` 添加 FP8 区域编译支持，传播量化溯源并验证 FP8 计算，兼容全图/区域 `Inductor` 编译。
   - [PR#3979](https://github.com/pytorch/torchtitan/pull/3979)：去重 EP 重叠就绪节点，修复因分块依赖导致的重复调度和矛盾相位边。
   - [PR#3975](https://github.com/pytorch/torchtitan/pull/3975)：引入两级 ILP 内存策略 `auto_perf_maxing`，基于 `torchinsights` 估算器在张量粒度自动决定保留/重计算/CPU 卸载。
   - [PR#3963](https://github.com/pytorch/torchtitan/pull/3963)：释放图输出梯度，将稳态 `max_active` 内存从 25.5 GiB 降至 19.9 GiB。
   - [PR#3956](https://github.com/pytorch/torchtitan/pull/3956)：支持 `MinimalAsyncEP` 的图分块，与 #3955、#3954、#3953 形成堆叠，统一分块梯度集合归一化。

3. **优化器与分片**
   - [PR#3986](https://github.com/pytorch/torchtitan/pull/3986)：新增优化器中立的 `flex_shard` 运行时，定义 `BucketSpec`、`Owned` 等计算契约，自动构建重分布计划。
   - [PR#3987](https://github.com/pytorch/torchtitan/pull/3987)：基于 FlexShard 实现 `MuonAdapter`，声明完整矩阵 `Owned` 计算需求，保持 DTensor 持久存储。
   - [PR#3988](https://github.com/pytorch/torchtitan/pull/3988)：向量化 MoE 专家偏置更新，批量处理 `[layers, experts]` 张量，使用 foreach 操作并兼容 DTensor。
   - [PR#3985](https://github.com/pytorch/torchtitan/pull/3985)：添加虚拟 EMA 优化器，支持固定衰减和基于步数的尾部平均，用于模型平均。

4. **上下文并行（CP）**
   - [PR#3977](https://github.com/pytorch/torchtitan/pull/3977)：重构 CP 代码为独立包 `context_parallel`，为 Ulysses、Allgather、SelectiveGather 等实现做准备。
   - [PR#3978](https://github.com/pytorch/torchtitan/pull/3978)：通过 `cp_method` 和 `attention_sharding` 实现可插拔 CP 注意力，在配置系统中动态替换实现。
   - [PR#3972](https://github.com/pytorch/torchtitan/pull/3972)：允许 PTRR 负载均衡器从字典中选择掩码，支持多掩码模型（如 GPT-OSS、Olmo3）。

5. **强化学习（RL）训练**
   - [PR#3980](https://github.com/pytorch/torchtitan/pull/3980)：在 RL 策略训练器中支持流水线并行和上下文并行，通过 `TorchStore` 发布/重建分阶段状态，覆盖 PP、CP、PP+DP 及 8-GPU 混合拓扑。
   - [PR#3957](https://github.com/pytorch/torchtitan/pull/3957)：统一 Qwen3.5 混合模型在 vLLM 中的生成路径，复用 `fla` 内核，实现 bitwise 一致性，支持 TP+DP/EP。
   - [PR#3951](https://github.com/pytorch/torchtitan/pull/3951)：添加单节点 Qwen3-4B DAPO-Math 示例，TP=2 训练器 + 6 个独立生成器。
   - [PR#3958](https://github.com/pytorch/torchtitan/pull/3958)：添加 vLLM 统计日志器，导出 OTLP 指标用于生成性能调试。
   - [PR#3959](https://github.com/pytorch/torchtitan/pull/3959)：修复 RL CI 中 bitwise 测试因进程组销毁导致的挂起。
   - [PR#3950](https://github.com/pytorch/torchtitan/pull/3950)：修复 `readline` 导入导致 `VLLMGenerator` 挂起的问题。
   - [PR#3981](https://github.com/pytorch/torchtitan/pull/3981)：修复 RL 测试（已关闭）。

6. **模型与后端**
   - [PR#3966](https://github.com/pytorch/torchtitan/pull/3966)：添加 Olmo3 模型支持（堆叠 #3967、#3968）。
   - [PR#3967](https://github.com/pytorch/torchtitan/pull/3967)：添加预分词代码。
   - [PR#3968](https://github.com/pytorch/torchtitan/pull/3968)：添加外部评估钩子。
   - [PR#3964](https://github.com/pytorch/torchtitan/pull/3964)：为 HF transformers 建模后端接入 `spmd_types` 分片后端，解锁 DSA+TP 配置。
   - [PR#3973](https://github.com/pytorch/torchtitan/pull/3973)：为 Qwen3.5 dense 启用 `spmd_types` 后端（概念验证）。
   - [PR#3984](https://github.com/pytorch/torchtitan/pull/3984)：在 flex attention 下重置 GatedDeltaNet 文档边界状态（基于 #3801）。
   - [PR#3976](https://github.com/pytorch/torchtitan/pull/3976)：限制 FA3 仅在 Hopper 激活，Blackwell 回退 FA2，避免 SM 10.0 崩溃。

7. **专家并行（EP）**
   - [PR#3970](https://github.com/pytorch/torchtitan/pull/3970)：统一 EP 令牌调度器 API，抽象 `BaseEPTokenDispatcher`，整合 AllToAll、DeepEP、HybridEP、MinimalAsyncEP。
   - [PR#3969](https://github.com/pytorch/torchtitan/pull/3969)：修复 `MinimalAsyncEP` top-k 内核中 int32 地址溢出，提升程序 ID 到 int64。
   - [PR#3955](https://github.com/pytorch/torchtitan/pull/3955)：启用 eager EP 重叠。
   - [PR#3954](https://github.com/pytorch/torchtitan/pull/3954)：拆分令牌交换的启动与等待。
   - [PR#3953](https://github.com/pytorch/torchtitan/pull/3953)：统一分块梯度集合归一化。

8. **基础设施与 CI**
   - [PR#3961](https://github.com/pytorch/torchtitan/pull/3961)：CI 每个模型测试仅运行一个后端（优先 `spmd_types`），减少超时。
   - [PR#3962](https://github.com/pytorch/torchtitan/pull/3962)：修复 transformers 5.9.0 和 hub 1.24.0 的 tokenizer 下载兼容性。
   - [PR#3965](https://github.com/pytorch/torchtitan/pull/3965)：更新 GitHub Actions 依赖。
   - [PR#3974](https://github.com/pytorch/torchtitan/pull/3974)：添加粗粒度模块分析器插桩，标记 block、attention、moe 等区域。
